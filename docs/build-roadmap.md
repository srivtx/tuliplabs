# Build your own X: what comes next

Chapters 1–49 are live. These are the parts chosen next, in the order they'll be built. On 2026-11-07 two parts came first: **Backends at work**, the apps a company asks a backend developer to build, in Node with Express and Zod, then in Python with FastAPI. Each starts from nothing and grows into a real service, and its code runs in the page (Node in a box, `learn/wb-node.js`; zod there matches the real Zod 4 on every case in `tools/zod-parity.js`). On 2026-11-04 the order changed: the chapters that explain how reality works come first, and each of those has to answer a real "what is actually going on?" question. Each chapter
gets the usual shape: a live simulation with a naive-vs-real comparison and one goal, write / bug /
Parsons / predict exercises, a real-world project with graded exercises, a from-memory rebuild and a
recall question.
