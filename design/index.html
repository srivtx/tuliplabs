Draw it in CSS
until it matches.

Every level is a target: a poster, a card, a phone screen. Write the CSS, lay your board over the target, and watch the match climb pixel by pixel. The courses run from one square to a layout that reflows from desktop to phone.

Start with one square How a level works

How a level works

  1. Read the briefOne target, one idea to learn, and a few house rules a good designer would follow.
  2. Write the CSSThe HTML is fixed. You only write styles, with hints and a peek at the answer if you need them.
  3. Lay it over the targetGhost, side by side, or a heat map of every pixel that's off. Check it on phone, tablet and desktop.
  4. Match it96% of the pixels and every house rule, and the level is yours.
