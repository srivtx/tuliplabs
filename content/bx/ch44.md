## The jam with no cause

In 2008, researchers in Japan put 22 cars on a circular track and told the drivers to hold a steady speed. There was nothing on the road. Within minutes, a jam appeared, and it rolled backward round the circle.

Here's that experiment. Nobody in it does anything wrong.

```viz
name: bx-traffic
title: 22 cars on a loop
goal: Wait until a jam forms by itself, then switch on **One smart car** and keep it on until the wave has gone.
height: 400
Tap any car to brake it. On the right, each car draws its path as it goes.
```

Look at the right-hand picture. Every car's path climbs, because every car is going forward. But the red stripes slide **down**. A jam is not a thing made of cars. It's a **wave** passing through them, the way a stadium wave passes through people who never leave their seats. Cars enter at the back and leave at the front, while the jam itself drifts backward. On real motorways that drift is roughly 15–20 km/h, which is why you can hit a jam whose cause vanished half an hour ago.

## One driver's rule

The simulation uses the **intelligent driver model**, which real traffic engineers use. It balances two urges: speed up towards the speed you want, and back off if the gap is smaller than the one you'd like.

The gap you'd like has three parts: a minimum distance, your speed times a time headway (about 1.6 seconds here), and extra if you're closing on the car in front.


So where does the jam come from? Each driver reacts to the car in front a little late, and then brakes a little harder than that car did, to get the gap back. The next driver does the same, harder again. A small touch of the brakes **grows as it's passed backward**. Engineers call this string instability. Past a certain density, the steady flow can't survive: any small wobble will do.

## Jams on a grid

A much simpler model shows the same thing, and fits in a few lines: the **Nagel–Schreckenberg** model, a cousin of chapter 42's sand. The road is a ring of cells. A car has a whole-number speed, and all cars update at once:

1. Speed up by 1, up to `vmax`
2. Slow down to the number of empty cells ahead, so you never hit anyone
3. Maybe slow down by 1 at random (being human)
4. Move forward by your speed

```exercise
title: nagel_schreckenberg
kind: write
---prompt
Write `step(road, vmax, slow=())`. `road` is a list where `-1` is an empty cell and any other number is a car's speed. The road is a ring. `slow` is a collection of the indices of cars that randomly slow down this step (we pass it in so the tests are repeatable). Follow the four rules for each car, working from the **old** road, and return a new list.
---starter
def step(road, vmax, slow=()):
    n = len(road)
    new = [-1] * n
    for i, v in enumerate(road):
        if v >= 0:
            v = min(v + 1, vmax)
            new[(i + v) % n] = v
    return new
---solution
def step(road, vmax, slow=()):
    n = len(road)
    new = [-1] * n
    for i, v in enumerate(road):
        if v < 0:
            continue
        gap = 0
        while gap < n - 1 and road[(i + gap + 1) % n] < 0:
            gap += 1
        v = min(v + 1, vmax, gap)
        if i in slow and v > 0:
            v -= 1
        new[(i + v) % n] = v
    return new
---tests
assert step([0, -1, -1, -1, -1], 2) == [-1, 1, -1, -1, -1]
assert step([2, -1, -1, -1, -1, -1], 2) == [-1, -1, 2, -1, -1, -1], "at top speed"
assert step([2, -1, 0, -1], 5) == [-1, 1, -1, 1], "blocked by the gap, and the front car is free to go"
assert step([1, 0, -1], 5) == [0, -1, 1], "no gap, no movement"
assert step([3, -1, -1, -1, -1, -1], 3, {0}) == [-1, -1, 2, -1, -1, -1], "a random slow-down"
assert step([-1, -1, 1], 3) == [-1, 2, -1], "the ring wraps round"
assert sum(1 for c in step([1, -1, 2, -1, 0, -1, -1], 3) if c >= 0) == 3, "cars never vanish"
---hint
Count the empty cells ahead with `%` so the road wraps round. Then speed = `min(v + 1, vmax, gap)`.
```

## More cars, fewer arrivals

How many cars get past a point per minute? That's the **flow**, and it's what a road exists to deliver. An empty road has none, and a packed road has none, so somewhere between them there's a peak. Going past it, each added car reduces how many arrive.

```predict
for density in (0.1, 0.2, 0.5, 0.9):
    print(density, round(min(density * 5, 1 - density), 2))
```

```exercise
title: fundamental_diagram
kind: write
---prompt
Write `flow(density, vmax=5, n=120, steps=300)`. Place `round(density * n)` cars with speed 0, spread evenly: car `k` goes in cell `k * n // cars`. Run `step` (given) for `steps` steps with no random slow-downs. Return the total of all the cars' speeds divided by `n`: that's the average number of cars crossing a point per step.
---setup
def step(road, vmax, slow=()):
    n = len(road)
    new = [-1] * n
    for i, v in enumerate(road):
        if v < 0:
            continue
        gap = 0
        while gap < n - 1 and road[(i + gap + 1) % n] < 0:
            gap += 1
        v = min(v + 1, vmax, gap)
        new[(i + v) % n] = v
    return new
---starter
def flow(density, vmax=5, n=120, steps=300):
    return density * vmax
---solution
def flow(density, vmax=5, n=120, steps=300):
    cars = round(density * n)
    road = [-1] * n
    for k in range(cars):
        road[k * n // cars] = 0
    for _ in range(steps):
        road = step(road, vmax)
    return sum(v for v in road if v >= 0) / n
---tests
assert abs(flow(0.1) - 0.5) < 0.02, "light traffic: everyone at full speed"
assert abs(flow(0.5) - 0.5) < 0.02, "half full"
assert abs(flow(0.8) - 0.2) < 0.02
assert flow(0.8) < flow(0.2) and flow(0.5) < flow(0.2), "past the peak, more cars means less flow"
assert max(range(5, 95, 5), key=lambda d: flow(d / 100)) in (15, 20), "the peak is near density 1 / (vmax + 1)"
---hint
The starter assumes everyone always drives at full speed. Build the road, run it, and add up the speeds.
```

This is why ramp lights exist on busy motorways. Holding cars back at the ramp keeps the road just below the peak, so more of them get through.

## The road that made everyone slower

Here's a stranger result. In 1968, the mathematician Dietrich Braess showed that adding a road can make **everyone's** trip longer.

```viz
name: bx-braess
title: A free shortcut
goal: Open the **shortcut**, wait until the average trip has settled at 80 minutes, then close it again.
height: 400
Then try **A planner decides**.
```

Nobody is stupid here. Given what everyone else is doing, each driver picks the fastest route, and when no one can improve by switching alone, the system has reached a **Nash equilibrium**. It's stable, and it's worse. Selfish choices don't have to add up to the best result for the group.

It isn't only a puzzle. Seoul tore down a major elevated road in the 2000s to restore the Cheonggyecheon stream, and the feared gridlock didn't arrive. The same logic applies beyond roads: power grids, networks and even food webs can get worse when you add a link.

```exercise
title: selfish_drivers
kind: write
---prompt
Write `settle(n, shortcut)`. `n` drivers choose routes `0` (top), `1` (bottom) or, if `shortcut` is true, `2` (both narrow roads and the free link). With `a` the number of drivers using the top narrow road (routes 0 and 2) and `b` those using the bottom narrow road (routes 1 and 2):

- route 0 takes `a / 100 + 45`
- route 1 takes `45 + b / 100`
- route 2 takes `a / 100 + b / 100`

Start with half of them (rounded down) on route 0 and the rest on route 1. Then repeat: go through the drivers in order, and move any driver to a route that is **strictly** faster for them, counting the change their own move makes. Stop when a full pass moves nobody. Return the average trip time, rounded to 1 decimal place.
---starter
def settle(n, shortcut):
    return 45 + n / 200
---solution
def settle(n, shortcut):
    routes = [0] * (n // 2) + [1] * (n - n // 2)
    a = routes.count(0)
    b = routes.count(1)

    def times(a, b):
        return [a / 100 + 45, 45 + b / 100, a / 100 + b / 100]

    options = [0, 1, 2] if shortcut else [0, 1]
    moved = True
    while moved:
        moved = False
        for i, r in enumerate(routes):
            best, best_t = r, times(a, b)[r]
            for o in options:
                if o == r:
                    continue
                na = a - (r in (0, 2)) + (o in (0, 2))
                nb = b - (r in (1, 2)) + (o in (1, 2))
                t = times(na, nb)[o]
                if t < best_t - 1e-9:
                    best, best_t = o, t
            if best != r:
                a += (best in (0, 2)) - (r in (0, 2))
                b += (best in (1, 2)) - (r in (1, 2))
                routes[i] = best
                moved = True
    t = times(a, b)
    return round(sum(t[r] for r in routes) / n, 1)
---tests
assert settle(4000, False) == 65.0, "without the shortcut"
assert settle(4000, True) == 80.0, "with it, everyone is 15 minutes slower"
assert settle(1000, True) < settle(1000, False), "with few drivers, the shortcut really does help"
---hint
Keep `a` and `b` up to date as drivers move. To judge a move, work out what `a` and `b` would become.
---hint
Booleans count as 0 and 1 in Python, so `a - (r in (0, 2)) + (o in (0, 2))` is the new count.
```

When a free-flowing road meets slow traffic, the boundary between them moves at a speed you can calculate from flow and density on both sides. It's how you predict how far back a queue will reach.

```exercise
title: shock_wave
kind: write
---prompt
Write `wave_speed(q1, k1, q2, k2)`: the speed of the boundary between traffic with flow `q1` and density `k1` upstream, and flow `q2` and density `k2` downstream. It's `(q2 - q1) / (k2 - k1)`. If the densities are equal, there's no boundary, so return `0.0`. A negative answer means that the boundary moves backward.
---starter
def wave_speed(q1, k1, q2, k2):
    return (q1 + q2) / (k1 + k2)
---solution
def wave_speed(q1, k1, q2, k2):
    if k1 == k2:
        return 0.0
    return (q2 - q1) / (k2 - k1)
---tests
assert wave_speed(1500, 20, 0, 150) == -1500 / 130, "free traffic hits a stopped queue"
assert wave_speed(1500, 20, 0, 150) < 0, "so the queue grows backward"
assert wave_speed(1000, 40, 1800, 25) < 0
assert wave_speed(1000, 40, 1000, 40) == 0.0
---hint
It's a slope: the change in flow divided by the change in density.
```

How bad can selfishness get? The **price of anarchy** is the ratio between the selfish result and the best a planner could do.

```exercise
title: price_of_anarchy
kind: write
---prompt
Write `price_of_anarchy(n, narrow, wide)`. `n` drivers choose between two parallel roads. The narrow one takes `x * narrow` minutes with `x` drivers on it, and the wide one always takes `wide` minutes. Return `selfish / best`, both as average trip times, rounded to 3 places:

- `selfish`: try every `x` from 0 to `n` and take the **largest** `x` for which `x * narrow <= wide` (a driver will use the narrow road while it's no slower).
- `best`: try every `x` from 0 to `n` and take the smallest possible average, `(x * x * narrow + (n - x) * wide) / n`.

In both cases the average is the second formula, with that `x`.
---starter
def price_of_anarchy(n, narrow, wide):
    return 1.0
---solution
def price_of_anarchy(n, narrow, wide):
    def average(x):
        return (x * x * narrow + (n - x) * wide) / n
    selfish = max(x for x in range(n + 1) if x * narrow <= wide)
    best = min(average(x) for x in range(n + 1))
    return round(average(selfish) / best, 3)
---tests
assert price_of_anarchy(100, 1, 100) == 1.333, "the classic result: 4/3"
assert price_of_anarchy(10, 1, 1000) == 1.0, "plenty of room: selfishness costs nothing"
assert price_of_anarchy(1000, 0.1, 100) == 1.333
---hint
Define `average(x)` once, and use it for both.
```

```recall
Q: Explain how a traffic jam can appear with no cause and why it moves backward, why more cars can mean fewer arrivals, and how adding a road can make everyone slower.
A: Each driver follows the car ahead with a delay and brakes slightly harder than the car in front, so a small disturbance grows as it's passed back along the line. Above a critical density the smooth flow is unstable, and any wobble becomes a stop-and-go wave. The jam is a wave, not a group of cars: cars enter at the back and leave at the front, so the jam drifts backward while every car moves forward. One car that keeps a steady average speed and lets its gap absorb the wave breaks the copying chain. Flow is density times speed: it's zero on an empty road and zero on a packed one, so it peaks in the middle, and past that peak extra cars reduce arrivals. Selfish routing ends in a Nash equilibrium, where nobody can improve by changing only their own choice. It's stable but needn't be good. In Braess's paradox a free shortcut pulls everybody onto the narrow roads, raising each trip from 65 to 80 minutes, so closing it helps everyone.
```
