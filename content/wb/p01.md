Ledger is a small database in the spirit of Redis. You talk to it in a terminal. `SET` stores a value, `GET` reads it, and it remembers everything even after the program is killed in the middle of a write.

You'll write it in three files, the way a real one is laid out: **shell.py** speaks the protocol, **store.py** owns the data and **log.py** keeps it safe on disk. Every ticket adds one part, and the map on the right lights it up.

```ticket
The terminal hands your program one line at a time: `handle(line)` gets the text and returns the reply.
`handle` is already written. It answers `PING` and `ECHO`. What it needs is **`tokenize(line)`**, which splits the line into words.

Spaces separate words, except inside double quotes. `ECHO "hello world" again` is three words: `ECHO`, `hello world` and `again`. The quotes themselves are not part of the word. Every tool that reads commands starts here: shells, SQL, Redis, git. `line.split()` looks right until somebody stores a value with a space in it. Walking the line one character at a time, remembering whether you're inside quotes, is the smallest real **lexer**, and you'll write bigger ones later.
```

```ticket
---brief
Now Ledger stores data. Add four commands to `handle`, keeping everything in a dictionary called `DATA` at the top of shell.py:

| Command | Reply |
|---|---|
| `SET key value` | `OK` |
| `GET key` | the value, or `(nil)` if there's no such key |
| `DEL key` | `1` if it deleted something, `0` if not |
| `KEYS` | every key, sorted, one per line, or `(empty)` |

A **protocol** is a promise: every command has a fixed shape and one reply. Checking the argument count *before* doing anything means a typo can never half-run a command. Redis keeps a table of each command's arity for exactly this reason, and so will you.

"""Ledger's shell: the terminal sends each line to handle(line), and prints what it returns."""

DATA = {}

# How many arguments each command takes (None: any number).
ARITY = {"PING": 0, "ECHO": None, "SET": 2, "GET": 1, "DEL": 1, "KEYS": 0}


def tokenize(line):
    """Split a command line into words. Double quotes keep spaces inside one word."""
    words, word = [], ""
    quoted = started = False
    for ch in line:
        if ch == '"':
            quoted = not quoted
            started = True
        elif ch == " " and not quoted:
            if started:
                words.append(word)
            word, started = "", False
        else:
            word += ch
            started = True
    if quoted:
        raise ValueError("unclosed quote")
    if started:
        words.append(word)
    return words


def handle(line):
    try:
        words = tokenize(line)
    except ValueError as e:
        return f"ERR {e}"
    if not words:
        return None
    cmd, args = words[0].upper(), words[1:]
    if cmd not in ARITY:
        return f"ERR unknown command '{words[0]}'"
    if ARITY[cmd] is not None and len(args) != ARITY[cmd]:
        return f"ERR wrong number of arguments for '{cmd.lower()}'"
    if cmd == "PING":
        return "PONG"
    if cmd == "ECHO":
        return " ".join(args)
    if cmd == "SET":
        DATA[args[0]] = args[1]
        return "OK"
    if cmd == "GET":
        return DATA.get(args[0], "(nil)")
    if cmd == "DEL":
        if args[0] in DATA:
            del DATA[args[0]]
            return "1"
        return "0"
    if cmd == "KEYS":
        return "\n".join(sorted(DATA)) or "(empty)"
```

```ticket
"""Ledger's storage engine. The only code that touches the data."""


class Store:
    def __init__(self):
        self.data = {}

    def set(self, key, value):
        self.data[key] = value

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        if key not in self.data:
            return False
        del self.data[key]
        return True

    def keys(self):
        return sorted(self.data)

    def incr(self, key):
        value = self.data.get(key, "0")
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n
```

```ticket
id: t4
title: Survive a restart
files: log.py, store.py, shell.py
---brief
Press **Restart** in the terminal: every key is gone, because `data` lived in memory. Fix it with an **append-only log** in a new file, log.py:

- `Log(path)` remembers the file name.
- `log.append(record)` adds one record, a list like `["SET", "views", "42"]`, as one line of JSON at the end of the file. Flush it and `os.fsync` it before returning.
- `log.read()` returns every record in the file, oldest first (an empty list if the file doesn't exist yet).

Then `Store(log)` takes an optional log. When it has one, it **replays** every record at start-up, and writes each change to the log *before* changing `data`. In shell.py, open it as `db = Store(Log("ledger.log"))`.
---why
Memory is fast and forgets. Disk remembers. An append-only log is the simplest way to make a database **durable**: you never rewrite old bytes, you only add a line, so a write is one quick operation. To rebuild the state, you replay the log from the top. Redis's AOF, Kafka, and the write-ahead log in Postgres and SQLite all start from this idea. `fsync` matters: without it, "written" can still mean "sitting in the OS's memory".
---picture
  SET a 1   ─▶  ledger.log  ["SET","a","1"]
  SET b 2   ─▶              ["SET","b","2"]
  DEL a     ─▶              ["DEL","a"]
                     │
   restart ──replay top to bottom──▶  data = {"b": "2"}

"""Ledger's append-only log: every change, one JSON line each, oldest first."""
import json
import os


class Log:
    def __init__(self, path):
        self.path = path

    def append(self, record):
        with open(self.path, "a", encoding="utf-8") as fh:
            fh.write(json.dumps(record) + "\n")
            fh.flush()
            os.fsync(fh.fileno())

    def read(self):
        if not os.path.exists(self.path):
            return []
        with open(self.path, encoding="utf-8") as fh:
            return [json.loads(line) for line in fh if line.strip()]
---solution store.py
"""Ledger's storage engine. The only code that touches the data."""


class Store:
    def __init__(self, log=None):
        self.data = {}
        self.log = log
        if log is not None:
            for record in log.read():
                self.apply(record)

    def apply(self, record):
        """Change data for one record. Used both live and when replaying the log."""
        op, key, *rest = record
        if op == "SET":
            self.data[key] = rest[0]
        elif op == "DEL":
            self.data.pop(key, None)

    def write(self, *record):
        """Log first, then change memory: if we crash in between, the log still has it."""
        if self.log is not None:
            self.log.append(list(record))
        self.apply(list(record))

    def set(self, key, value):
        self.write("SET", key, value)

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        if key not in self.data:
            return False
        self.write("DEL", key)
        return True

    def keys(self):
        return sorted(self.data)

    def incr(self, key):
        value = self.data.get(key, "0")
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n
```

```ticket
id: t5
title: Pull the plug mid-write
files: log.py
---brief
Type a few `SET`s, then press **⚡ Pull the plug**. It kills Ledger halfway through writing its last line, the way a power cut would, and starts it again. It won't start: `json.loads` chokes on half a record.

Make the log crash-safe:

- Each line becomes `crc json`: the CRC-32 of the JSON text as 8 hex digits, a space, then the JSON. `zlib.crc32(body.encode())` gives the number; `f"{n:08x}"` formats it.
- When reading, stop at the first line that is torn: no newline at the end, or a CRC that doesn't match. Every record before it is good.
- Cut the file back to the end of the last good line, so the next append starts on a clean line instead of being glued onto the garbage.
---why
A disk writes in pieces, and power can go between any two of them. """Ledger's storage engine. The only code that touches the data."""
```


```ticket
class Store:
    def __init__(self, log=None):
        self.data = {}
        self.log = log
        self.count = 0  # records in the log
        if log is not None:
            for record in log.read():
                self.apply(record)
                self.count += 1

    def apply(self, record):
        """Change data for one record. Used both live and when replaying the log."""
        op, key, *rest = record
        if op == "SET":
            self.data[key] = rest[0]
        elif op == "DEL":
            self.data.pop(key, None)

    def write(self, *record):
        """Log first, then change memory: if we crash in between, the log still has it."""
        if self.log is not None:
            self.log.append(list(record))
            self.count += 1
        self.apply(list(record))

    def set(self, key, value):
        self.write("SET", key, value)

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        if key not in self.data:
            return False
        self.write("DEL", key)
        return True

    def keys(self):
        return sorted(self.data)

    def incr(self, key):
        value = self.data.get(key, "0")
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n

    def compact(self):
        """Rewrite the log as one SET per live key. Returns (records before, records after)."""
        records = [["SET", key, self.data[key]] for key in self.keys()]
        before = self.count
        if self.log is not None:
            self.log.rewrite(records)
        self.count = len(records)
        return before, self.count
```

```ticket
"""Ledger's storage engine. The only code that touches the data."""
import math
import time


class Store:
    def __init__(self, log=None, clock=time.time):
        self.data = {}
        self.expires = {}  # key -> the moment it dies, in clock seconds
        self.clock = clock
        self.log = log
        self.count = 0  # records in the log
        if log is not None:
            for record in log.read():
                self.apply(record)
                self.count += 1

    def apply(self, record):
        """Change data for one record. Used both live and when replaying the log."""
        op, key, *rest = record
        if op == "SET":
            self.data[key] = rest[0]
            self.expires.pop(key, None)
        elif op == "DEL":
            self.data.pop(key, None)
            self.expires.pop(key, None)
        elif op == "EXPIRE":
            if key in self.data:
                self.expires[key] = rest[0]

    def write(self, *record):
        """Log first, then change memory: if we crash in between, the log still has it."""
        if self.log is not None:
            self.log.append(list(record))
            self.count += 1
        self.apply(list(record))

    def alive(self, key):
        """Is the key here? A key past its deadline is dropped the moment someone looks.
        Nothing is logged: replaying its SET and EXPIRE gives the same deadline, so it dies again."""
        deadline = self.expires.get(key)
        if deadline is not None and deadline <= self.clock():
            del self.data[key]
            del self.expires[key]
        return key in self.data

    def set(self, key, value):
        self.write("SET", key, value)

    def get(self, key):
        return self.data[key] if self.alive(key) else None

    def delete(self, key):
        if not self.alive(key):
            return False
        self.write("DEL", key)
        return True

    def keys(self):
        return [key for key in sorted(self.data) if self.alive(key)]

    def incr(self, key):
        value = self.data[key] if self.alive(key) else "0"
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n

    def expire(self, key, seconds):
        if not self.alive(key):
            return False
        self.write("EXPIRE", key, self.clock() + seconds)
        return True

    def ttl(self, key):
        if not self.alive(key):
            return -2
        deadline = self.expires.get(key)
        return -1 if deadline is None else math.ceil(deadline - self.clock())

    def compact(self):
        """Rewrite the log as one SET per live key, plus its deadline. Returns (records before, records after)."""
        records = []
        for key in self.keys():
            records.append(["SET", key, self.data[key]])
            if key in self.expires:
                records.append(["EXPIRE", key, self.expires[key]])
        before = self.count
        if self.log is not None:
            self.log.rewrite(records)
        self.count = len(records)
        return before, self.count
```

```ticket
---brief
Moving money is two writes: take 10 from one balance, add 10 to the other. Pull the plug between them and the money is gone. Add **transactions**:

| Command | Reply |
|---|---|
| `MULTI` | `OK`, and start queueing. Inside, `MULTI` again answers `ERR MULTI calls can not be nested` |
| any other command, inside | `QUEUED`. Nothing runs yet, not even reads |
| `EXEC` | run the queue in order and answer each reply numbered, one per line: `1) OK`, `2) 42`. An empty queue answers `(empty)` |
| `DISCARD` | `OK`, and drop the queue |

- `EXEC` or `DISCARD` outside a transaction: `ERR EXEC without MULTI` (or `DISCARD`).
- A command that's wrong while queueing (unknown, or the wrong number of arguments) answers its error as usual and spoils the transaction: `EXEC` then answers `EXECABORT Transaction discarded because of previous errors` and runs nothing.
- **The point:** the whole transaction is **one record** in the log, `["TX", [record, record, …]]`. Give `Store` a `begin()` that starts holding records back and a `commit()` that writes them as one. A crash tears one line, and with it the whole transaction, so you get all the writes or none.
---why
That's the **A** in ACID: atomicity. The log from ticket 5 already drops a torn line whole, so wrapping several writes in one line makes them land together for free. Real databases do the same with a commit record: Postgres writes a transaction's changes to its WAL, and only the final commit record makes them count. Queueing first also means a typo in the third command can't leave the first two half-done.

---hint
In `Store`, `begin()` sets `self.batch = []`. `write` appends to `batch` when it isn't `None`, instead of logging. `commit()` writes `["TX", batch]` with one `log.append` and resets `batch` to `None`. In `apply`, a record whose first item is `"TX"` applies each record inside it.
---solution store.py
"""Ledger's storage engine. The only code that touches the data."""
import math
import time


class Store:
    def __init__(self, log=None, clock=time.time):
        self.data = {}
        self.expires = {}  # key -> the moment it dies, in clock seconds
        self.clock = clock
        self.log = log
        self.count = 0  # records in the log
        self.batch = None  # a list while a transaction is running
        if log is not None:
            for record in log.read():
                self.apply(record)
                self.count += 1

    def apply(self, record):
        """Change data for one record. Used both live and when replaying the log."""
        if record[0] == "TX":
            for inner in record[1]:
                self.apply(inner)
            return
        op, key, *rest = record
        if op == "SET":
            self.data[key] = rest[0]
            self.expires.pop(key, None)
        elif op == "DEL":
            self.data.pop(key, None)
            self.expires.pop(key, None)
        elif op == "EXPIRE":
            if key in self.data:
                self.expires[key] = rest[0]

    def write(self, *record):
        """Log first, then change memory. Inside a transaction, hold the record back for commit()."""
        record = list(record)
        if self.batch is not None:
            self.batch.append(record)
        elif self.log is not None:
            self.log.append(record)
            self.count += 1
        self.apply(record)

    def begin(self):
        self.batch = []

    def commit(self):
        """Write the whole transaction as one record: a crash keeps all of it or none."""
        records, self.batch = self.batch, None
        if records and self.log is not None:
            self.log.append(["TX", records])
            self.count += 1

    def alive(self, key):
        """Is the key here? A key past its deadline is dropped the moment someone looks.
        Nothing is logged: replaying its SET and EXPIRE gives the same deadline, so it dies again."""
        deadline = self.expires.get(key)
        if deadline is not None and deadline <= self.clock():
            del self.data[key]
            del self.expires[key]
        return key in self.data

    def set(self, key, value):
        self.write("SET", key, value)

    def get(self, key):
        return self.data[key] if self.alive(key) else None

    def delete(self, key):
        if not self.alive(key):
            return False
        self.write("DEL", key)
        return True

    def keys(self):
        return [key for key in sorted(self.data) if self.alive(key)]

    def incr(self, key):
        value = self.data[key] if self.alive(key) else "0"
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n

    def expire(self, key, seconds):
        if not self.alive(key):
            return False
        self.write("EXPIRE", key, self.clock() + seconds)
        return True

    def ttl(self, key):
        if not self.alive(key):
            return -2
        deadline = self.expires.get(key)
        return -1 if deadline is None else math.ceil(deadline - self.clock())

    def compact(self):
        """Rewrite the log as one SET per live key, plus its deadline. Returns (records before, records after)."""
        records = []
        for key in self.keys():
            records.append(["SET", key, self.data[key]])
            if key in self.expires:
                records.append(["EXPIRE", key, self.expires[key]])
        before = self.count
        if self.log is not None:
            self.log.rewrite(records)
        self.count = len(records)
        return before, self.count

"""Ledger's shell: the terminal sends each line to handle(line), and prints what it returns."""
from log import Log
from store import Store

db = Store(Log("ledger.log"))

# How many arguments each command takes (None: any number).
ARITY = {"PING": 0, "ECHO": None, "SET": 2, "GET": 1, "DEL": 1, "KEYS": 0, "INCR": 1, "COMPACT": 0,
         "EXPIRE": 2, "TTL": 1, "MULTI": 0, "EXEC": 0, "DISCARD": 0}

QUEUE = None     # None outside a transaction; the queued (cmd, args) inside one
ABORTED = False  # a bad command was queued, so EXEC must refuse


def tokenize(line):
    """Split a command line into words. Double quotes keep spaces inside one word."""
    words, word = [], ""
    quoted = started = False
    for ch in line:
        if ch == '"':
            quoted = not quoted
            started = True
        elif ch == " " and not quoted:
            if started:
                words.append(word)
            word, started = "", False
        else:
            word += ch
            started = True
    if quoted:
        raise ValueError("unclosed quote")
    if started:
        words.append(word)
    return words


def handle(line):
    global QUEUE, ABORTED
    try:
        words = tokenize(line)
    except ValueError as e:
        return f"ERR {e}"
    if not words:
        return None
    cmd, args = words[0].upper(), words[1:]
    error = None
    if cmd not in ARITY:
        error = f"ERR unknown command '{words[0]}'"
    elif ARITY[cmd] is not None and len(args) != ARITY[cmd]:
        error = f"ERR wrong number of arguments for '{cmd.lower()}'"
    if QUEUE is not None and cmd not in ("MULTI", "EXEC", "DISCARD"):
        if error:
            ABORTED = True
            return error
        QUEUE.append((cmd, args))
        return "QUEUED"
    if error:
        return error
    if cmd == "MULTI":
        if QUEUE is not None:
            return "ERR MULTI calls can not be nested"
        QUEUE, ABORTED = [], False
        return "OK"
    if cmd == "DISCARD":
        if QUEUE is None:
            return "ERR DISCARD without MULTI"
        QUEUE = None
        return "OK"
    if cmd == "EXEC":
        if QUEUE is None:
            return "ERR EXEC without MULTI"
        queued, QUEUE = QUEUE, None
        if ABORTED:
            return "EXECABORT Transaction discarded because of previous errors"
        if not queued:
            return "(empty)"
        db.begin()
        try:
            replies = [execute(c, a) for c, a in queued]
        finally:
            db.commit()
        return "\n".join(f"{i}) {r}" for i, r in enumerate(replies, 1))
    return execute(cmd, args)


def execute(cmd, args):
    """Run one command whose arguments have already been checked."""
    if cmd == "PING":
        return "PONG"
    if cmd == "ECHO":
        return " ".join(args)
    if cmd == "SET":
        db.set(args[0], args[1])
        return "OK"
    if cmd == "GET":
        value = db.get(args[0])
        return "(nil)" if value is None else value
    if cmd == "DEL":
        return "1" if db.delete(args[0]) else "0"
    if cmd == "KEYS":
        return "\n".join(db.keys()) or "(empty)"
    if cmd == "INCR":
        try:
            return str(db.incr(args[0]))
        except ValueError as e:
            return f"ERR {e}"
    if cmd == "COMPACT":
        before, after = db.compact()
        return f"compacted {before} records into {after}"
    if cmd == "EXPIRE":
        if not args[1].isdigit():
            return "ERR value is not an integer"
        return "1" if db.expire(args[0], int(args[1])) else "0"
    if cmd == "TTL":
        return str(db.ttl(args[0]))
```
