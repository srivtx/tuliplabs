Ledger is a small database in the spirit of Redis. You talk to it in a terminal. `SET` stores a value, `GET` reads it, and it remembers everything even after the program is killed in the middle of a write.

You'll write it in three files, the way a real one is laid out: **shell.py** speaks the protocol, **store.py** owns the data and **log.py** keeps it safe on disk. Every ticket adds one part, and the map on the right lights it up.

```ticket
---brief
The terminal hands your program one line at a time: `handle(line)` gets the text and returns the reply.
`handle` is already written. It answers `PING` and `ECHO`. What it needs is **`tokenize(line)`**, which splits the line into words.

Spaces separate words, except inside double quotes. `ECHO "hello world" again` is three words: `ECHO`, `hello world` and `again`. The quotes themselves are not part of the word. A quote that never closes is an error: raise `ValueError("unclosed quote")` and `handle` turns it into `ERR unclosed quote`.

Every tool that reads commands starts here: shells, SQL, Redis, git. `line.split()` looks right until somebody stores a value with a space in it. Walking the line one character at a time, remembering whether you're inside quotes, is the smallest real **lexer**, and you'll write bigger ones later.
```

```ticket
---brief
Now Ledger stores data. Add four commands to `handle`, keeping everything in a dictionary called `DATA` at the top of shell.py:

| Command | Reply |
|---|---|
| `SET key value` | `OK` |
| `GET key` | the value, or `(nil)` if there's no such key |
| `DEL key` | `1` if it deleted something, `0` if not |
| `KEYS` | every key, sorted, one per line, or `(empty)` |

A **protocol** is a promise: every command has a fixed shape and one reply. Checking the argument count *before* doing anything means a typo can never half-run a command. Redis keeps a table of each command's arity for exactly this reason, and so will you.

          DATA["name"] = "tulip"  ──▶  OK

"""Ledger's shell: the terminal sends each line to handle(line), and prints what it returns."""

DATA = {}

# How many arguments each command takes (None: any number).
ARITY = {"PING": 0, "ECHO": None, "SET": 2, "GET": 1, "DEL": 1, "KEYS": 0}


def tokenize(line):
    """Split a command line into words. Double quotes keep spaces inside one word."""
    words, word = [], ""
    quoted = started = False
    for ch in line:
        if ch == '"':
            quoted = not quoted
            started = True
        elif ch == " " and not quoted:
            if started:
                words.append(word)
            word, started = "", False
        else:
            word += ch
            started = True
    if quoted:
        raise ValueError("unclosed quote")
    if started:
        words.append(word)
    return words


def handle(line):
    try:
        words = tokenize(line)
    except ValueError as e:
        return f"ERR {e}"
    if not words:
        return None
    cmd, args = words[0].upper(), words[1:]
    if cmd not in ARITY:
        return f"ERR unknown command '{words[0]}'"
    if ARITY[cmd] is not None and len(args) != ARITY[cmd]:
        return f"ERR wrong number of arguments for '{cmd.lower()}'"
    if cmd == "PING":
        return "PONG"
    if cmd == "ECHO":
        return " ".join(args)
    if cmd == "SET":
        DATA[args[0]] = args[1]
        return "OK"
    if cmd == "GET":
        return DATA.get(args[0], "(nil)")
    if cmd == "DEL":
        if args[0] in DATA:
            del DATA[args[0]]
            return "1"
        return "0"
    if cmd == "KEYS":
        return "\n".join(sorted(DATA)) or "(empty)"
```

```ticket
Right now any line of shell.py can reach into `DATA`. Move the data into its own object: a **`Store`** class in a new file, store.py. Its methods are the only way in:

The shell only *speaks*; the store *owns*. Real databases split the same way: a network layer that parses, and a storage engine behind it.

"""Ledger's storage engine. The only code that touches the data."""


class Store:
    def __init__(self):
        self.data = {}

    def set(self, key, value):
        self.data[key] = value

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        if key not in self.data:
            return False
        del self.data[key]
        return True

    def keys(self):
        return sorted(self.data)

    def incr(self, key):
        value = self.data.get(key, "0")
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n
```

```ticket
id: t4
title: Survive a restart
files: log.py, store.py, shell.py
---brief
Press **Restart** in the terminal: every key is gone, because `data` lived in memory. Fix it with an **append-only log** in a new file, log.py:

- `Log(path)` remembers the file name.
- `log.append(record)` adds one record, a list like `["SET", "views", "42"]`, as one line of JSON at the end of the file. Flush it and `os.fsync` it before returning.
- `log.read()` returns every record in the file, oldest first (an empty list if the file doesn't exist yet).

Then `Store(log)` takes an optional log. When it has one, it **replays** every record at start-up, and writes each change to the log *before* changing `data`. In shell.py, open it as `db = Store(Log("ledger.log"))`.
---why
Memory is fast and forgets. Disk remembers. An append-only log is the simplest way to make a database **durable**: you never rewrite old bytes, you only add a line, so a write is one quick operation. To rebuild the state, you replay the log from the top. Redis's AOF, Kafka, and the write-ahead log in Postgres and SQLite all start from this idea. `fsync` matters: without it, "written" can still mean "sitting in the OS's memory".
---picture
  SET a 1   ─▶  ledger.log  ["SET","a","1"]
  SET b 2   ─▶              ["SET","b","2"]
  DEL a     ─▶              ["DEL","a"]
                     │
   restart ──replay top to bottom──▶  data = {"b": "2"}

"""Ledger's append-only log: every change, one JSON line each, oldest first."""
import json
import os


class Log:
    def __init__(self, path):
        self.path = path

    def append(self, record):
        with open(self.path, "a", encoding="utf-8") as fh:
            fh.write(json.dumps(record) + "\n")
            fh.flush()
            os.fsync(fh.fileno())

    def read(self):
        if not os.path.exists(self.path):
            return []
        with open(self.path, encoding="utf-8") as fh:
            return [json.loads(line) for line in fh if line.strip()]
---solution store.py
"""Ledger's storage engine. The only code that touches the data."""


class Store:
    def __init__(self, log=None):
        self.data = {}
        self.log = log
        if log is not None:
            for record in log.read():
                self.apply(record)

    def apply(self, record):
        """Change data for one record. Used both live and when replaying the log."""
        op, key, *rest = record
        if op == "SET":
            self.data[key] = rest[0]
        elif op == "DEL":
            self.data.pop(key, None)

    def write(self, *record):
        """Log first, then change memory: if we crash in between, the log still has it."""
        if self.log is not None:
            self.log.append(list(record))
        self.apply(list(record))

    def set(self, key, value):
        self.write("SET", key, value)

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        if key not in self.data:
            return False
        self.write("DEL", key)
        return True

    def keys(self):
        return sorted(self.data)

    def incr(self, key):
        value = self.data.get(key, "0")
        if not value.lstrip("-").isdigit():
            raise ValueError("value is not an integer")
        n = int(value) + 1
        self.set(key, str(n))
        return n
```

```ticket
id: t5
title: Pull the plug mid-write
files: log.py
---brief
Type a few `SET`s, then press **⚡ Pull the plug**. It kills Ledger halfway through writing its last line, the way a power cut would, and starts it again. It won't start: `json.loads` chokes on half a record.

Make the log crash-safe:

- Each line becomes `crc json`: the CRC-32 of the JSON text as 8 hex digits, a space, then the JSON. `zlib.crc32(body.encode())` gives the number; `f"{n:08x}"` formats it.
- When reading, stop at the first line that is torn: no newline at the end, or a CRC that doesn't match. Every record before it is good.
- Cut the file back to the end of the last good line, so the next append starts on a clean line instead of being glued onto the garbage.
---why
A disk writes in pieces, and power can go between any two of them. A database has to tell *"the last write didn't finish"* from *"the data is fine"*, and the only honest answer is a checksum: the record proves itself. Dropping the torn tail is safe because that write was never acknowledged, so nobody was told `OK`. The cut-back step is the part people forget: without it, the next record is glued to half a line and is lost too.

---hint
Read the file in binary (`"rb"`) so you can count bytes exactly: keep `good`, the byte offset just after the last good line. Decode each line with `line.decode("utf-8")`.
---hint
A line is good only if it ends with `b"\n"` and its first 8 characters equal the CRC of the rest after the space. Wrap `json.loads` in `try` too: a damaged line can fail to parse.
---hint
After the loop: if `good < os.path.getsize(self.path)`, open the file with `"r+b"` and call `fh.truncate(good)`.
---solution log.py
"""Ledger's append-only log: every change, one line each, oldest first.
Each line is `crc json`, so a record torn by a crash can be told from a good one."""
import json
import os
import zlib


def encode(record):
    body = json.dumps(record)
    return f"{zlib.crc32(body.encode()):08x} {body}\n"


def decode(line):
    """The record on one line (bytes), or None if the line is torn or damaged."""
    if not line.endswith(b"\n"):
        return None
    crc, _, body = line.decode("utf-8", "replace").rstrip("\n").partition(" ")
    if crc != f"{zlib.crc32(body.encode()):08x}":
        return None
    try:
        return json.loads(body)
    except ValueError:
        return None


class Log:
    def __init__(self, path):
        self.path = path

    def append(self, record):
        with open(self.path, "a", encoding="utf-8") as fh:
            fh.write(encode(record))
            fh.flush()
            os.fsync(fh.fileno())

    def read(self):
        if not os.path.exists(self.path):
            return []
        records, good = [], 0
        with open(self.path, "rb") as fh:
            for line in fh:
                record = decode(line)
                if record is None:
                    break
                records.append(record)
                good += len(line)
        if good < os.path.getsize(self.path):
            with open(self.path, "r+b") as fh:
                fh.truncate(good)
        return records
```
