## A board full of coin flips

Drop a ball onto a board of pegs. At every peg it goes left or right at random. Where does it land? You can't say for one ball. But drop a few hundred and a very definite **shape** appears, and you can predict that shape before dropping a single ball.

```viz
name: ps-galton
title: The Galton board
goal: Tilt the board (set **p** at least 0.1 away from 0.5), drop **500** balls, and get your pile to match the formula's ghosts within 6%.
height: 440
Each ball goes right at each peg with probability **p**. The bin it lands in is the number of rights. Amber ghosts are what the binomial formula predicts. Click anything to ask why.
```

```quiz
With p = 0.5 and 10 rows, why do so many balls land in the middle bin (5 rights) and so few at the edges (0 or 10 rights)?
- The pegs in the middle are bigger
- Balls bounce toward the centre
* Only one route gives 0 rights (left every time), but 252 different routes give exactly 5 rights
- It's luck; with more balls it would even out
> Every single route is equally likely when p = 0.5. The middle bin wins because **far more routes** end there. Counting those routes is what the binomial formula does.
```

## A random variable is just a number from an outcome

Flip 3 coins. The **outcome** is something like `HTH`. A **random variable** is any number you compute from the outcome: the number of heads (2), whether the first is heads (1), the longest run (1). Calling it X and asking "what values can X take, and how often?" is the whole game.

```predict
from itertools import product
outcomes = list(product("HT", repeat=3))
heads = [o.count("H") for o in outcomes]
print(len(outcomes))
print(sorted(heads))
print({k: heads.count(k) for k in range(4)})
```

The table of "value → probability" is the variable's **distribution**. For a variable with separate values, it's called the **PMF** (probability mass function). Its running total, P(X ≤ x), is the **CDF** (cumulative distribution function). The CDF is handy because any range is a subtraction: P(a < X ≤ b) = CDF(b) − CDF(a).

```exercise
title: pmf_cdf
kind: write
---prompt
Write `pmf_cdf(samples)` for a list of whole numbers. Return two dicts with the same sorted keys (every distinct value): `pmf[v]` is the fraction of samples equal to `v`, and `cdf[v]` is the fraction **less than or equal to** `v`.
---starter
def pmf_cdf(samples):
    pmf, cdf = {}, {}
    return pmf, cdf
---solution
def pmf_cdf(samples):
    n = len(samples)
    values = sorted(set(samples))
    pmf = {v: samples.count(v) / n for v in values}
    cdf, running = {}, 0.0
    for v in values:
        running += pmf[v]
        cdf[v] = running
    return pmf, cdf
---tests
pmf, cdf = pmf_cdf([0, 1, 1, 2, 2, 2, 3, 3])
assert list(pmf) == [0, 1, 2, 3], "one key per distinct value, sorted"
assert pmf[2] == 3 / 8, f"three of the eight samples are 2; got {pmf[2]}"
assert cdf[1] == 3 / 8 and abs(cdf[3] - 1) < 1e-12, "CDF(1) counts 0s and 1s; the CDF ends at 1"
assert abs((cdf[3] - cdf[1]) - (pmf[2] + pmf[3])) < 1e-12, "a range is a difference of two CDF values"
---hint
Build the PMF with `samples.count(v) / n`, then walk the sorted values keeping a running total for the CDF.
```

## The binomial: counting the routes

The Galton board is **n independent yes/no trials** with the same chance **p** of "yes" each time (a **Bernoulli** trial). The number of yeses follows the **binomial** distribution:

    P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ

Read it as a sentence: *the number of routes with k yeses* × *the chance of any one such route*. `C(n, k)` ("n choose k", `math.comb(n, k)`) counts the routes; `pᵏ(1−p)ⁿ⁻ᵏ` is the chance of each one, because the trials are independent and their probabilities multiply.

It fits whenever all four hold: a fixed number of trials, two outcomes each, the same p, and independence. Free-throw makes, defective items in a batch, and patients who respond to a drug are all binomial.

```parsons
title: The binomial PMF
---lines
def binom_pmf(k, n, p):
    routes = math.comb(n, k)
    one_route = p ** k * (1 - p) ** (n - k)
    return routes * one_route
?? one_route = p ** n * (1 - p) ** k
---tests
assert abs(binom_pmf(5, 10, 0.5) - 252 / 1024) < 1e-12, "C(10,5)/2^10"
assert abs(sum(binom_pmf(k, 7, 0.3) for k in range(8)) - 1) < 1e-12, "a PMF sums to 1"
```

```exercise
title: at_least
kind: write
---prompt
A basketball player makes 70% of free throws. Write `at_least(k, n, p)`: the probability of **at least** `k` makes in `n` independent shots, by adding up binomial probabilities with `math.comb`. Then check yourself against `stats.binom.sf(k - 1, n, p)` (which the tests do).
---starter
def at_least(k, n, p):
    return 0.0
---solution
def at_least(k, n, p):
    return sum(math.comb(n, j) * p ** j * (1 - p) ** (n - j) for j in range(k, n + 1))
---tests
assert abs(at_least(8, 10, 0.7) - stats.binom.sf(7, 10, 0.7)) < 1e-12, "at least 8 of 10 at 70%: about 0.383"
assert abs(at_least(0, 5, 0.3) - 1) < 1e-12, "at least 0 makes is certain"
assert at_least(10, 10, 0.7) == 0.7 ** 10, "all 10: just 0.7^10"
---hint
"At least k" means k, k+1, …, n. Add the binomial probability for each.
```

## Waiting for something: geometric and Poisson

Two more counting distributions come up constantly:

- **Geometric:** how many tries until the first success? (Rolls until a six, calls until a sale.) P(first success on try k) = (1 − p)ᵏ⁻¹ · p. Its average is 1/p.
- **Poisson:** how many events in a fixed window, when they happen independently at an average rate λ? (Calls per minute, typos per page, goals per match.) P(X = k) = λᵏ e^(−λ) / k!. Its average and its variance are both λ.

```predict
print(round(stats.poisson.pmf(0, 3), 4))
print(round(stats.poisson.pmf(3, 3), 4))
print(round(stats.geom.mean(1 / 6), 2))
```

```exercise
title: rolls_until_six
kind: write
---prompt
Write `rolls_until_six(trials, seed=0)`: simulate `trials` experiments of rolling a fair die until the first six (use `rng = np.random.default_rng(seed)` and `rng.integers(1, 7)`), and return the **average** number of rolls needed. The geometric distribution says it should be close to 6.
---starter
def rolls_until_six(trials, seed=0):
    rng = np.random.default_rng(seed)
    return 0.0
---solution
def rolls_until_six(trials, seed=0):
    rng = np.random.default_rng(seed)
    total = 0
    for _ in range(trials):
        rolls = 1
        while rng.integers(1, 7) != 6:
            rolls += 1
        total += rolls
    return total / trials
---tests
avg = rolls_until_six(20000)
assert abs(avg - 6) < 0.15, f"on average a six takes 1/p = 6 rolls; got {avg:.3f}"
assert rolls_until_six(1, seed=3) >= 1, "it always takes at least one roll"
---hint
For each trial, count rolls in a `while` loop that stops when you roll a 6.
```

## Continuous variables: probability is area

Heights, times and temperatures can take any value in a range. Then the chance of hitting one **exact** value, like exactly 1.500000… m, is **zero**: there are infinitely many neighbours sharing the probability. Instead, a **PDF** (probability density function) is a curve, and the probability of a range is the **area** under it. The CDF still works the same way.

The three you'll meet most:

| Distribution | Shape | Typical use |
|---|---|---|
| uniform(a, b) | flat | a random point in a range |
| exponential(rate λ) | high at 0, decaying | waiting time between Poisson events |
| normal(μ, σ) | the bell | sums of many small effects (chapter 6) |

```quiz
Bus waits are exponential with an average of 10 minutes. You've already waited 10 minutes. How long do you expect to wait now?
- 0 minutes: it's due
- 5 minutes
* 10 more minutes: the exponential has no memory
- 20 minutes
> The exponential is **memoryless**: P(wait > s + t | waited s) = P(wait > t). If buses truly arrive like a Poisson process, the time you've already waited tells you nothing. (Real buses on a timetable aren't like this, which is why the model choice matters.)
```

```exercise
title: between
kind: fill
---prompt
Adult heights in a population are normal with mean 170 cm and standard deviation 8 cm. Fill in `between(a, b)` to return P(a < height < b) using the CDF.
---starter
def between(a, b):
    dist = stats.norm(170, 8)
    return ____
---solution
def between(a, b):
    dist = stats.norm(170, 8)
    return dist.cdf(b) - dist.cdf(a)
---tests
assert abs(between(162, 178) - 0.6827) < 1e-3, "within one standard deviation: about 68%"
assert abs(between(170, 1000) - 0.5) < 1e-9, "above the mean: half"
assert between(175, 175) == 0, "the chance of one exact value is 0"
---hint
The area between a and b is the CDF at b minus the CDF at a.
```

## Real-world project: staffing a call centre

```project
title: How many agents for the lunchtime rush?
client: A bank's customer-support call centre
skills: Poisson distribution, survival function, choosing a risk level, simulation checks
---brief
Calls arrive at random, averaging 18 per 10-minute block over lunch. One agent can handle 4 calls per block. Management wants the **fewest agents** such that the chance of getting more calls than the team can handle in a block is at most 5%. Model calls per block as Poisson, find the answer with `stats.poisson`, then check it by simulating a month of lunch blocks.
---why
"Enough capacity for all but the worst 5% of minutes" is how call centres, cloud autoscalers, hospital emergency rooms and even bakeries plan. The Poisson model is the standard starting point for arrivals of independent events, and picking the risk level (5%? 1%?) is a business decision the maths makes explicit.
---milestones
- Check the Poisson assumption: are calls independent and at a steady rate over lunch?
- Write `overflow_risk(agents, rate, per_agent)` with `stats.poisson.sf`
- Write `agents_needed(rate, per_agent, risk)` by trying 1, 2, 3, … agents
- Simulate 1,000 lunch blocks with `rng.poisson` and count overflows to confirm
- Report how the answer changes for 1% risk and for a 20% busier day
---stretch
- Compare with the naive answer "average / capacity" and explain the gap
- Model calls that can wait for the next block (a queue, like ModSim chapter 10)
- Use real-looking data: a rate that rises and falls over the day
```

```exercise
title: agents_needed
kind: write
---prompt
Write `agents_needed(rate, per_agent, risk)`: with calls per block ~ Poisson(`rate`), return the smallest number of agents `a` (starting from 1) such that P(calls > a × per_agent) ≤ `risk`. Use `stats.poisson.sf(x, rate)`, which gives P(calls > x).
---starter
def agents_needed(rate, per_agent, risk):
    return math.ceil(rate / per_agent)
---solution
def agents_needed(rate, per_agent, risk):
    a = 1
    while stats.poisson.sf(a * per_agent, rate) > risk:
        a += 1
    return a
---tests
a = agents_needed(18, 4, 0.05)
assert a == 7, f"the average needs only 4.5 agents, but covering 95% of blocks takes 7; got {a}"
assert stats.poisson.sf(a * 4, 18) <= 0.05 < stats.poisson.sf((a - 1) * 4, 18), "7 is enough and 6 isn't"
assert agents_needed(18, 4, 0.01) > a, "a stricter risk needs more agents"
---hint
Loop `a = 1, 2, 3, …` until `stats.poisson.sf(a * per_agent, rate) <= risk`.
```

## Rebuild it and explain it

```exercise
title: binomial_table
kind: rebuild
---prompt
From memory: write `binomial_table(n, p)` returning a list whose entry `k` is P(X = k) for a binomial(n, p) variable, for k = 0 … n, using `math.comb`.
---starter
def binomial_table(n, p):
    pass
---solution
def binomial_table(n, p):
    return [math.comb(n, k) * p ** k * (1 - p) ** (n - k) for k in range(n + 1)]
---tests
t = binomial_table(4, 0.5)
assert t == [1 / 16, 4 / 16, 6 / 16, 4 / 16, 1 / 16], f"4 coins: 1, 4, 6, 4, 1 routes out of 16; got {t}"
assert abs(sum(binomial_table(9, 0.3)) - 1) < 1e-12, "probabilities add to 1"
---hint
Routes times the chance of one route, for each k.
```

```recall
Q: Explain the binomial formula C(n, k) pᵏ (1−p)ⁿ⁻ᵏ using the Galton board, and say when you'd use Poisson instead.
A: Each peg is a yes/no trial with chance p of "right". A ball's bin is its number of rights k. Any single route with k rights and n−k lefts has probability pᵏ(1−p)ⁿ⁻ᵏ because independent chances multiply, and there are C(n, k) such routes, so you multiply the two. Use Poisson when there's no fixed number of trials, just events happening independently at a steady average rate λ in a window of time or space (calls per minute, typos per page).
```
