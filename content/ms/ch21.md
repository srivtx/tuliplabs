## The drag equation

Moving through air, an object pushes air aside and feels a force opposite to its motion:

F_drag = ½ · ρ · v² · C_d · A

- ρ (rho): air density, about 1.2 kg/m³
- v: speed (drag grows with its **square**)
- C_d: the **drag coefficient**, set by shape (measured, not derived)
- A: the cross-sectional area facing the air

As the penny speeds up, drag grows until it equals gravity's pull. Then acceleration is zero and the speed stays constant: **terminal velocity**.

```quiz
If you double an object's speed, what happens to its drag force?
- It doubles
* It quadruples
- It halves
- Nothing; drag depends only on shape
> Drag is proportional to v², so 2× the speed gives 4× the force. That's why terminal velocity arrives fairly quickly for light objects.
```

## From terminal velocity to C_d

Measurements say a penny's terminal velocity is about **18 m/s**. At terminal velocity drag equals weight: ½ρv²C_dA = m·g. Solve for C_d.

```exercise
title: drag coefficient from terminal velocity
kind: write
---prompt
Write `drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8)`: the area is that of a circle with the given diameter; return `2 * mass * g / (rho * area * v_term**2)`.
---starter
def drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8):
    pass
---solution
def drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8):
    area = pi * (diameter / 2) ** 2
    return 2 * mass * g / (rho * area * v_term**2)
---tests
c = drag_coefficient(2.5e-3, 19e-3, 18)
assert abs(c - 0.444) < 0.005, f"A penny (2.5 g, 19 mm, 18 m/s): C_d about 0.44, got {c:.3f}"
assert abs(drag_coefficient(1, 1, 1, rho=1, g=1) - 2 / (pi / 4)) < 1e-12, "Check the area: pi * (d/2)**2"
```

```predict
rho, C_d, area, v = 1.2, 0.44, pi * 0.0095**2, 18
f = rho * v**2 * C_d * area / 2
print(round(f / 9.8 * 1000, 2))
```

## The penny with drag

```exercise
title: slope_func with drag
kind: write
---prompt
Write `slope_func(state, t, system)` with drag. The penny falls (v is negative), so drag pushes **up**: `a_drag = f_drag / mass` with `f_drag = rho * v**2 * C_d * area / 2`, and `dvdt = -g + a_drag`. Read everything from `system`.
---starter
def slope_func(state, t, system):
    y, v = state
    pass
---solution
def slope_func(state, t, system):
    y, v = state
    rho, C_d, g = system.rho, system.C_d, system.g
    area, mass = system.area, system.mass
    f_drag = rho * v**2 * C_d * area / 2
    a_drag = f_drag / mass
    dydt = v
    dvdt = -g + a_drag
    return dydt, dvdt
---tests
s = System(rho=1.2, C_d=0.44, g=9.8, area=pi * 0.0095**2, mass=2.5e-3)
assert slope_func(State(y=100.0, v=0.0), 0, s) == (0.0, -9.8), "At rest there's no drag"
d = slope_func(State(y=100.0, v=-18.0), 0, s)
assert abs(d[1]) < 0.1, f"At about 18 m/s drag nearly cancels gravity, got dv/dt = {d[1]:.3f}"
---show
system = System(init=State(y=381.0, v=0.0), rho=1.2, C_d=0.44, g=9.8,
                area=pi * 0.0095**2, mass=2.5e-3, t_end=60)
results, _ = run_ode_solver(system, slope_func, events=event_func)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.2))
ax1.plot(results.index, results.y); ax1.set_xlabel("time (s)"); ax1.set_ylabel("height (m)")
ax2.plot(results.index, results.v); ax2.set_xlabel("time (s)"); ax2.set_ylabel("velocity (m/s)")
ax2.set_title("speed levels off: terminal velocity")
print(f"With your drag model: {get_last_label(results):.1f} s to fall, hitting at {get_last_value(results.v):.1f} m/s")
```

```quiz
With drag, the penny takes about 22 s and hits at about 18 m/s, instead of 8.8 s and 86 m/s. What does that say about the myth?
- The myth is true
```

```recall
A: - The speed at which drag equals weight, so acceleration is zero and speed stops changing.
- Setting ½ρv²C_dA = mg at the measured terminal velocity (18 m/s) gives C_d = 2mg/(ρAv²) ≈ 0.44 for a penny.
```

## Real-world project: a parachute sizer for a weather-balloon payload

You worked **backward** from a terminal velocity to a drag coefficient. Engineers do the same thing in the other direction all the time: pick the landing speed you want, then solve for the parachute. Too small and the payload smashes; too big and it drifts kilometres in the wind and costs more. Terminal velocity is the bridge between the two.

```project
title: Payload parachute sizer
client: A school science club launching a weather balloon with a camera payload
skills: the drag equation, terminal velocity, solving a formula for a design variable, simulation as a check
---brief
When the balloon pops at altitude, the payload (a camera in a foam box) falls under a parachute. The club wants it to land at no more than 5 m/s so the camera survives. Given the payload mass and the parachute's drag coefficient (about 1.5 for a round canopy), compute the canopy area needed, then simulate the last few hundred metres to check the landing speed and how long the descent takes.
---why
Model rocketry and drone-recovery calculators, spacecraft landing designers and airdrop planners all start with this same equation solved for area. And "solve a formula for the design variable, then verify with a simulation" is how most engineering software works: the formula is fast and gives a first answer; the simulation catches what the formula assumed away.
---milestones
- Write `parachute_area(mass, v_land)` from ½ρv²C_dA = m·g, solved for A
- Convert the area to a canopy diameter (it's a circle)
- Write `descent(mass, area, height)` that simulates the fall with drag and returns landing time and speed
- Check the simulated landing speed matches the target
- Print a table of canopy sizes for payloads of 0.5, 1 and 2 kg
---stretch
- Air is thinner high up: make ρ depend on height and see how fast the payload falls at 20 km
- Add a sideways wind and estimate how far the payload drifts while descending
- Size a two-stage system: a small drogue chute high up, the main chute below 500 m
```

```exercise
title: parachute_area
kind: write
---prompt
Write `parachute_area(mass, v_land, C_d=1.5, rho=1.2, g=9.8)`: at terminal velocity drag equals weight, ½·ρ·v²·C_d·A = m·g. Solve for A and return it (m²).
---starter
def parachute_area(mass, v_land, C_d=1.5, rho=1.2, g=9.8):
    return mass * g
---solution
def parachute_area(mass, v_land, C_d=1.5, rho=1.2, g=9.8):
    return 2 * mass * g / (rho * C_d * v_land**2)
---tests
A = parachute_area(0.5, 5)
assert abs(A - 0.2178) < 1e-3, f"A 0.5 kg payload landing at 5 m/s needs about 0.218 m^2, got {A:.4f}"
assert abs(parachute_area(2, 5) - 4 * A) < 1e-9, "Four times the mass needs four times the area (drag must hold four times the weight)"
assert abs(parachute_area(0.5, 2.5) - 4 * A) < 1e-9, "Halving the landing speed needs four times the area, because drag goes with v squared"
---hint
It's the chapter's `drag_coefficient` formula rearranged: same equation, different unknown.
```

```exercise
title: descent
kind: write
---prompt
Write `descent(mass, area, height, C_d=1.5, rho=1.2, g=9.8)`. Define a slope function for a falling object with drag (drag pushes up, as in this chapter's `slope_func`), build a System with `init=State(y=float(height), v=0.0)` and `t_end=1000`, run it with the prelude's `event_func` (stops at the ground) and return `(t_land, v_land)`: the last time label and last velocity (negative = downward).
---starter
def descent(mass, area, height, C_d=1.5, rho=1.2, g=9.8):
    t = sqrt(2 * height / g)
    return t, -g * t
---solution
def descent(mass, area, height, C_d=1.5, rho=1.2, g=9.8):
    def slope_func(state, t, system):
        y, v = state
        f_drag = rho * v**2 * C_d * area / 2
        return v, -g + f_drag / mass
    system = System(init=State(y=float(height), v=0.0), t_end=1000)
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_label(results), get_last_value(results.v)
---tests
A = 2 * 0.5 * 9.8 / (1.2 * 1.5 * 25)
t, v = descent(0.5, A, 300)
assert abs(v + 5) < 0.05, f"Sized for 5 m/s, the payload should land at about -5 m/s, got {v:.2f}"
assert abs(t - 60.35) < 0.5, f"300 m at about 5 m/s takes about a minute (60.4 s), got {t:.1f}"
t_small, v_small = descent(0.5, A / 4, 300)
assert v_small < -9.5, f"A quarter of the canopy lands twice as fast (about -10 m/s), got {v_small:.2f}"
---show
A = 2 * 0.5 * 9.8 / (1.2 * 1.5 * 25)
for mass in [0.5, 1, 2]:
    area = 2 * mass * 9.8 / (1.2 * 1.5 * 25)
    t, v = descent(mass, area, 300)
    print(f"{mass} kg payload: canopy {area:.2f} m^2 (diameter {2 * sqrt(area / pi):.2f} m), lands at {-v:.1f} m/s after {t:.0f} s")
```
