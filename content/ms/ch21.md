## The drag equation

Moving through air, an object pushes air aside and feels a force opposite to its motion:

F_drag = ½ · ρ · v² · C_d · A

- ρ (rho): air density, about 1.2 kg/m³
- v: speed (drag grows with its **square**)
- C_d: the **drag coefficient**, set by shape (measured, not derived)
- A: the cross-sectional area facing the air

As the penny speeds up, drag grows until it equals gravity's pull. Then acceleration is zero and the speed stays constant: **terminal velocity**.

```quiz
If you double an object's speed, what happens to its drag force?
- It doubles
* It quadruples
- It halves
- Nothing; drag depends only on shape
> Drag is proportional to v², so 2× the speed gives 4× the force. That's why terminal velocity arrives fairly quickly for light objects.
```

## From terminal velocity to C_d

Measurements say a penny's terminal velocity is about **18 m/s**. At terminal velocity drag equals weight: ½ρv²C_dA = m·g. Solve for C_d.

```exercise
title: drag coefficient from terminal velocity
kind: write
---prompt
Write `drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8)`: the area is that of a circle with the given diameter; return `2 * mass * g / (rho * area * v_term**2)`.
---starter
def drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8):
    pass
---solution
def drag_coefficient(mass, diameter, v_term, rho=1.2, g=9.8):
    area = pi * (diameter / 2) ** 2
    return 2 * mass * g / (rho * area * v_term**2)
---tests
c = drag_coefficient(2.5e-3, 19e-3, 18)
assert abs(c - 0.444) < 0.005, f"A penny (2.5 g, 19 mm, 18 m/s): C_d about 0.44, got {c:.3f}"
assert abs(drag_coefficient(1, 1, 1, rho=1, g=1) - 2 / (pi / 4)) < 1e-12, "Check the area: pi * (d/2)**2"
```

```predict

print(round(f / 9.8 * 1000, 2))
```

## The penny with drag

```exercise
title: slope_func with drag
kind: write
---prompt
Write `slope_func(state, t, system)` with drag. The penny falls (v is negative), so drag pushes **up**: `a_drag = f_drag / mass` with `f_drag = rho * v**2 * C_d * area / 2`, and `dvdt = -g + a_drag`. Read everything from `system`.
---starter
def slope_func(state, t, system):
    y, v = state
    pass
---solution
def slope_func(state, t, system):
    y, v = state
    rho, C_d, g = system.rho, system.C_d, system.g
    area, mass = system.area, system.mass
    f_drag = rho * v**2 * C_d * area / 2
    a_drag = f_drag / mass
    dydt = v
    dvdt = -g + a_drag
    return dydt, dvdt
---tests
s = System(rho=1.2, C_d=0.44, g=9.8, area=pi * 0.0095**2, mass=2.5e-3)
assert slope_func(State(y=100.0, v=0.0), 0, s) == (0.0, -9.8), "At rest there's no drag"
d = slope_func(State(y=100.0, v=-18.0), 0, s)
assert abs(d[1]) < 0.1, f"At about 18 m/s drag nearly cancels gravity, got dv/dt = {d[1]:.3f}"
---show
system = System(init=State(y=381.0, v=0.0), rho=1.2, C_d=0.44, g=9.8,
                area=pi * 0.0095**2, mass=2.5e-3, t_end=60)
results, _ = run_ode_solver(system, slope_func, events=event_func)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.2))
ax1.plot(results.index, results.y); ax1.set_xlabel("time (s)"); ax1.set_ylabel("height (m)")
ax2.plot(results.index, results.v); ax2.set_xlabel("time (s)"); ax2.set_ylabel("velocity (m/s)")
ax2.set_title("speed levels off: terminal velocity")
print(f"With your drag model: {get_last_label(results):.1f} s to fall, hitting at {get_last_value(results.v):.1f} m/s")
```

```quiz
With drag, the penny takes about 22 s and hits at about 18 m/s, instead of 8.8 s and 86 m/s. What does that say about the myth?
```

```exercise
title: The wrong-direction bug
kind: bug
---prompt
In this version the penny never reaches a terminal velocity: it falls faster and faster. One sign is wrong.
---starter
def slope_func(state, t, system):

    f_drag = system.rho * v**2 * system.C_d * system.area / 2

---solution
def slope_func(state, t, system):
    y, v = state
    f_drag = system.rho * v**2 * system.C_d * system.area / 2
    return v, -system.g + f_drag / system.mass

The penny moves down; drag pushes the other way.
```

```recall
Q: What is terminal velocity, and how did we use it to find the penny's drag coefficient?
A: - The speed at which drag equals weight, so acceleration is zero and speed stops changing.
- Setting ½ρv²C_dA = mg at the measured terminal velocity (18 m/s) gives C_d = 2mg/(ρAv²) ≈ 0.44 for a penny.
```
