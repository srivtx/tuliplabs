## Constant growth

The simplest model: population grows by the **same amount every year**. Pick that amount so the model matches the first and last data points:

annual_growth = (p_end − p_0) / (t_end − t_0)

```exercise
title: annual growth from data
kind: write
---prompt
Write `annual_growth(series)` returning the average growth per year between the first and last points of a TimeSeries. Use `get_first_label`, `get_last_label`, `get_first_value` and `get_last_value`.
---starter
def annual_growth(series):
    pass
---solution
def annual_growth(series):
    t_0, t_end = get_first_label(series), get_last_label(series)
    p_0, p_end = get_first_value(series), get_last_value(series)
    return (p_end - p_0) / (t_end - t_0)
---tests
g = annual_growth(census)
assert abs(g - 0.0723) < 0.0005, f"About 0.072 billion (72 million) per year, got {g:.4f}"
assert annual_growth(TimeSeries({0: 1.0, 10: 3.0})) == 0.2, "From 1 to 3 over 10 years: 0.2 per year"
```

## Simulate year by year

`linrange(t_0, t_end)` gives the years t_0, t_0+1, …, t_end−1 (including the first but not the last). Each year, the next value is this year's plus the growth.

```parsons
title: The simulation loop
---lines
results = TimeSeries()
results[t_0] = p_0
for t in linrange(t_0, t_end):
    results[t + 1] = results[t] + growth
?? results[t] = results[t + 1] + growth
---setup
t_0, t_end, p_0, growth = 1950, 2016, 2.558, 0.0723
---tests
assert len(results) == 67 and abs(results[2016] - (2.558 + 66 * 0.0723)) < 1e-9
```

```run
title: Constant growth vs data
t_0, t_end = get_first_label(census), get_last_label(census)
p_0 = get_first_value(census)
growth = (get_last_value(census) - p_0) / (t_end - t_0)

results = TimeSeries()
results[t_0] = p_0
for t in linrange(t_0, t_end):
    results[t + 1] = results[t] + growth

plot(census, "o", label="US Census")
plot(results, color="gray", label="constant growth model")
decorate(xlabel="Year", ylabel="World population (billion)", title="Constant growth")
```

```quiz
The constant-growth line matches both ends but runs above the data around 1950–1970 and below it around 1990. What does that suggest?
- The data are wrong
* Growth per year wasn't constant: it was smaller early on and larger later
- The model is perfect
- Population fell after 1990
> Fitting the endpoints forces the line through them; the systematic misses in between tell you the real growth rate changed over time. Chapter 6 tries growth proportional to population.
```

```recall
Q: Describe the constant-growth model: how its one parameter is chosen and how the simulation works.
A: - Parameter: annual_growth = (p_end − p_0)/(t_end − t_0), chosen so the model matches the first and last data points.
- Simulation: start with results[t_0] = p_0; for each year t, results[t+1] = results[t] + annual_growth.
```

## Real-world project: will the town's school be full?

A constant-growth model is too simple for the whole world, but it is exactly what many small planning offices use for the next few years: take the trend from the records you have, carry it forward, and see when you hit a limit. The answer isn't certain, but it tells you **when to start worrying**, and that is often the decision.

```project
title: School enrolment forecast for a growing town
client: The education office of a commuter town with one secondary school
skills: TimeSeries, constant growth from data, linrange, finding a crossing
---brief
The school has 1,100 places. Enrolment was 812 in 2016 and has been rising as new houses are built. Using the records the office gives you, fit a constant-growth model, extend it ten years beyond the data, and report the **first year the forecast goes over capacity**, so the council knows when the new wing must open.
---why
Trend projection like this is everywhere in planning software: school places, hospital beds, road traffic, warehouse space, even "when will this disk fill up?" alerts in server monitoring. The skill is the same: fit the simplest model to the data, project it, and find where it crosses a limit.
---milestones
- Load the enrolment records into a `TimeSeries` and plot them
- Write `forecast(series, end_year)`: carry the average annual growth forward from the last record
- Write `first_year_over(series, capacity)`: the first year a forecast exceeds capacity, or None
- Plot records, forecast and a horizontal capacity line together
- Re-fit using only the last 4 years: does the warning year move? Which would you trust?
---stretch
- Add a pessimistic and an optimistic forecast (growth ±25%) and report a range of years
- Split enrolment by year group and move each cohort up one grade per year
- Include planned housing: add an extra 30 pupils in the year a new estate opens
```

```exercise
title: forecast enrolment
kind: write
---prompt
Write `forecast(series, end_year)`. Compute the average annual growth from the first and last points of `series` (as in this chapter). Then return a **new** TimeSeries that starts at the last data year with the last data value and adds that growth each year up to and including `end_year`.
---starter
def forecast(series, end_year):
    results = TimeSeries()
    return results
---solution
def forecast(series, end_year):
    t_0, t_end = get_first_label(series), get_last_label(series)
    growth = (get_last_value(series) - get_first_value(series)) / (t_end - t_0)
    results = TimeSeries()
    results[t_end] = get_last_value(series)
    for t in linrange(t_end, end_year):
        results[t + 1] = results[t] + growth
    return results
---tests
records = TimeSeries({2012: 700.0, 2014: 760.0, 2016: 812.0})
f = forecast(records, 2026)
assert get_first_label(f) == 2016 and f[2016] == 812, "Start from the last record: 2016, 812 pupils"
assert get_last_label(f) == 2026, f"Go up to and including 2026, got {get_last_label(f)}"
assert abs(f[2017] - 840) < 1e-9, f"Growth is (812 - 700) / 4 = 28 pupils a year, so 2017 is 840. Got {f[2017]}"
assert abs(f[2026] - (812 + 10 * 28)) < 1e-9, "Ten years of 28 a year on top of 812"
---hint
The loop is the chapter's loop with different start and end: `for t in linrange(t_end, end_year):`.
```

```exercise
title: first_year_over capacity
kind: write
---prompt
Write `first_year_over(series, capacity)`: go through the series in order and return the first label (year) whose value is **greater than** `capacity`. Return `None` if it never is.
---starter
def first_year_over(series, capacity):
    return get_last_label(series)
---solution
def first_year_over(series, capacity):
    for year, value in series.items():
        if value > capacity:
            return year
    return None
---tests
f = TimeSeries({2016: 812.0, 2017: 840.0, 2018: 868.0, 2019: 896.0})
assert first_year_over(f, 850) == 2018, f"868 in 2018 is the first value over 850, got {first_year_over(f, 850)}"
assert first_year_over(f, 840) == 2018, "Equal to capacity is still OK; only greater counts"
assert first_year_over(f, 1100) is None, "Never over capacity: None"
---hint
`series.items()` gives `(label, value)` pairs in order.
```
