## Newton's second law for rotation

A **torque** τ (force × lever arm, N·m) causes **angular acceleration** α:

τ = I·α

I is the **moment of inertia**, rotation's version of mass. It depends on how far the mass sits from the axis:

- a solid disk of mass m, radius r: I = ½·m·r²
- a small mass m at distance r: I = m·r²

```predict
m_disk, r_disk = 7.0, 0.5
m_pot, r_pot = 0.3, 0.4
I_disk = 0.5 * m_disk * r_disk**2
I_pot = m_pot * r_pot**2
print(I_disk, round(I_pot, 3), round(I_disk + I_pot, 3))
```

```quiz
Two disks have the same mass, but one has twice the radius. Compared with the smaller one, how much torque does it need for the same angular acceleration?
- The same
- Twice as much
* Four times as much
- Half as much
> I = ½mr², so doubling r quadruples I, and τ = Iα needs four times the torque. Mass far from the axis is hard to spin.
```

## The teapot on the turntable

The setup: a turntable (a disk, 7 kg, radius 0.5 m) with a teapot (0.3 kg) near the edge at 0.4 m. You push the edge with a force of 2 N for 0.5 s, then let go. Friction exerts a constant opposing torque until it stops.

```exercise
title: slope_func for the turntable
kind: write
---prompt
Write `slope_func(state, t, system)` with state `(theta, omega)`. For `t < system.t_push` the push adds torque `system.force * system.radius`. Friction torque `system.tau_friction` always opposes motion while `omega > 0` (use 0 when it isn't moving). Return `(omega, alpha)` with `alpha = net_torque / system.I`.
---starter
def slope_func(state, t, system):
    theta, omega = state
    pass
---solution
def slope_func(state, t, system):
    theta, omega = state
    tau = system.force * system.radius if t < system.t_push else 0
    if omega > 0:
        tau -= system.tau_friction
    alpha = tau / system.I
    return omega, alpha
---tests
s = System(force=2, radius=0.5, t_push=0.5, tau_friction=0.2, I=0.923)
d = slope_func(State(theta=0.0, omega=0.0), 0.1, s)
assert abs(d[1] - 1.0 / 0.923) < 1e-9, "At rest during the push: torque 2*0.5 = 1 N m, no friction yet"
d = slope_func(State(theta=1.0, omega=2.0), 1.0, s)
assert d[0] == 2.0 and abs(d[1] + 0.2 / 0.923) < 1e-9, "After the push: only friction, slowing it"
```

def slope_func(state, t, system):
    theta, omega = state
    tau = system.force * system.radius if t < system.t_push else 0
    if omega > 0:

## Estimating friction from an observation

Suppose you watch the real turntable and it turns through **1.0 radian** before stopping. Friction is unknown. Use a root finder: which friction torque makes the model turn exactly 1.0 rad?

## Real-world project: motor sizing for a product-photo turntable

The teapot model takes a torque and tells you how the turntable moves. A product designer asks the reverse: **which motor** is strong enough? Real motors don't give a constant torque; a small DC motor pushes hardest when it's stopped and its torque falls to zero at its top speed. With that one change, a hand formula no longer works, and the simulation earns its keep.

```project
title: Photo-turntable motor picker
client: An online shop building motorised turntables for 360° product photos
skills: τ = I·α, adding moments of inertia, speed-dependent torque, events, "None" for impossible
---brief
The turntable is a 2 kg plate 30 cm in radius; the heaviest product is about 1.5 kg sitting 10 cm off-centre. The camera wants one turn every 10 seconds (0.63 rad/s), reached within 2 seconds of pressing start. Candidate motors have different stall torques and free speeds. Build the tool: compute I, simulate the spin-up with the motor's torque curve and friction, and report the time to reach speed, or that the motor never gets there.
---why
Sizing a motor against a load's inertia is daily work for robotics, e-bike, drone, conveyor and hard-drive engineers, and spec sheets give exactly these two numbers (stall torque and no-load speed). The software lesson: when an input depends on the state (torque depends on ω), you can't use the simple formula, but the slope function doesn't care.
---milestones
- Write `inertia(disks, points)` that adds ½mr² for each disk and mr² for each point mass
- Model the motor: τ = τ_stall·(1 − ω/ω_free), minus friction
- Write `spin_up_time(...)` with an event at the target speed, returning `None` if it's never reached
- Compare three catalogue motors and pick the cheapest that meets 2 seconds
- Show why: the motor's top speed with friction is ω_free·(1 − τ_friction/τ_stall)
---stretch
- Add a gearbox with ratio n: torque × n, speed ÷ n, and find the best n
- Simulate stopping: how many degrees does it overshoot after the motor cuts off?
- Make the heaviest product a parameter and plot spin-up time against it
```

```exercise
title: inertia of the turntable
kind: write
---prompt
Write `inertia(disks=(), points=())`. `disks` is a list of `(mass, radius)` pairs for solid disks (I = ½mr²); `points` is a list of `(mass, distance)` pairs for small objects (I = mr²). Return the total.
---starter
def inertia(disks=(), points=()):
    return sum(m * r**2 for m, r in disks)
---solution
def inertia(disks=(), points=()):
    I = 0
    for m, r in disks:
        I += 0.5 * m * r**2
    for m, r in points:
        I += m * r**2
    return I
---tests
assert abs(inertia([(2.0, 0.3)], [(1.5, 0.1)]) - 0.105) < 1e-12, f"Plate 0.5 x 2 x 0.09 = 0.09, product 1.5 x 0.01 = 0.015, total 0.105; got {inertia([(2.0, 0.3)], [(1.5, 0.1)])}"

```

```exercise
title: spin_up_time with a real motor
kind: write
---prompt
Write `spin_up_time(tau_stall, omega_free, I, tau_friction, omega_target)`. State `(theta, omega)`; net torque `tau_stall * (1 - omega / omega_free) - tau_friction`; α = torque / I. Stop with an event `omega - omega_target`, `t_end = 60`. If the final ω is still below the target (within 1e-6), return `None`; otherwise return the final time.
---starter
def spin_up_time(tau_stall, omega_free, I, tau_friction, omega_target):
    return I * omega_target / (tau_stall - tau_friction)
---solution
def spin_up_time(tau_stall, omega_free, I, tau_friction, omega_target):
    def slope_func(state, t, system):
        theta, omega = state
        tau = tau_stall * (1 - omega / omega_free) - tau_friction
        return omega, tau / I

    def event_func(state, t, system):
        theta, omega = state
        return omega - omega_target

    system = System(init=State(theta=0.0, omega=0.0), t_end=60)
    results, details = run_ode_solver(system, slope_func, events=event_func)
    if get_last_value(results.omega) < omega_target - 1e-6:
        return None
    return get_last_label(results)
---tests
target = 2 * pi / 10
t = spin_up_time(0.1, 1.0, 0.105, 0.02, target)
assert t is not None and abs(t - 1.615) < 0.02, f"This motor reaches one turn per 10 s in about 1.62 s, got {t}"
assert t > 0.105 * target / (0.1 - 0.02), "Slower than the constant-torque formula, because the torque fades as it speeds up"
assert spin_up_time(0.1, 0.7, 0.105, 0.02, target) is None, "Top speed 0.7 x (1 - 0.2) = 0.56 rad/s is below the target: return None"
assert spin_up_time(0.03, 1.0, 0.105, 0.02, target) is None, "Barely stronger than friction: it never gets there"
---hint
The event stops the run at the target speed. If the motor can't reach it, the run goes all the way to `t_end`, and the last ω tells you so.
---show
I = 0.105
for name, ts, wf in [("motor A", 0.06, 1.2), ("motor B", 0.1, 1.0), ("motor C", 0.2, 0.8)]:
    t = spin_up_time(ts, wf, I, 0.02, 2 * pi / 10)
    print(f"{name}: " + ("never reaches speed" if t is None else f"{t:.2f} s" + ("  OK" if t <= 2 else "  too slow")))
```
