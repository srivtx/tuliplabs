## The Part II toolkit

| Tool | What it does |
|---|---|
| `State`, `System`, `Params` | state variables; fixed parameters; values to vary |
| update function | computes the next state with a fixed step |
| slope function | returns derivatives; `run_ode_solver` does the stepping |
| `TimeFrame` | one row per time, one column per state variable |

## Case study 1: the insulin minimal model

The glucose model took insulin as measured input. The book's companion model explains **insulin** itself: the pancreas secretes insulin when glucose is above a threshold G_T, and the body clears it at rate k.

dI/dt = −k·I + γ·max(G(t) − G_T, 0)·t

```exercise
title: slope_func for insulin
kind: write
---prompt
Write `slope_func(state, t, system)` for the insulin model. `state` has one variable, `I`. Use `system.k`, `system.gamma`, `system.G_T` and the glucose function `system.G(t)`. Return a one-element tuple `(dIdt,)`.
---starter
def slope_func(state, t, system):
    I, = state
    pass
---solution
def slope_func(state, t, system):
    I, = state
    excess = max(system.G(t) - system.G_T, 0)
    dIdt = -system.k * I + system.gamma * excess * t
    return (dIdt,)
---tests
s = System(k=0.25, gamma=0.004, G_T=80, G=lambda t: 180.0)
d = slope_func(State(I=40.0), 10, s)
assert abs(d[0] - (-10 + 0.004 * 100 * 10)) < 1e-9, f"-0.25*40 + 0.004*100*10 = -6, got {d[0]}"
s2 = System(k=0.25, gamma=0.004, G_T=200, G=lambda t: 180.0)
assert abs(slope_func(State(I=40.0), 10, s2)[0] + 10) < 1e-9, "Below the threshold there's no secretion, only clearance"
```

```predict
G_T = 80
for G in [60, 80, 130]:
    print(max(G - G_T, 0))
```

## Case study 2: a low-pass filter

An electronic **RC circuit** (a resistor R and a capacitor C) smooths a signal: slow changes pass through, fast wiggles get damped. The output voltage follows

dV_out/dt = (V_in(t) − V_out) / (R·C)

That's Newton's law of cooling again, with V_in as a moving "room temperature". The **cutoff frequency** is f_c = 1 / (2π·R·C).

```exercise
title: slope_func for the filter
kind: write
---prompt
Write `slope_func(state, t, system)` for the RC filter: `state` has `V_out`; `system` has `R`, `C` and a function `V_in(t)`. Return `(dVdt,)`.
---starter
def slope_func(state, t, system):
    V_out, = state
    pass
---solution
def slope_func(state, t, system):
    V_out, = state
    dVdt = (system.V_in(t) - V_out) / (system.R * system.C)
    return (dVdt,)
---tests
s = System(R=1e6, C=1e-6, V_in=lambda t: 5.0)
assert abs(slope_func(State(V_out=0.0), 0, s)[0] - 5.0) < 1e-9, "RC = 1 s: dV/dt = (5 - 0)/1 = 5"
assert slope_func(State(V_out=5.0), 0, s)[0] == 0, "When output equals input, nothing changes"
```

```run
title: Slow vs fast input
def slope_func(state, t, system):
    V_out, = state
    return ((system.V_in(t) - V_out) / (system.R * system.C),)

R, C = 1e6, 1e-6                       # RC = 1 second, cutoff about 0.16 Hz
fig, axes = plt.subplots(1, 2, figsize=(10, 3.2))
for ax, f in zip(axes, [0.05, 2.0]):
    V_in = lambda t, f=f: 5 * np.sin(2 * np.pi * f * t)
    system = System(init=State(V_out=0.0), R=R, C=C, V_in=V_in, t_0=0, t_end=5 / f)
    results, _ = run_ode_solver(system, slope_func, t_eval=linspace(0, 5 / f, 400), max_step=0.05 / f)
    ts = results.index.values
    ax.plot(ts, V_in(ts), label="input"); ax.plot(ts, results.V_out.values, label="output")
    ax.set_title(f"{f} Hz"); ax.set_xlabel("time (s)"); ax.legend(fontsize=8)
```

```exercise
title: Amplitude ratio
kind: write
---prompt
Theory says a sine input of frequency f comes out with its amplitude multiplied by 1/√(1 + (f/f_c)²). Write `gain(f, R, C)`.
---starter
def gain(f, R, C):
    pass
---solution
def gain(f, R, C):
    f_c = 1 / (2 * pi * R * C)
    return 1 / sqrt(1 + (f / f_c) ** 2)
---tests
R, C = 1e6, 1e-6
f_c = 1 / (2 * pi)
assert abs(gain(f_c, R, C) - 1 / sqrt(2)) < 1e-12, "At the cutoff the gain is 1/sqrt(2), about 0.707"
assert gain(0.001, R, C) > 0.999 and gain(20, R, C) < 0.01, "Slow signals pass, fast ones are crushed"
```

```quiz
Why is the RC filter mathematically the same kind of system as the cooling coffee?
* Both say the rate of change is proportional to the gap between the current value and a target (room temperature, input voltage)
- Both involve heat
- Both have two state variables
- They aren't the same; one is electrical
> dT/dt = −r(T − T_env) and dV/dt = (V_in − V)/(RC) have the same form, with r ↔ 1/RC. Spotting the same structure in different systems is one of the most useful modeling skills.
```

## Real-world project: a steady display for a kitchen scale

The RC filter is everywhere in software too, as a few lines of code. A digital scale's load sensor jitters by a few grams, so the raw number on the display flickers. Run the readings through a low-pass filter and the display goes steady, but if you smooth too much it takes ages to show a new weight. Picking R·C is picking that trade-off.

```project
title: Kitchen-scale display smoother
client: A company making a Bluetooth kitchen scale with a companion recipe app
skills: the RC filter equation, Euler steps, cutoff frequency, trade-offs you can measure
---brief
The sensor sends 100 readings a second with about ±3 g of noise. The display must not flicker by more than half a gram, but when you drop flour in, it should show the new weight within about a second. Turn the RC equation into a digital filter, choose R·C from a cutoff frequency, and measure both requirements.
---why
This exact filter (often called an exponential moving average) smooths phone accelerometers, game-controller sticks, audio volume meters, stock-price indicators and the "estimated time remaining" in file downloads. Each one picks a time constant to trade smoothness against lag, which is the same number as R·C here.
---milestones
- Write `rc_for_cutoff(f_c)`, the time constant for a chosen cutoff frequency
- Write `smooth(samples, dt, RC)`: the RC equation as one Euler step per reading
- Measure the noise left on a steady weight (standard deviation of the output)
- Measure the lag: how long after a step change the display is within 1 g of the new weight
- Pick the RC that meets both requirements and print it
---stretch
- Plot raw vs smoothed readings for three RC values side by side
- Add "snap" logic: if a reading jumps by more than 20 g, reset the filter to it immediately
- Compare with a simple moving average of the last N readings
```

```exercise
title: rc_for_cutoff
kind: fill
---prompt
The cutoff frequency is f_c = 1 / (2π·R·C). Fill the blank to solve it for the time constant R·C.
---starter
def rc_for_cutoff(f_c):
    return ____
---solution
def rc_for_cutoff(f_c):
    return 1 / (2 * pi * f_c)
---tests
assert abs(rc_for_cutoff(1 / (2 * pi)) - 1.0) < 1e-12, "This chapter's circuit: cutoff 0.159 Hz means RC = 1 s"
assert abs(rc_for_cutoff(0.5) - 0.3183) < 1e-4, f"A 0.5 Hz cutoff needs RC of about 0.318 s, got {rc_for_cutoff(0.5)}"
```

```exercise
title: smooth
kind: write
---prompt
Write `smooth(samples, dt, RC)`: start the output at the first sample, then for **each** sample `x` take one Euler step of dV/dt = (x − V)/RC, i.e. `V = V + (x - V) * dt / RC`, and append V. Return the list of outputs (same length as the input).
---starter
def smooth(samples, dt, RC):
    return list(samples)
---solution
def smooth(samples, dt, RC):
    out = []
    V = samples[0]
    for x in samples:
        V = V + (x - V) * dt / RC
        out.append(V)
    return out
---tests
assert smooth([500.0] * 20, 0.01, 0.3) == [500.0] * 20, "A steady weight stays exactly steady"
step = smooth([0.0] + [1.0] * 50, 0.01, 0.5)
assert len(step) == 51, "One output per reading"
assert abs(step[50] - 0.636) < 0.005, f"After one time constant (50 steps of 0.01 s with RC = 0.5) the output is about 63% of the way: got {step[50]:.3f}"
np.random.seed(1)
noisy = list(500 + np.random.normal(0, 3, 400))
assert np.std(smooth(noisy, 0.01, 0.3)[200:]) < 0.5, "With RC = 0.3 s the ±3 g jitter shrinks below half a gram"
---show
np.random.seed(2)
t = np.arange(0, 4, 0.01)
raw = np.where(t < 1.5, 0.0, 250.0) + np.random.normal(0, 3, len(t))
plt.plot(t, raw, ".", ms=2, color="#999", label="raw sensor")
for RC in [0.05, 0.3, 1.0]:
    plt.plot(t, smooth(list(raw), 0.01, RC), label=f"RC = {RC} s")
decorate(xlabel="Time (s)", ylabel="Weight (g)", title="250 g of flour dropped at 1.5 s: smooth vs slow")
```
