## The Freshman Plague

Every fall at Olin College, a few days after the first-years arrive, an illness spreads through the class. The book models it with the classic **SIR model**: everyone is in one of three compartments.

- **S**usceptible: can catch it.
- **I**nfectious: has it and can spread it.
- **R**ecovered: had it, now immune.

Two parameters drive the flow S → I → R:

- **β (beta)**, the contact rate: each infected person makes β infecting contacts per day, but only contacts with susceptible people count, so new infections per day = β·i·s.
- **γ (gamma)**, the recovery rate: a fraction γ of infected people recover each day, so recoveries = γ·i. If illness lasts about 4 days, γ = 1/4.

We use **fractions** of the population (s + i + r = 1). The class has 90 students, one of them sick on day 0.

```quiz
Why is the number of new infections proportional to s·i and not just to i?
- It's an arbitrary choice
* An infection needs a contact between an infectious person and a susceptible one; as susceptibles run out, contacts stop producing infections
- Because recovered people get sick again
- Because i is always small
> Each infectious person's contacts are spread over the whole population, and only the fraction s of them can be infected. That s·i product is what eventually stops the epidemic.
```

## The update function

```exercise
title: update_func
kind: write
---prompt
Write the book's `update_func(state, t, system)`: unpack `s, i, r = state`, compute `infected = system.beta * i * s` and `recovered = system.gamma * i`, update the three values, and return a **new** `State(S=s, I=i, R=r)`.
---starter
def update_func(state, t, system):
    s, i, r = state
    pass
---solution
def update_func(state, t, system):
    s, i, r = state
    infected = system.beta * i * s
    recovered = system.gamma * i
    s -= infected
    i += infected - recovered
    r += recovered
    return State(S=s, I=i, R=r)
---tests
st = update_func(State(S=0.9, I=0.1, R=0.0), 0, System(beta=0.5, gamma=0.25))
assert abs(st.S - 0.855) < 1e-9 and abs(st.I - 0.12) < 1e-9 and abs(st.R - 0.025) < 1e-9, f"Expected S=0.855, I=0.12, R=0.025, got {st}"
assert abs(st.S + st.I + st.R - 1) < 1e-9, "People move between compartments; the total stays 1"
---hint
New infections leave S and enter I; recoveries leave I and enter R.
```

```run
title: The Freshman Plague
def update_func(state, t, system):
    s, i, r = state
    infected = system.beta * i * s
    recovered = system.gamma * i
    return State(S=s - infected, I=i + infected - recovered, R=r + recovered)

def run_simulation(system, update_func):
    frame = TimeFrame(columns=system.init.index)
    frame.row[system.t_0] = system.init
    for t in linrange(system.t_0, system.t_end):
        frame.row[t + 1] = update_func(frame.row[t], t, system)
    return frame

tc, tr = 3, 4                        # days between contacts, days to recover
system = make_system(1 / tc, 1 / tr)
results = run_simulation(system, update_func)
plot(results.S, "--", label="Susceptible")
plot(results.I, "-", label="Infected")
plot(results.R, ":", label="Recovered")
decorate(xlabel="Time (days)", ylabel="Fraction of population")
print("peak infected:", round(results.I.max(), 3), "on day", results.I.idxmax())
print("fraction who got sick:", round(results.S.iloc[0] - results.S.iloc[-1], 3))
```

```quiz
The epidemic ends with about half the class never infected. Why doesn't everyone get sick?
- The model runs out of days
* As S falls, each infected person produces fewer new infections; once that drops below the recovery rate, infections die out while susceptibles remain
- Recovered people protect everyone
- β is too small to infect anyone
> New infections are β·i·s. When s falls below γ/β, each case causes less than one new case on average, so the epidemic shrinks even though susceptible people remain. This is the idea behind herd immunity.
```

```recall
Q: Describe the SIR model: compartments, parameters, and the flow equations for one day.
A: - Compartments S, I, R as fractions of the population.
- β: contact rate (infecting contacts per infected person per day); γ: recovery rate (1 / days sick).
- Each day: infected = β·i·s moves from S to I; recovered = γ·i moves from I to R.
- The total s + i + r stays 1.
```
