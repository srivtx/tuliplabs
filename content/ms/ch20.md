## Second-order systems

Part II's systems had first derivatives: temperature changes at some rate. Mechanics is different. **Newton's second law**, F = m·a, gives the **acceleration**, the second derivative of position. The book's trick: track **two** state variables, position y and velocity v:

- dy/dt = v
- dv/dt = a = F/m

Now it's two first-order equations, and `run_ode_solver` can handle it.

```quiz
To simulate a falling object with run_ode_solver, what goes in the state?
- Only the position
* Position and velocity
- Velocity and acceleration
- Only the acceleration
> The slope function must return the derivative of every state variable. Position's derivative is velocity (which must therefore be in the state) and velocity's derivative is acceleration (computed from forces).
```

## Dropping the penny

Back to chapter 1: a penny dropped from 381 m, no air resistance (yet).

```exercise
title: slope_func for free fall
kind: write
---prompt
Write the book's `slope_func(state, t, system)`: unpack `y, v = state`, return `dydt, dvdt` with constant acceleration `-system.g`.
---starter
def slope_func(state, t, system):
    y, v = state
    pass
---solution
def slope_func(state, t, system):
    y, v = state
    dydt = v
    dvdt = -system.g
    return dydt, dvdt
---tests
assert slope_func(State(y=381.0, v=-10.0), 0, System(g=9.8)) == (-10.0, -9.8), "dy/dt is the velocity; dv/dt is -g"
```

```run
title: Fall for 10 seconds
def slope_func(state, t, system):
    y, v = state
    return v, -system.g

init = State(y=381.0, v=0.0)
system = System(init=init, g=9.8, t_end=10)
results, details = run_ode_solver(system, slope_func)
plot(results.y, label="y")
decorate(xlabel="Time (s)", ylabel="Position (m)")
print(results.tail(3))
```

The plot goes **below zero**: the penny falls through the sidewalk. We ran a fixed 10 seconds, but we want to stop when y reaches 0.

```predict
results = TimeFrame({"y": [5.0, 1.0, -3.0]}, index=[8.0, 8.5, 9.0])
print(crossings(results.y, 0))
```

`crossings` finds when a TimeSeries passes a value, by interpolating between points. A better tool stops the solver right there.

## Events

An **event function** returns a number that crosses zero when something happens. `run_ode_solver(..., events=event_func)` stops the simulation at that moment.

```exercise
title: event_func
kind: write
---prompt
Write `event_func(state, t, system)` that returns the penny's height (it hits zero at the sidewalk).
---starter
def event_func(state, t, system):
    pass
---solution
def event_func(state, t, system):
    y, v = state
    return y
---tests
assert event_func(State(y=12.5, v=-3.0), 0, System()) == 12.5, "Return the height"
```

```exercise
title: Flight time and impact speed
kind: write
---prompt
Write `drop(height, g=9.8)`: run the free-fall model from rest at `height`, stopping at the ground, and return `(t_sidewalk, v_sidewalk)` using `get_last_label(results)` and `get_last_value(results.v)`. `slope_func` and `event_func` are defined.
---setup
def slope_func(state, t, system):
    y, v = state
    return v, -system.g

def event_func(state, t, system):
    y, v = state
    return y
---starter
def drop(height, g=9.8):
    pass
---solution
def drop(height, g=9.8):
    init = State(y=height, v=0.0)
    system = System(init=init, g=g, t_end=100)
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_label(results), get_last_value(results.v)
---tests
t, v = drop(381)
assert abs(t - 8.818) < 0.01, f"About 8.8 s, as chapter 1 computed by hand; got {t:.3f}"
assert abs(v + 86.4) < 0.2, f"About -86 m/s (negative = downward), got {v:.2f}"
---hint
Make `t_end` comfortably longer than the fall (say 100 s); the event stops the run early.
---show
for h in [50, 150, 381]:
    system = System(init=State(y=float(h), v=0.0), g=9.8, t_end=100)
    results, _ = run_ode_solver(system, slope_func, events=event_func)
    plot(results.y, label=f"dropped from {h} m")
t, v = drop(381)
decorate(title=f"Your drop(381): {t:.1f} s, {v:.0f} m/s", xlabel="Time (s)", ylabel="Height (m)")
```

```recall
Q: How does the book turn Newton's second law into something run_ode_solver can solve, and how does it stop at the ground?
A: - Use position and velocity as state variables: dy/dt = v, dv/dt = F/m (here −g). Two first-order ODEs instead of one second-order one.
- An event function returns y; the solver stops when it crosses zero, so the last row of results is the moment of impact.
```
