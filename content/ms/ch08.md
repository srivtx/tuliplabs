```prelude
from modsim import *

census = TimeSeries({1950: 2.558, 1955: 2.782, 1960: 3.043, 1965: 3.350, 1970: 3.712,
                     1975: 4.089, 1980: 4.452, 1985: 4.855, 1990: 5.288, 1995: 5.700,
                     2000: 6.090, 2005: 6.474, 2010: 6.864, 2015: 7.256, 2016: 7.333})

# Approximate UN medium-variant projections (billions), rounded, for comparison.
un_proj = TimeSeries({2020: 7.8, 2030: 8.5, 2040: 9.2, 2050: 9.7, 2060: 10.2,
                      2070: 10.5, 2080: 10.8, 2090: 11.0, 2100: 11.2})

def run_simulation(system, update_func):
    results = TimeSeries()
    results[system.t_0] = system.p_0
    for t in linrange(system.t_0, system.t_end):
        results[t + 1] = update_func(results[t], t, system)
    return results

def update_func_quad(pop, t, system):
    return pop + system.alpha * pop + system.beta * pop**2
```

## Where did alpha and beta come from?

The quadratic model says the **growth rate per person** is a straight line in p:

net growth / p = alpha + beta·p

So if we compute the growth rate from the data and plot it against population, the intercept is alpha and the slope is beta. That's an estimate from data, not a guess.

```exercise
title: Growth rates from data
kind: write
---prompt
Write `growth_rates(series)`: for each pair of consecutive data points `(t1, p1)`, `(t2, p2)`, compute the annual growth rate per person `(p2 - p1) / (t2 - t1) / p1`. Return two numpy arrays: the populations `p1` and the rates.
---starter
def growth_rates(series):
    t = np.array(series.index, dtype=float)
    p = np.array(series.values, dtype=float)
    pass
---solution
def growth_rates(series):
    t = np.array(series.index, dtype=float)
    p = np.array(series.values, dtype=float)
    rates = np.diff(p) / np.diff(t) / p[:-1]
    return p[:-1], rates
---tests
pops, rates = growth_rates(TimeSeries({0: 100.0, 10: 110.0, 20: 132.0}))
assert pops.tolist() == [100.0, 110.0], "Use the population at the start of each interval"
assert np.allclose(rates, [0.01, 0.02]), f"10 over 10 years from 100 is 1%/yr; 22 over 10 from 110 is 2%/yr. Got {rates}"
---hint
`np.diff(p)` gives the changes between consecutive values.
```

```run
title: Fit alpha and beta
t = np.array(census.index, dtype=float)
p = np.array(census.values, dtype=float)
pops, rates = p[:-1], np.diff(p) / np.diff(t) / p[:-1]
beta, alpha = np.polyfit(pops, rates, 1)
print(f"alpha = {alpha:.4f}, beta = {beta:.5f}, equilibrium = {-alpha / beta:.1f} billion")
plt.plot(pops, rates, "o", label="from data")
xs = np.linspace(2, 8, 10)
plt.plot(xs, alpha + beta * xs, label="best-fit line")
decorate(xlabel="Population (billion)", ylabel="Net growth rate (per person per year)")
```

```quiz
The fitted line slopes down. In terms of the model, what does that mean?
- Births are rising
* beta is negative: the per-person growth rate falls as population rises
- alpha is negative
- The world population is shrinking
> A negative slope is a negative beta, the crowding term. The fit supports the quadratic model's key assumption, at least for these years.
```

## Projections

```run
title: Project to 2100
t = np.array(census.index, dtype=float); p = np.array(census.values, dtype=float)
beta, alpha = np.polyfit(p[:-1], np.diff(p) / np.diff(t) / p[:-1], 1)
system = System(t_0=1950, t_end=2100, p_0=census[1950], alpha=alpha, beta=beta)
results = run_simulation(system, update_func_quad)
plot(census, "o", label="US Census")
plot(un_proj, "s", label="UN projection (approx.)")
plot(results, color="gray", label="quadratic model")
decorate(xlabel="Year", ylabel="World population (billion)", title="Quadratic model projection")
print("model 2050:", round(results[2050], 1), "  model 2100:", round(results[2100], 1))
```

```quiz
The quadratic model and the UN projection broadly agree to 2050, then drift apart. Which statement is fairest?
- The model proves the UN is wrong
* The model shows one possible future if past trends continue; the UN uses much more detailed information (age structure, fertility trends), so agreement is reassuring but neither is certain
- Long-range projections are impossible, so the model is useless
- The models agree, so the future is known
> A simple model fitted to the past can only extend past trends. Its value is in making the assumptions explicit, and comparing it with expert projections shows where the extra detail matters.
```

```recall
Q: How do you estimate alpha and beta for the quadratic model from data?
A: - Compute the per-person growth rate between consecutive data points: Δp / Δt / p.
- Plot it against population; the quadratic model predicts a straight line, rate = alpha + beta·p.
- Fit a line (e.g. `np.polyfit(p, rate, 1)`): the intercept is alpha, the slope is beta.
```

## Real-world project: when will the storage cluster be full?

Fitting alpha and beta from data is how you turn "it's growing fast" into a date. A company's file storage grows like a population: more users store more files, but growth slows as the market fills up. Fit the model to the usage history, run it forward, and read off when it crosses the size of the disks you own. That date is when the purchase order has to go in.

```project
title: Capacity forecast for a photo app's storage
client: The infrastructure team of a photo-sharing app
skills: estimating parameters from data, np.polyfit, projections, crossing a limit
---brief
The team has 24 months of total storage used (in terabytes). The cluster holds 300 TB, and new disks take 3 months to arrive. Estimate alpha and beta from the monthly growth rates, project forward with the quadratic model, and report the **month storage first reaches 300 TB**, and so the month the order must be placed.
---why
Capacity planning is a real job in every company that runs servers: databases, disks, network links and even office space are forecast exactly like this. Monitoring tools (Grafana, Datadog, cloud consoles) have "predict when this fills up" features built on fitted growth curves. Knowing the fit is an estimate, and checking it against new data each month, is what keeps the forecast honest.
---milestones
- Load the 24 months into a `TimeSeries` and plot it
- Write `fit_alpha_beta(series)`: growth rate per TB against TB, fitted with `np.polyfit`
- Project 48 months ahead with `run_simulation` and `update_func_quad`
- Write `month_full(system, capacity)`: the first month at or over capacity, or None
- Subtract the 3-month delivery time and write the one-line recommendation for the team
---stretch
- Refit using only the last 12 months and compare the full-date: how sensitive is the answer?
- Add a planned feature launch that adds 20 TB in one month
- Plot the history, the fit and the capacity line on one chart for the team's weekly report
```

```exercise
title: fit_alpha_beta from usage history
kind: write
---prompt
Write `fit_alpha_beta(series)`: compute the growth rate per unit for each pair of consecutive points, `(p2 - p1) / (t2 - t1) / p1`, then fit a straight line of rate against `p1` with `np.polyfit(..., 1)`. The intercept is alpha and the slope is beta. Return `(alpha, beta)`.
---starter
def fit_alpha_beta(series):
    t = np.array(series.index, dtype=float)
    p = np.array(series.values, dtype=float)
    return 0, 0
---solution
def fit_alpha_beta(series):
    t = np.array(series.index, dtype=float)
    p = np.array(series.values, dtype=float)
    rates = np.diff(p) / np.diff(t) / p[:-1]
    beta, alpha = np.polyfit(p[:-1], rates, 1)
    return alpha, beta
---tests
history = run_simulation(System(t_0=0, t_end=24, p_0=50.0, alpha=0.08, beta=-0.0002), update_func_quad)
alpha, beta = fit_alpha_beta(history)
assert abs(alpha - 0.08) < 1e-6 and abs(beta + 0.0002) < 1e-8, f"Data made by the model itself should give back alpha = 0.08, beta = -0.0002. Got {alpha:.5f}, {beta:.7f}"
a2, b2 = fit_alpha_beta(TimeSeries({0: 100.0, 2: 120.0, 4: 144.0}))
assert abs(a2 - 0.1) < 1e-9 and abs(b2 - 0.0) < 1e-9, "+20% every 2 years, whatever the size, is a rate of 0.1 per year that never slows: alpha = 0.1, beta = 0"
---hint
`np.polyfit(x, y, 1)` returns `[slope, intercept]`, in that order.
```

```exercise
title: month_full
kind: write
---prompt
Write `month_full(system, capacity)`: run `run_simulation(system, update_func_quad)` (both are in the prelude) and return the first time label whose value is **at least** `capacity`, or `None` if it never gets there before `system.t_end`.
---starter
def month_full(system, capacity):
    return system.t_end
---solution
def month_full(system, capacity):
    results = run_simulation(system, update_func_quad)
    for month, used in results.items():
        if used >= capacity:
            return month
    return None
---tests
s = System(t_0=24, t_end=72, p_0=150.0, alpha=0.08, beta=-0.0002)
m = month_full(s, 300)
assert m == 45, f"From 150 TB at month 24, the fitted model reaches 300 TB in month 45. Got {m}"
assert month_full(s, 450) is None, "450 TB is above the model's ceiling of 400 TB (-alpha/beta): never full"
assert month_full(s, 100) == 24, "Already over 100 TB at the start"
```
