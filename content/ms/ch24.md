## Rotation, the same way as motion

A spinning object has an **angle** θ (radians) and an **angular velocity** ω = dθ/dt (radians per second). A point at radius r on the rim moves at linear speed **v = r·ω**. One full turn is 2π radians.

```predict
r, omega = 0.05, 10           # metres, radians per second
print(r * omega)               # rim speed in m/s
print(round(2 * pi / omega, 3)) # seconds per turn
```

## The toilet paper problem

The example: a roll of toilet paper with core radius R_min = 2 cm, full radius R_max = 5.5 cm, and paper length L = 47 m. If you pull it so the roll turns at a constant ω = 10 rad/s, how long until it's empty?

As paper comes off, the radius shrinks, so each turn delivers less paper. Each turn removes a layer of thickness k·2π, where k comes from the geometry: the area of the paper's cross-section (π(R_max² − R_min²)) equals its length times its thickness, giving

k = (R_max² − R_min²) / (2L)

## The state and the slope function

State: θ (angle turned), y (paper unrolled, in metres), r (current radius). With constant ω:

- dθ/dt = ω
- dy/dt = r·ω (the rim speed)
- dr/dt = −k·ω (the roll shrinks)

```exercise
title: slope_func for unrolling
kind: write
---prompt
Write `slope_func(state, t, system)` returning `(dθ/dt, dy/dt, dr/dt)` as above. `system` has `omega` and `k`.
---starter
def slope_func(state, t, system):
    theta, y, r = state
    pass
---solution
def slope_func(state, t, system):
    theta, y, r = state
    omega, k = system.omega, system.k
    dydt = r * omega
    drdt = -k * omega
    return omega, dydt, drdt
---tests
d = slope_func(State(theta=0.0, y=0.0, r=0.05), 0, System(omega=10, k=2.8e-5))
assert abs(d[0] - 10) < 1e-12 and abs(d[1] - 0.5) < 1e-12 and abs(d[2] + 2.8e-4) < 1e-12, f"Expected (10, 0.5, -0.00028), got {d}"
---show
k = compute_k(0.02, 0.055, 47) if "compute_k" in dir() else (0.055**2 - 0.02**2) / 94
system = System(init=State(theta=0.0, y=0.0, r=0.055), omega=10, k=k, L=47, t_end=200)
def event_func(state, t, system):
    theta, y, r = state
```

```run
title: Unroll until empty
def slope_func(state, t, system):
    theta, y, r = state
    return system.omega, r * system.omega, -system.k * system.omega

def event_func(state, t, system):
    theta, y, r = state
    return system.L - y          # zero when all the paper is out

k = (0.055**2 - 0.02**2) / (2 * 47)
system = System(init=State(theta=0.0, y=0.0, r=0.055), omega=10, k=k, L=47, t_end=200)
results, details = run_ode_solver(system, slope_func, events=event_func)
print(f"empty after {get_last_label(results):.1f} s; final radius {get_last_value(results.r) * 100:.2f} cm")
plot(results.r * 100, label="radius (cm)")
decorate(xlabel="Time (s)", ylabel="Radius (cm)")
```

```quiz
The final radius comes out at about 2.0 cm, the core radius, even though we never told the model to stop there. Why is that a good sign?
- It's a coincidence
* k was derived from R_min, R_max and L; unrolling exactly L metres should bring the radius back to R_min, so the match checks the model's consistency
- The event stops at the core
- The solver rounds to 2 cm
> The event stops when y = L. Landing on R_min at that moment confirms that the geometry (k) and the dynamics agree. Checks like this catch bugs.
```

```recall
Q: How does the toilet paper model connect rotation to linear motion?
A: - The rim moves at v = r·ω, so paper comes off at dy/dt = r·ω.
- Each radian unrolled removes thickness k, so dr/dt = −k·ω with k = (R_max² − R_min²)/(2L).
- With constant ω, θ grows steadily while the paper comes out more slowly as r shrinks; an event stops at y = L.
```

## Real-world project: a constant-speed reel controller

The toilet-paper roll turned at a constant ω, so the paper came off **slower and slower** as the radius shrank. Real machines that unwind paper, film, labels or cable usually need the opposite: a constant **line speed**, so the motor has to spin faster as the roll gets smaller. That's v = r·ω, solved for ω, running in a loop.

```project
title: Unwind-reel speed controller
client: A packaging plant that prints labels from big paper reels
skills: v = r·ω, slope functions with three relations, events, consistency checks
---brief
A reel holds 2,000 m of label paper on a 5 cm core, 60 cm across when full. The printer pulls paper at a steady 5 m/s, so the unwind motor must set ω = v / r at every moment. The plant wants a controller model: the motor speed command over time, how much paper is left given the current radius (a cheap distance sensor measures r), and when to have the next reel ready.
---why
Constant-surface-speed control runs paper mills, film and tape drives, cable winches, fishing reels and lathes (spindle speed rises as the cutter moves toward the centre). "Estimate what's left from one easy measurement" is the same idea as a fuel gauge, or a phone estimating battery charge from voltage.
---milestones
- Write `remaining_length(r, R_min, k)`: metres left on the reel from its current radius
- Write a slope function where ω = v_line / r instead of a constant
- Write `time_to_empty(R_min, R_max, L, v_line)` with an event at the core radius
- Check the answer against L / v_line (it must match: the line speed is constant)
- Plot the motor speed command ω(t) and find its maximum (the motor must be able to reach it)
---stretch
- Add a maximum motor speed and find the smallest core the printer can run to
- Model the reel's moment of inertia shrinking too (chapter 25) and the torque needed to keep speed
- Warn the operator 2 minutes before the reel runs out
```

```exercise
title: time_to_empty at constant line speed
kind: write
---prompt
Write `time_to_empty(R_min, R_max, L, v_line)`. Compute `k` with the chapter's formula. The state is `(y, r)`; in the slope function, `omega = system.v_line / r`, then `dy/dt = v_line` and `dr/dt = -k * omega`. Stop with an event `r - R_min`. Start at `State(y=0.0, r=R_max)` with `t_end = 10 * L / v_line`. Return `(t_empty, omega_max)`, where `omega_max = v_line / R_min` is the motor speed at the end.
---starter
def time_to_empty(R_min, R_max, L, v_line):
    return L / v_line, v_line / R_max
---solution
def time_to_empty(R_min, R_max, L, v_line):
    k = (R_max**2 - R_min**2) / (2 * L)

    def slope_func(state, t, system):
        y, r = state
        omega = system.v_line / r
        return system.v_line, -system.k * omega

    def event_func(state, t, system):
        y, r = state
        return r - R_min

    system = System(init=State(y=0.0, r=R_max), k=k, v_line=v_line, t_end=10 * L / v_line)
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_label(results), v_line / R_min
---tests
t, w = time_to_empty(0.05, 0.6, 2000, 5)
assert abs(t - 400) < 1, f"Constant 5 m/s for 2000 m must take 400 s; the model says {t:.1f}"
assert abs(w - 100) < 1e-9, f"At the 5 cm core the motor must turn at 5 / 0.05 = 100 rad/s, got {w}"
assert time_to_empty(0.05, 0.6, 2000, 10)[0] < t, "Pull faster, empty sooner"
---show
k = (0.6**2 - 0.05**2) / (2 * 2000)
def sf(state, t, system):
    y, r = state
    return 5, -k * 5 / r
def ev(state, t, system):
    return state.r - 0.05
res, _ = run_ode_solver(System(init=State(y=0.0, r=0.6), t_end=4000), sf, events=ev)
plt.plot(res.index, 5 / res.r.values)
decorate(xlabel="Time (s)", ylabel="Motor speed command ω (rad/s)", title="Constant line speed: the motor speeds up sharply near the core")
```
