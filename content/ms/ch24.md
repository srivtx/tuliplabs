## Rotation, the same way as motion

A spinning object has an **angle** θ (radians) and an **angular velocity** ω = dθ/dt (radians per second). A point at radius r on the rim moves at linear speed **v = r·ω**. One full turn is 2π radians.

```predict
r, omega = 0.05, 10           # metres, radians per second
print(r * omega)               # rim speed in m/s
print(round(2 * pi / omega, 3)) # seconds per turn
```

## The toilet paper problem

The book's example: a roll of toilet paper with core radius R_min = 2 cm, full radius R_max = 5.5 cm, and paper length L = 47 m. If you pull it so the roll turns at a constant ω = 10 rad/s, how long until it's empty?

As paper comes off, the radius shrinks, so each turn delivers less paper. Each turn removes a layer of thickness k·2π, where the book finds k from the geometry: the area of the paper's cross-section (π(R_max² − R_min²)) equals its length times its thickness, giving

k = (R_max² − R_min²) / (2L)

```exercise
def compute_k(R_min, R_max, L):
    return (R_max**2 - R_min**2) / (2 * L)
---tests
k = compute_k(0.02, 0.055, 47)

```

## The state and the slope function

State: θ (angle turned), y (paper unrolled, in metres), r (current radius). With constant ω:

- dθ/dt = ω
- dy/dt = r·ω (the rim speed)
- dr/dt = −k·ω (the roll shrinks)

```exercise
title: slope_func for unrolling
kind: write
---prompt
Write `slope_func(state, t, system)` returning `(dθ/dt, dy/dt, dr/dt)` as above. `system` has `omega` and `k`.
---starter
def slope_func(state, t, system):
    theta, y, r = state
    pass
---solution
def slope_func(state, t, system):
    theta, y, r = state
    omega, k = system.omega, system.k
    dydt = r * omega
    drdt = -k * omega
    return omega, dydt, drdt
---tests
d = slope_func(State(theta=0.0, y=0.0, r=0.05), 0, System(omega=10, k=2.8e-5))
assert abs(d[0] - 10) < 1e-12 and abs(d[1] - 0.5) < 1e-12 and abs(d[2] + 2.8e-4) < 1e-12, f"Expected (10, 0.5, -0.00028), got {d}"
---show
```

```run
title: Unroll until empty
def slope_func(state, t, system):
    theta, y, r = state
    return system.omega, r * system.omega, -system.k * system.omega

def event_func(state, t, system):
    theta, y, r = state
    return system.L - y          # zero when all the paper is out

k = (0.055**2 - 0.02**2) / (2 * 47)
system = System(init=State(theta=0.0, y=0.0, r=0.055), omega=10, k=k, L=47, t_end=200)
results, details = run_ode_solver(system, slope_func, events=event_func)
print(f"empty after {get_last_label(results):.1f} s; final radius {get_last_value(results.r) * 100:.2f} cm")
plot(results.r * 100, label="radius (cm)")
decorate(xlabel="Time (s)", ylabel="Radius (cm)")
```

```quiz
The final radius comes out at about 2.0 cm, the core radius, even though we never told the model to stop there. Why is that a good sign?
- It's a coincidence
* k was derived from R_min, R_max and L; unrolling exactly L metres should bring the radius back to R_min, so the match checks the model's consistency
- The event stops at the core
- The solver rounds to 2 cm
> The event stops when y = L. Landing on R_min at that moment confirms that the geometry (k) and the dynamics agree. Checks like this catch bugs.
```

```recall
Q: How does the toilet paper model connect rotation to linear motion?
A: - The rim moves at v = r·ω, so paper comes off at dy/dt = r·ω.
- Each radian unrolled removes thickness k, so dr/dt = −k·ω with k = (R_max² − R_min²)/(2L).
- With constant ω, θ grows steadily while the paper comes out more slowly as r shrinks; an event stops at y = L.
```
