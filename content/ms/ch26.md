## The bungee dunk

The book's final case study: a jumper leaps from a crane 80 m up, attached to a bungee cord 25 m long. The stunt is to dip into a cup of tea at the very bottom (a "bungee dunk"). What spring constant should the cord have so the jumper's lowest point is exactly at the ground?

Three forces act on the jumper:

- **gravity**: m·g downward;
- **drag**: from a terminal velocity of 60 m/s for a falling human, as in chapter 21;
- **the cord**: nothing while slack; once the jumper has fallen more than L, it pulls up with **Hooke's law**, F = k·(stretch).

```predict
y_attach, L, k = 80, 25, 40
for y in [70, 55, 50]:
    stretch = max(y_attach - y - L, 0)
    print(y, stretch, k * stretch)
```

## The spring force

```exercise
title: spring_force
kind: write
---prompt
Write `spring_force(y, system)`: the upward force from the cord when the jumper is at height `y`. The distance fallen is `system.y_attach - y`; the cord stretches by `distance - system.L` when that's positive, and the force is `system.k * stretch`. Return 0 when the cord is slack.
---starter
def spring_force(y, system):
    pass
---solution
def spring_force(y, system):
    distance_fallen = system.y_attach - y
    if distance_fallen <= system.L:
        return 0
    extension = distance_fallen - system.L
    return system.k * extension
---tests
assert spring_force(60, params) == 0, "20 m below the attachment: the 25 m cord is slack"
assert spring_force(45, params) == 400, "35 m fallen: 10 m stretch x 40 N/m = 400 N"
assert spring_force(55, params) == 0, "Exactly at the cord's length: no force yet"
```

```exercise
title: slope_func for the jumper
kind: write
---prompt
Write `slope_func(state, t, system)`. State is `(y, v)`. Use: drag acceleration `a_drag = -system.C_d_term * v * abs(v)` (it opposes the motion; `C_d_term` is precomputed for you as g / v_term²), gravity `-g`, and the spring's acceleration `spring_force(y, system) / mass`. Return `(v, a)`. `spring_force` is defined.
---setup
def spring_force(y, system):
    d = system.y_attach - y
    return 0 if d <= system.L else system.k * (d - system.L)
---starter
def slope_func(state, t, system):
    y, v = state
    pass
---solution
def slope_func(state, t, system):
    y, v = state
    a_drag = -system.C_d_term * v * abs(v)
    a_spring = spring_force(y, system) / system.mass
    a = -system.g + a_drag + a_spring
    return v, a
---tests
s = System(params, C_d_term=9.8 / 60**2)
d = slope_func(State(y=80.0, v=0.0), 0, s)
assert d == (0.0, -9.8), "At the top, at rest: only gravity"
d = slope_func(State(y=45.0, v=0.0), 0, s)
assert abs(d[1] - (-9.8 + 400 / 75)) < 1e-9, "35 m down, momentarily stopped: gravity plus the cord"
d = slope_func(State(y=70.0, v=-60.0), 0, s)
assert abs(d[1]) < 1e-9, "Falling at terminal velocity with a slack cord: no acceleration"
```

## The jump

```run
title: One jump with k = 40 N/m
def spring_force(y, system):
    d = system.y_attach - y
    return 0 if d <= system.L else system.k * (d - system.L)

def slope_func(state, t, system):
    y, v = state
    a = -system.g - system.C_d_term * v * abs(v) + spring_force(y, system) / system.mass
    return v, a

def make_system(params):
    init = State(y=float(params.y_attach), v=float(params.v_init))
    return System(params, init=init, C_d_term=params.g / params.v_term**2)

system = make_system(params)
results, _ = run_ode_solver(system, slope_func, t_eval=linspace(0, params.t_end, 401))
plot(results.y, label="height")
plt.axhline(0, color="gray", lw=0.8)
decorate(xlabel="Time (s)", ylabel="Height (m)")
print(f"lowest point: {results.y.min():.1f} m above the ground")
```

## Design the cord

```exercise
title: lowest point
kind: rebuild
---prompt
From memory: `lowest_point(k, params)` builds a system with cord stiffness `k`, runs until the jumper starts coming back up (stop with an event on the velocity, after the first moment), and returns the minimum height. `make_system`, `slope_func` and `spring_force` are defined.
---setup
def spring_force(y, system):
    d = system.y_attach - y
    return 0 if d <= system.L else system.k * (d - system.L)

def slope_func(state, t, system):
    y, v = state
    a = -system.g - system.C_d_term * v * abs(v) + spring_force(y, system) / system.mass
    return v, a

def make_system(params):
    init = State(y=float(params.y_attach), v=float(params.v_init))
    return System(params, init=init, C_d_term=params.g / params.v_term**2)
---starter
def lowest_point(k, params):
    pass
---solution
def lowest_point(k, params):
    system = make_system(params.set(k=k))

    def event_func(state, t, system):
        y, v = state
        return v if t > 0.1 else -1

    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_value(results.y)
---tests
low40 = lowest_point(40, params)
assert -40 < low40 < 20, f"A sensible lowest point for k = 40, got {low40:.1f}"
assert lowest_point(80, params) > low40, "A stiffer cord stops the jumper higher up"
---show
res = root_bisect(lambda k: lowest_point(k, params), [20, 200])
print(f"For a perfect bungee dunk (lowest point at 0 m) the cord needs k = {res.root:.1f} N/m")
ks = linspace(20, 120, 11)
sweep = SweepSeries()
for k in ks:
    sweep[k] = lowest_point(k, params)
plot(sweep, "o-"); plt.axhline(0, color="gray", lw=0.8)
decorate(xlabel="Spring constant k (N/m)", ylabel="Lowest point (m)", title="Designing the cord with your lowest_point")
```

```quiz
Why does the event for the lowest point need the condition `t > 0.1`?
- Python needs a time limit
* At the very start v = 0, which would trigger "velocity crosses zero" immediately; ignoring the first moment lets the jump happen
- The cord isn't attached at t = 0
- It makes the solver faster
> The jumper starts at rest, so v is zero at t = 0. Returning a nonzero value for the first instant keeps the event from firing before anything happens.
```
