```prelude
from modsim import *

census = TimeSeries({1950: 2.558, 1955: 2.782, 1960: 3.043, 1965: 3.350, 1970: 3.712,
                     1975: 4.089, 1980: 4.452, 1985: 4.855, 1990: 5.288, 1995: 5.700,
                     2000: 6.090, 2005: 6.474, 2010: 6.864, 2015: 7.256, 2016: 7.333})

def run_simulation(system, update_func):
    results = TimeSeries()
    results[system.t_0] = system.p_0
    for t in linrange(system.t_0, system.t_end):
        results[t + 1] = update_func(results[t], t, system)
    return results
```

## Growth slows as the world fills

Proportional growth keeps accelerating, but the data show growth slowing. One explanation: as population rises, resources get scarcer, so the growth **rate** falls. The simplest way to model that is to make the net growth depend on p²:

net growth = alpha·p + beta·p²

with alpha > 0 (people have children) and beta < 0 (crowding slows growth). The book's values: alpha = 0.025, beta = −0.0018.

```exercise
title: update_func_quad
kind: write
---prompt
Write the quadratic update function using `system.alpha` and `system.beta`.
---starter
def update_func_quad(pop, t, system):
    pass
---solution
def update_func_quad(pop, t, system):
    net_growth = system.alpha * pop + system.beta * pop**2
    return pop + net_growth
---tests
s = System(alpha=0.025, beta=-0.0018)
assert abs(update_func_quad(10.0, 0, s) - (10 + 0.25 - 0.18)) < 1e-9, "At p=10: growth 0.25 - 0.18 = 0.07"
assert abs(update_func_quad(0.025 / 0.0018, 0, s) - 0.025 / 0.0018) < 1e-9, "At p = -alpha/beta growth is zero"
```

```run
title: Quadratic growth vs data
def update_func_quad(pop, t, system):
    return pop + system.alpha * pop + system.beta * pop**2

system = System(t_0=1950, t_end=2016, p_0=census[1950], alpha=0.025, beta=-0.0018)
results = run_simulation(system, update_func_quad)
plot(census, "o", label="US Census")
plot(results, color="gray", label="quadratic model")
decorate(xlabel="Year", ylabel="World population (billion)", title="Quadratic growth")
```

## Equilibrium

Growth stops when alpha·p + beta·p² = 0. Apart from p = 0, that's when p = −alpha/beta. This is the **equilibrium**: a population that, once reached, stays the same. Ecologists call it the **carrying capacity**.

```predict
alpha, beta = 0.025, -0.0018
print(round(-alpha / beta, 2))
```

```exercise
title: Find equilibrium by simulation
kind: write
---prompt
Write `long_run(system, update_func, years)`: start at `system.p_0` and apply `update_func(pop, t, system)` for `years` steps (t can be anything; use the loop index). Return the final population. The check confirms it approaches −alpha/beta.
---setup
def update_func_quad(pop, t, system):
    return pop + system.alpha * pop + system.beta * pop**2
---starter
def long_run(system, update_func, years):
    pass
---solution
def long_run(system, update_func, years):
    pop = system.p_0
    for t in range(years):
        pop = update_func(pop, t, system)
    return pop
---tests
s = System(p_0=2.5, alpha=0.025, beta=-0.0018)
p = long_run(s, update_func_quad, 1000)
assert abs(p - 0.025 / 0.0018) < 0.01, f"After 1000 years it should be near 13.89, got {p:.3f}"
s2 = System(p_0=20.0, alpha=0.025, beta=-0.0018)
assert abs(long_run(s2, update_func_quad, 1000) - 13.89) < 0.01, "Starting above the equilibrium, it comes down to it"
```

```quiz
Starting above the carrying capacity, the population falls toward it; starting below, it rises toward it. What kind of equilibrium is that?
* Stable: small departures shrink back
- Unstable: small departures grow
- Neutral: it stays wherever it starts
- Not an equilibrium at all
> If net growth is negative above the equilibrium and positive below, the system always moves back toward it: a stable equilibrium. p = 0 is the other equilibrium, and it's unstable.
```

## Dysfunctions

The book's list of common function mistakes: a function that **prints** instead of returning, one that reads **global** variables instead of its parameters, and one that **changes** its arguments when the caller doesn't expect it.

```exercise
title: The global-variable bug
kind: bug
---prompt
This update function ignores the `system` it's given and reads a global variable instead. So when you pass a different system, nothing changes. Fix it to use its parameter.
---setup
alpha = 0.025
---starter
def update_func(pop, t, system):
    return pop + alpha * pop
---solution
def update_func(pop, t, system):
    return pop + system.alpha * pop
---tests
assert abs(update_func(100.0, 0, System(alpha=0.5)) - 150.0) < 1e-9, "With system.alpha = 0.5, 100 should become 150"
---hint
Read the growth rate from `system`, not from the global name.
```

```recall
Q: What's the equilibrium of the quadratic model, why does the model have one, and is it stable?
A: - Net growth alpha·p + beta·p² is zero at p = −alpha/beta (≈ 13.9 billion with the book's values).
- Because beta < 0, crowding grows faster than births as p rises, so growth hits zero.
- It's stable: above it net growth is negative, below it positive, so the population moves toward it.
```
