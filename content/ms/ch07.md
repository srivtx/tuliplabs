```prelude
from modsim import *

census = TimeSeries({1950: 2.558, 1955: 2.782, 1960: 3.043, 1965: 3.350, 1970: 3.712,
                     1975: 4.089, 1980: 4.452, 1985: 4.855, 1990: 5.288, 1995: 5.700,
                     2000: 6.090, 2005: 6.474, 2010: 6.864, 2015: 7.256, 2016: 7.333})

def run_simulation(system, update_func):
    results = TimeSeries()
    results[system.t_0] = system.p_0
    for t in linrange(system.t_0, system.t_end):
        results[t + 1] = update_func(results[t], t, system)
    return results
```

## Growth slows as the world fills

Proportional growth keeps accelerating, but the data show growth slowing. One explanation: as population rises, resources get scarcer, so the growth **rate** falls. The simplest way to model that is to make the net growth depend on p²:

net growth = alpha·p + beta·p²

with alpha > 0 (people have children) and beta < 0 (crowding slows growth). Typical values: alpha = 0.025, beta = −0.0018.

```exercise
title: update_func_quad
kind: write
---prompt
Write the quadratic update function using `system.alpha` and `system.beta`.
---starter
def update_func_quad(pop, t, system):
    pass
---solution
def update_func_quad(pop, t, system):
    net_growth = system.alpha * pop + system.beta * pop**2
    return pop + net_growth
---tests
s = System(alpha=0.025, beta=-0.0018)
assert abs(update_func_quad(10.0, 0, s) - (10 + 0.25 - 0.18)) < 1e-9, "At p=10: growth 0.25 - 0.18 = 0.07"
assert abs(update_func_quad(0.025 / 0.0018, 0, s) - 0.025 / 0.0018) < 1e-9, "At p = -alpha/beta growth is zero"
```

```run
title: Quadratic growth vs data
def update_func_quad(pop, t, system):
    return pop + system.alpha * pop + system.beta * pop**2

system = System(t_0=1950, t_end=2016, p_0=census[1950], alpha=0.025, beta=-0.0018)
results = run_simulation(system, update_func_quad)
plot(census, "o", label="US Census")
plot(results, color="gray", label="quadratic model")
decorate(xlabel="Year", ylabel="World population (billion)", title="Quadratic growth")
```

## Equilibrium

Growth stops when alpha·p + beta·p² = 0. Apart from p = 0, that's when p = −alpha/beta. This is the **equilibrium**: a population that, once reached, stays the same. Ecologists call it the **carrying capacity**.

```predict
alpha, beta = 0.025, -0.0018
print(round(-alpha / beta, 2))
```

```exercise
title: Find equilibrium by simulation
kind: write
---prompt
Write `long_run(system, update_func, years)`: start at `system.p_0` and apply `update_func(pop, t, system)` for `years` steps (t can be anything; use the loop index). Return the final population. The check confirms it approaches −alpha/beta.
---setup
def update_func_quad(pop, t, system):
    return pop + system.alpha * pop + system.beta * pop**2
---starter
def long_run(system, update_func, years):
    pass
---solution
def long_run(system, update_func, years):
    pop = system.p_0
    for t in range(years):
        pop = update_func(pop, t, system)
    return pop
---tests
s = System(p_0=2.5, alpha=0.025, beta=-0.0018)
p = long_run(s, update_func_quad, 1000)
assert abs(p - 0.025 / 0.0018) < 0.01, f"After 1000 years it should be near 13.89, got {p:.3f}"
s2 = System(p_0=20.0, alpha=0.025, beta=-0.0018)
assert abs(long_run(s2, update_func_quad, 1000) - 13.89) < 0.01, "Starting above the equilibrium, it comes down to it"
```

```quiz
Starting above the carrying capacity, the population falls toward it; starting below, it rises toward it. What kind of equilibrium is that?
* Stable: small departures shrink back
- Unstable: small departures grow
- Neutral: it stays wherever it starts
- Not an equilibrium at all
> If net growth is negative above the equilibrium and positive below, the system always moves back toward it: a stable equilibrium. p = 0 is the other equilibrium, and it's unstable.
```

## Dysfunctions

Common function mistakes: a function that **prints** instead of returning, one that reads **global** variables instead of its parameters, and one that **changes** its arguments when the caller doesn't expect it.

```exercise
title: The global-variable bug
kind: bug
---prompt
This update function ignores the `system` it's given and reads a global variable instead. So when you pass a different system, nothing changes. Fix it to use its parameter.
---setup
alpha = 0.025
---starter
def update_func(pop, t, system):
    return pop + alpha * pop
---solution
def update_func(pop, t, system):
    return pop + system.alpha * pop
---tests
assert abs(update_func(100.0, 0, System(alpha=0.5)) - 150.0) < 1e-9, "With system.alpha = 0.5, 100 should become 150"
---hint
Read the growth rate from `system`, not from the global name.
```

```recall
Q: What's the equilibrium of the quadratic model, why does the model have one, and is it stable?
A: - Net growth alpha·p + beta·p² is zero at p = −alpha/beta (≈ 13.9 billion with these values).
- Because beta < 0, crowding grows faster than births as p rises, so growth hits zero.
- It's stable: above it net growth is negative, below it positive, so the population moves toward it.
```

## Real-world project: a safe fishing quota for a lake

The quadratic model is the standard starting point for managing fish, deer and forests. A lake has a carrying capacity, and the stock grows fastest when it is about half full (that's where alpha·p + beta·p² is biggest). Take out a fixed catch every year and the equilibrium moves. Take out too much and there's no equilibrium left at all: the stock **collapses**. The model tells you where that cliff edge is.

```project
title: Annual fishing quota for a lake
client: A regional fisheries office setting next year's licence limits
skills: quadratic growth, equilibrium, update functions with an extra term, testing for collapse
---brief
Surveys say the lake's trout follow the quadratic model with alpha = 0.4 and beta = −0.0004 (stock in tonnes, so the carrying capacity is 1,000 t). The office wants the largest yearly catch that doesn't wipe the trout out, and a check they can run on any proposed quota: "does the stock survive 100 years of this?"
---why
Fisheries really do set quotas from this model (it's called the maximum sustainable yield). The software pattern is broader: subtract a constant drain from a self-replenishing resource and look for the tipping point. It's the same shape as a cache under load, a battery being topped up by solar, or a support team with a backlog that grows faster than they can clear it.
---milestones
- Write `update_fish(pop, t, system)`: quadratic growth minus `system.catch`, never below zero
- Plot 50 years for catches of 60, 90 and 110 tonnes from a stock of 800 t
- Write `collapses(system, update_func, years)` that says whether the stock hits zero
- Work out the largest safe catch by algebra (the peak of alpha·p + beta·p²) and check it with your function
- Recommend a quota with a safety margin, and say why the margin matters
---stretch
- Make the catch a fraction of the stock instead of a fixed amount, and compare how safe each rule is
- Add a bad year: growth halves for one year. Which quotas survive it?
- Sweep the catch from 0 to 120 and plot the long-run stock
```

```exercise
title: update_fish with a yearly catch
kind: fill
---prompt
Fill in the blanks: next year's stock is this year's plus quadratic growth, minus the catch. Fish can't go negative, so return 0 if the result would be below zero.
---starter
def update_fish(pop, t, system):
    growth = ____
    new_pop = pop + growth - system.catch
    return ____
---solution
def update_fish(pop, t, system):
    growth = system.alpha * pop + system.beta * pop**2
    new_pop = pop + growth - system.catch
    return max(new_pop, 0)
---tests
s = System(alpha=0.4, beta=-0.0004, catch=90)
assert abs(update_fish(800.0, 0, s) - (800 + 320 - 256 - 90)) < 1e-9, f"At 800 t: growth 320 - 256 = 64, minus a 90 t catch: 774. Got {update_fish(800.0, 0, s)}"
assert update_fish(50.0, 0, s) == 0, "A tiny stock can't support a 90 t catch: it drops to 0, not below"
assert abs(update_fish(500.0, 0, s.set(catch=0)) - 600.0) < 1e-9, "No fishing: 500 grows by 200 - 100 = 100"
---hint
`max(new_pop, 0)` keeps it from going below zero.
```

```exercise
title: collapses
kind: write
---prompt
Write `collapses(system, update_func, years)`: start at `system.p_0`, apply `update_func(pop, t, system)` for `years` steps, and return `True` as soon as the stock reaches 0, or `False` if it survives every year. `update_fish` is provided.
---setup
def update_fish(pop, t, system):
    return max(pop + system.alpha * pop + system.beta * pop**2 - system.catch, 0)
---starter
def collapses(system, update_func, years):
    return False
---solution
def collapses(system, update_func, years):
    pop = system.p_0
    for t in range(years):
        pop = update_func(pop, t, system)
        if pop <= 0:
            return True
    return False
---tests
lake = System(p_0=800.0, alpha=0.4, beta=-0.0004, catch=90)
assert collapses(lake, update_fish, 100) is False, "90 t a year is below the maximum sustainable yield of 100 t: the trout survive"
assert collapses(lake.set(catch=110), update_fish, 100) is True, "110 t a year is more than the lake can ever regrow: collapse"
assert collapses(lake.set(p_0=300.0), update_fish, 100) is True, "Even a 'safe' 90 t catch collapses a stock that starts too low (below about 342 t)"
max_catch = -lake.alpha**2 / (4 * lake.beta)
assert collapses(lake.set(catch=max_catch - 1), update_fish, 200) is False, "Just under -alpha^2/(4 beta) = 100 t should be sustainable from 800 t"
---hint
Check `pop <= 0` inside the loop, right after each update, and `return True` there.
```
