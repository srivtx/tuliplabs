```prelude
from modsim import *

def drag_force(V, system):
    return -V.hat() * (system.rho * V.mag**2 * system.C_d * system.area / 2)

def slope_func(state, t, system):
    R, V = state
    return V, Vector(0, -system.g) + drag_force(V, system) / system.mass

def event_func(state, t, system):
    R, V = state
    return R.y

params = Params(x=0, y=1, g=9.8, mass=0.145, diameter=0.073, rho=1.2,
                C_d=0.33, angle=45, speed=40, t_end=20)

def make_system(params):
    theta = np.deg2rad(params.angle)
    V = Vector(*pol2cart(theta, params.speed))
    init = State(R=Vector(params.x, params.y), V=V)
    area = pi * (params.diameter / 2) ** 2
    return System(params, init=init, area=area)
```

## The problem

Fenway Park in Boston has a famous left-field wall, the **Green Monster**: 11.3 m high, about 94.5 m from home plate. The book asks: what's the **minimum speed** a ball needs to clear it, if the batter picks the best angle? Two steps: find the best angle for a given speed, then the lowest speed that clears the wall.

## Let the optimizer search

Sweeping works, but `maximize(func, [low, high], *args)` finds the best value precisely using a **golden-section search**: it keeps shrinking the bracket around the maximum.

```run
title: Best angle at 40 m/s
def range_func(angle, params):
    system = make_system(params.set(angle=angle))
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_value(results.R).x

res = maximize(range_func, [0, 90], params)
print(f"best angle {res.x:.1f} degrees, range {res.fun:.1f} m")
```

```quiz
Without air the best angle is exactly 45°. With drag the optimizer finds a smaller angle. Why does drag favour a flatter launch?
- Drag pushes the ball forward
* A higher arc keeps the ball in the air longer, giving drag more time to slow it, so trading a little height for horizontal speed pays off
- Gravity is weaker at lower angles
- The optimizer has a bug
> Drag punishes time in flight. A slightly flatter trajectory spends less time losing speed, so the optimum moves below 45°.
```

## The Green Monster

Now find the height of the ball when it reaches the wall. Use an event that fires when **x reaches the wall**.

```exercise
title: height at the wall
kind: write
---prompt
Write `height_at_wall(speed, params, wall_x=94.5)`: at the given speed and at the best angle for that speed (use `maximize` with `range_func`, which is defined), run until the ball reaches `wall_x` and return its height there. If the ball lands before the wall, return `0`.
---setup
def range_func(angle, params):
    system = make_system(params.set(angle=angle))
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_value(results.R).x
---starter
def height_at_wall(speed, params, wall_x=94.5):
    pass
---solution
def height_at_wall(speed, params, wall_x=94.5):
    p = params.set(speed=speed)
    best = maximize(range_func, [0, 90], p)
    system = make_system(p.set(angle=best.x))

    def wall_event(state, t, system):
        R, V = state
        return R.x - wall_x

    results, details = run_ode_solver(system, slope_func, events=[wall_event, event_func])
    R = get_last_value(results.R)
    return R.y if R.x >= wall_x - 1e-6 else 0
---tests
assert height_at_wall(30, params) == 0, "At 30 m/s the ball doesn't reach the wall"
h = height_at_wall(45, params)
assert 15 < h < 30, f"At 45 m/s the ball passes the wall well above it, got {h:.1f} m"
---hint
Pass two events, `[wall_event, event_func]`: whichever happens first stops the run. Check whether the final x reached the wall.
```

```run
title: The minimum speed to clear the wall
def range_func(angle, params):
    system = make_system(params.set(angle=angle))
    results, details = run_ode_solver(system, slope_func, events=event_func)
    return get_last_value(results.R).x

def height_at_wall(speed, params, wall_x=94.5):
    p = params.set(speed=speed)
    system = make_system(p.set(angle=maximize(range_func, [0, 90], p).x))
    def wall_event(state, t, system):
        R, V = state
        return R.x - wall_x
    results, _ = run_ode_solver(system, slope_func, events=[wall_event, event_func])
    R = get_last_value(results.R)
    return R.y if R.x >= wall_x - 1e-6 else 0

def error_func(speed, params):
    return height_at_wall(speed, params) - 11.3      # the wall is 11.3 m high

res = root_bisect(error_func, [38, 45], params, xtol=0.01)
print(f"minimum speed to clear the Green Monster: about {res.root:.1f} m/s")
```

```recall
Q: Describe the two-level search the Manny Ramirez problem uses.
A: - Inner: for a given speed, `maximize` searches over launch angle (each evaluation runs a full simulation) to find the best angle.
- Outer: `root_bisect` searches over speed for the value where the ball's height at the wall, at its best angle, equals the wall's height.
- Each level wraps a simulation in a function of one parameter, so standard optimizers and root finders can drive it.
```
