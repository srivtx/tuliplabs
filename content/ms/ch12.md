```prelude
from modsim import *

def make_system(beta, gamma):
    init = State(S=89/90, I=1/90, R=0.0)
    return System(init=init, t_0=0, t_end=7 * 14, beta=beta, gamma=gamma)

def update_func(state, t, system):
    s, i, r = state
    infected = system.beta * i * s
    recovered = system.gamma * i
    return State(S=s - infected, I=i + infected - recovered, R=r + recovered)

def run_simulation(system, update_func):
    frame = TimeFrame(columns=system.init.index)
    frame.row[system.t_0] = system.init
    for t in linrange(system.t_0, system.t_end):
        frame.row[t + 1] = update_func(frame.row[t], t, system)
    return frame
```

```quiz
Vaccinating the first 10% prevents far more than 10% of infections. Why?
- Vaccines also cure people
* Each vaccinated person is one fewer link in the chain, so they protect others too; near the threshold, small increases can stop the epidemic
- The model double-counts
- Vaccinated people recover faster
> Removing susceptibles slows transmission for everyone (herd immunity). The curve is steepest at first and flattens once the epidemic is mostly prevented.
```

## Hand washing, and a budget

The health centre has **$1200**. Doses cost **$100** each. A hand-washing campaign reduces β, with **diminishing returns**: we model the effect with a logistic curve of spending.

```run
title: Split the budget between vaccines and hand washing
def calc_total_infected(results):
    return get_first_value(results.S) - get_last_value(results.S)

def add_immunization(system, fraction):
    system.init.S -= fraction
    system.init.R += fraction

def compute_factor(spending):
    return 0.2 / (1 + exp(-0.01 * (spending - 500)))

budget, price_per_dose, num_students = 1200, 100, 90
sweep = SweepSeries()
for doses in range(0, budget // price_per_dose + 1):
    system = make_system(1/3, 1/4)
    add_immunization(system, doses / num_students)
    system.beta *= 1 - compute_factor(budget - doses * price_per_dose)
    sweep[doses] = calc_total_infected(run_simulation(system, update_func))
plot(sweep, "o-")
decorate(xlabel="Doses of vaccine (rest of budget on hand washing)", ylabel="Total fraction infected")
print("best number of doses:", sweep.idxmin(), "  infected:", round(sweep.min(), 3))
```

```quiz
The best split isn't "all vaccines" or "all hand washing". What modeling idea produces an interior optimum like this?
- Randomness
* Diminishing returns: the logistic campaign gives most of its benefit for the first few hundred dollars, so spending everything there wastes money that vaccines would use better
- The epidemic is too short
- Hand washing doesn't work
> When one option's benefit flattens out, the last dollar does more good elsewhere. The sweep finds where the marginal benefits balance.
```

```recall
Q: How does the model represent vaccination and hand washing, and how do we choose between them?
A: - Vaccination: move a fraction of the population from S to R before the start.
- Hand washing: reduce β by a factor that depends on spending through a logistic (diminishing-returns) curve.
- For each way of splitting the budget, run the simulation and compute total infected; sweep the split and pick the minimum.
```

## Real-world project: keep the infirmary from overflowing

Metrics turn a simulation into a decision. "Total infected" is one metric; a hospital manager cares more about another: **the most people sick at the same time**, because that's what has to fit in the beds.

```project
title: Cheapest plan that keeps the infirmary under capacity
client: A university health centre with 2 isolation beds
skills: metrics, interventions as parameter changes, comparing plans, cost constraints
---brief
The health centre can pick one plan: do nothing, a hand-washing campaign, extra vaccine doses, or both, and each has a cost and an effect on beta or on the starting susceptible fraction. Simulate every plan, compute the **peak number sick at once**, and recommend the **cheapest plan** whose peak fits in 2 beds.
---why
"Flatten the curve" in 2020 was this exact metric: not how many get sick in total, but whether the peak fits the hospital. Choosing the cheapest option that meets a constraint is the everyday shape of engineering decisions too, from picking cloud instance sizes to meeting a latency target at minimum cost.
---milestones
- Write `max_sick(results, n)`: the peak of `I` converted to people
- Describe each plan as a name, a cost, a beta multiplier and a vaccinated fraction
- Simulate each plan and record cost and peak
- Write `cheapest_safe(plans, beds)` to pick the winner, or report that none is safe
- Present the table sorted by cost, with the safe plans marked
---stretch
- Add "days over capacity" as a second metric and use it to break ties
- Sweep the hand-washing budget finely and find the minimum spend that's safe
- Make the beds a parameter and plot "cheapest safe cost" against number of beds
```

```exercise
title: cheapest_safe
kind: write
---prompt
Write `cheapest_safe(plans, beds, n=90)`. Each plan is a dict with `"name"`, `"cost"`, `"beta_factor"` and `"vaccinated"` (fraction moved from S to R at the start). For each plan: `system = make_system(1/3, 1/4)`, multiply `system.beta` by the factor, apply the vaccination with `add_immunization(system, fraction)` (defined), run `run_simulation(system, update_func)` and compute the peak sick `results.I.max() * n`. Return the **name** of the cheapest plan whose peak is at most `beds`, or `None`.
---setup
def add_immunization(system, fraction):
    system.init.S -= fraction
    system.init.R += fraction
---starter
def cheapest_safe(plans, beds, n=90):
    return plans[0]["name"]
---solution
def cheapest_safe(plans, beds, n=90):
    safe = []
    for plan in plans:
        system = make_system(1/3, 1/4)
        system.beta *= plan["beta_factor"]
        add_immunization(system, plan["vaccinated"])
        results = run_simulation(system, update_func)
        if results.I.max() * n <= beds:
            safe.append(plan)
    if not safe:
        return None
    return min(safe, key=lambda p: p["cost"])["name"]
---tests
plans = [
    {"name": "nothing", "cost": 0, "beta_factor": 1.0, "vaccinated": 0.0},
    {"name": "hand washing", "cost": 500, "beta_factor": 0.8, "vaccinated": 0.0},
    {"name": "vaccines", "cost": 1200, "beta_factor": 1.0, "vaccinated": 0.3},
    {"name": "both", "cost": 1700, "beta_factor": 0.8, "vaccinated": 0.3},
]
assert cheapest_safe(plans, 100) == "nothing", "with 100 beds, doing nothing is already safe and costs 0"
pick = cheapest_safe(plans, 2)
assert pick == "hand washing", f"with 2 beds, doing nothing peaks near 4 sick; hand washing (cost 500) fits and is cheapest; got {pick}"
assert cheapest_safe(plans, 1.05) == "vaccines", "with room for barely 1, only plans that vaccinate keep the peak that low"
assert cheapest_safe(plans, 0) is None, "no plan fits zero beds"
---hint
Simulate every plan, keep the ones whose peak fits, then `min(safe, key=lambda p: p["cost"])`.
```
