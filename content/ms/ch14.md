```prelude
from modsim import *

def make_system(beta, gamma):
    init = State(S=89/90, I=1/90, R=0.0)
    return System(init=init, t_0=0, t_end=7 * 28, beta=beta, gamma=gamma)

def update_func(state, t, system):
    s, i, r = state
    infected = system.beta * i * s
    recovered = system.gamma * i
    return State(S=s - infected, I=i + infected - recovered, R=r + recovered)

def run_simulation(system, update_func):
    frame = TimeFrame(columns=system.init.index)
    frame.row[system.t_0] = system.init
    for t in linrange(system.t_0, system.t_end):
        frame.row[t + 1] = update_func(frame.row[t], t, system)
    return frame
```

## The contact number

Chapter 13's contour lines were straight lines through the origin, so only the ratio **c = β/γ** seems to matter. c is the **contact number**: the number of new infections one infected person causes in a fully susceptible population during their illness (β contacts per day × 1/γ days). It's what epidemiologists call R₀.

Removing units this way, so a model depends on fewer combined parameters, is **nondimensionalization**.

```predict
beta, gamma = 1/3, 1/4
print(round(beta / gamma, 4))
print(round(1/3 / (1/6), 4), round(0.5 / 0.375, 4))
```

```quiz
What happens when c < 1?
* Each case causes less than one new case on average, so the outbreak fizzles out
- Everyone gets sick slowly
- The epidemic peaks later but is just as big
- The model breaks
> c is the average number of new infections per case at the start. Below 1, the number infected shrinks from the beginning. c = 1 is the threshold, another phase transition like those in Think Complexity.
```

## An equation for the final size

The book derives a relation (by dividing the S and R equations and integrating) between c and the final fraction of susceptibles, s∞, for an outbreak that starts with almost everyone susceptible:

c = ln(s∞) / (s∞ − 1)

We can't easily solve for s∞, but going the other way is easy, and that's enough to plot it.

```exercise
title: c from s_inf

---prompt

---starter

    pass
---solution
def contact_from_s_inf(s_inf):
    return log(s_inf) / (s_inf - 1)
---tests
assert abs(contact_from_s_inf(0.5) - 1.3863) < 1e-4, "s_inf = 0.5 corresponds to c = ln(0.5)/(-0.5) = 1.386"

```

## Estimating c from an outbreak

Measuring β and γ separately is hard. But if you know what fraction of a population **didn't** get sick, the relation gives c directly. Suppose 26 of 90 students got sick: s∞ = 64/90.

```exercise
title: Estimate the contact number
kind: rebuild
---prompt
From memory: `estimate_c(num_sick, population)` returns the contact number implied by an outbreak where `num_sick` of `population` got sick (use the final-size relation).
---starter
def estimate_c(num_sick, population):
    pass
---solution
def estimate_c(num_sick, population):
    s_inf = (population - num_sick) / population
    return log(s_inf) / (s_inf - 1)
---tests
assert abs(estimate_c(26, 90) - 1.1801) < 1e-3, f"26 of 90 sick gives c about 1.18, got {estimate_c(26, 90):.4f}"
assert estimate_c(45, 90) > estimate_c(26, 90), "More people sick means a bigger contact number"
```

```recall
Q: What is the contact number, why do SIR results depend only on it, and how can you estimate it?
A: - c = β/γ: infecting contacts per day times days infectious, i.e. new cases per case in a fully susceptible population.
- Dividing the SIR equations removes time units; the shape of the outbreak (final size) depends only on the ratio.
- From an observed final fraction of susceptibles s∞, c = ln(s∞)/(s∞ − 1).
```

## Real-world project: an outbreak planner for a campus clinic

The final-size equation is more than a neat formula. If you can guess c for a disease (from last year's outbreak, say), it tells you **how many people will get sick in total** before anyone runs a single simulation. That's exactly the number a clinic needs to plan beds, staff and how many people to vaccinate.

```project
title: Campus outbreak planner
client: A university health clinic preparing for flu season
skills: root finding, the final-size relation, functions of one parameter, what-if tables
---brief
The clinic has 6,000 students. Last winter's flu had a contact number of about 1.8. They want a small tool: type in c, the population and the fraction of students vaccinated, and get back the expected number of cases, so they can decide how many vaccine doses to order. The relation c = ln(s∞)/(s∞ − 1) goes from s∞ to c; your tool needs the other direction, so you'll solve it with a root finder.
---why
Public-health teams do this every season: the "attack rate" (fraction who get sick) from the final-size relation is the first estimate in pandemic plans, school-closure decisions and vaccine orders. In software terms you're turning an equation you can't rearrange into a function you can call, which is the same trick behind loan calculators (solve for the interest rate) and game physics (solve for the launch speed).
---milestones
- Write `final_fraction_sick(c)` by solving the final-size relation with `root_bisect`
- Handle c ≤ 1 (no outbreak) without crashing
- Add vaccination: a vaccinated fraction v shrinks the effective contact number to c·(1 − v)
- Write `expected_cases(c, population, vaccinated)` and print a table for v = 0, 0.2, 0.4
- Find the smallest v that keeps cases under 100 (another root find)
---stretch
- Plot expected cases against v and mark the herd-immunity threshold 1 − 1/c
- Check your answer against the SIR simulation from chapter 13 with the same c
- Add a "beds needed" column using a hospitalisation rate
```

```exercise
title: final_fraction_sick
kind: write
---prompt
Write `final_fraction_sick(c)`: the fraction of people who end up sick, 1 − s∞. Find s∞ with `root_bisect` on `log(s) / (s - 1) - c`, using the bracket `[1e-12, 1 - 1e-9]` (s = 1 exactly would divide by zero). If `c <= 1`, there is no outbreak: return `0.0`.
---starter
def final_fraction_sick(c):
    pass
---solution
def final_fraction_sick(c):
    if c <= 1:
        return 0.0
    def error(s):
        return log(s) / (s - 1) - c
    s_inf = root_bisect(error, [1e-12, 1 - 1e-9]).root
    return 1 - s_inf
---tests
f = final_fraction_sick(1.1801)
assert f is not None, "Return a number, the fraction who get sick"
assert abs(f - 26 / 90) < 1e-3, f"c = 1.18 is the outbreak where 26 of 90 got sick, so expect about {26/90:.3f}, got {f:.4f}"
assert abs(final_fraction_sick(2) - 0.797) < 1e-3, f"c = 2: about 80% get sick, got {final_fraction_sick(2):.4f}"
assert final_fraction_sick(0.8) == 0.0, "c below 1: the outbreak fizzles, nobody extra gets sick"
---hint
The function inside `root_bisect` is zero at the s∞ that matches your c. Near s = 0 it's huge and positive; near s = 1 it is 1 − c, which is negative when c > 1. That's why the bracket works.
---show
cs = linspace(0.5, 4, 36)
plot(TimeSeries({c: final_fraction_sick(c) for c in cs}), "o-")
decorate(xlabel="Contact number c", ylabel="Fraction who get sick", title="Your final_fraction_sick: nothing below c = 1, then a fast rise")
```

```exercise
title: expected_cases with vaccination
kind: write
---prompt
Write `expected_cases(c, population, vaccinated=0.0)`. Vaccinated people can't catch it, so only `population * (1 - vaccinated)` are susceptible, and the effective contact number is `c * (1 - vaccinated)`. Return the number of cases (a float): susceptible people times `final_fraction_sick` of the effective c. `final_fraction_sick` is defined.
---setup
def final_fraction_sick(c):
    if c <= 1:
        return 0.0
    return 1 - root_bisect(lambda s: log(s) / (s - 1) - c, [1e-12, 1 - 1e-9]).root
---starter
def expected_cases(c, population, vaccinated=0.0):
    return population * final_fraction_sick(c)
---solution
def expected_cases(c, population, vaccinated=0.0):
    susceptible = population * (1 - vaccinated)
    c_eff = c * (1 - vaccinated)
    return susceptible * final_fraction_sick(c_eff)
---tests
assert abs(expected_cases(1.8, 6000) - 6000 * final_fraction_sick(1.8)) < 1e-6, "With nobody vaccinated, it's just population x fraction sick"
a, b = expected_cases(1.8, 6000, 0.2), expected_cases(1.8, 6000, 0.0)
assert a < 0.6 * b, f"Vaccinating 20% should cut cases by much more than 20% (fewer susceptible AND a smaller c): {a:.0f} vs {b:.0f}"
assert expected_cases(1.8, 6000, 0.5) == 0.0, "At 50% vaccinated, c_eff = 0.9 < 1: no outbreak (that's herd immunity)"
---hint
Two things change when people are vaccinated: how many can get sick, and how many contacts actually spread it.
---show
for v in [0, 0.1, 0.2, 0.3, 0.4, 0.45]:
    print(f"vaccinated {v:4.0%}: about {expected_cases(1.8, 6000, v):6.0f} cases")
```
