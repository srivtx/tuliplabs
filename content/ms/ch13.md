```prelude
from modsim import *

def make_system(beta, gamma):
    init = State(S=89/90, I=1/90, R=0.0)
    return System(init=init, t_0=0, t_end=7 * 14, beta=beta, gamma=gamma)

def update_func(state, t, system):
    s, i, r = state
    infected = system.beta * i * s
    recovered = system.gamma * i
    return State(S=s - infected, I=i + infected - recovered, R=r + recovered)

def run_simulation(system, update_func):
    frame = TimeFrame(columns=system.init.index)
    frame.row[system.t_0] = system.init
    for t in linrange(system.t_0, system.t_end):
        frame.row[t + 1] = update_func(frame.row[t], t, system)
    return frame

def calc_total_infected(results):
    return get_first_value(results.S) - get_last_value(results.S)
```

## Why sweep?

We don't know β and γ for the Freshman Plague precisely. Before trusting any prediction, ask: **how much do the results depend on the parameters?** Sweeping answers that.

## Sweep beta

```exercise
title: sweep_beta
kind: write
---prompt
Write `sweep_beta(beta_array, gamma)`: for each β, make a system, run it, and store the total infected in a `SweepSeries` indexed by β.
---starter
def sweep_beta(beta_array, gamma):
    pass
---solution
def sweep_beta(beta_array, gamma):
    sweep = SweepSeries()
    for beta in beta_array:
        system = make_system(beta, gamma)
        results = run_simulation(system, update_func)
        sweep[beta] = calc_total_infected(results)
    return sweep
---tests
s = sweep_beta([0.1, 1/3, 1.0], 0.25)
assert len(s) == 3, "One value per beta"
assert s.iloc[0] < 0.05, "beta < gamma: the illness barely spreads"
assert abs(s.iloc[1] - 0.468) < 0.005, "The base case: about 0.468"
assert s.iloc[2] > 0.9, "beta = 1: nearly everyone gets sick"
```

## SweepFrame

A `SweepFrame` is a table: one row per β, one column per γ, each cell the metric.

```quiz
The contour lines in the plot look like straight lines through the origin. What does that suggest?
- β and γ don't matter
* The result depends only on the ratio β/γ: along each line the ratio is constant
- The simulation is too short
- The model is linear
> Lines through the origin are lines of constant β/γ. That's a hint that the two parameters combine into one, the contact number, which chapter 14 explores.
```

## Real-world project: a risk map for unknown diseases

When a new illness appears, nobody knows beta or gamma yet. A two-parameter sweep turns that uncertainty into a **map**: for every plausible combination, would it spread badly? Officials can then say "if the illness lasts longer than X days and spreads faster than Y, we act".

```project
title: Outbreak risk map for a city public-health office
client: A public-health office preparing for a new respiratory illness
skills: two-parameter sweeps, SweepFrame, thresholds, reading R0 = beta / gamma
---brief
Sweep beta (contact rate) and gamma (recovery rate) over plausible ranges, and for each pair compute the fraction eventually infected. Mark each cell **high risk** if more than 30% would be infected. Then check the pattern: high-risk cells should be exactly where beta / gamma (the basic reproduction number R0) is large enough.
---why
Risk maps over uncertain parameters drive real policy: pandemic planning scenarios, flood maps over rainfall and soil, and "what if" tables in finance (sensitivity analysis). Finding that one combination (R0) explains the whole map is the kind of insight sweeps are for: it tells you which single number to measure first.
---milestones
- Choose ranges for beta and gamma and build the sweep with `sweep_parameters`
- Write `risk_cells(betas, gammas, threshold)` returning a grid of True/False
- Plot the infected fraction as a contour map with `contour`
- Overlay the line beta = gamma (R0 = 1) and explain what you see
- Write the rule for the office in one sentence
---stretch
- Add a third parameter, vaccinated fraction, and make one map per value
- Find the minimum vaccination that makes every cell low-risk
- Colour each cell by R0 and compare with the infected map
```

```exercise
title: risk_cells
kind: write
---prompt
Write `risk_cells(betas, gammas, threshold)`: return a numpy boolean array of shape `(len(betas), len(gammas))` where entry `[i, j]` is True if the total fraction infected for `make_system(betas[i], gammas[j])` is **more than** `threshold`. Use `run_simulation`, `update_func` and `calc_total_infected` from the prelude.
---starter
def risk_cells(betas, gammas, threshold):
    return np.zeros((len(betas), len(gammas)), dtype=bool)
---solution
def risk_cells(betas, gammas, threshold):
    out = np.zeros((len(betas), len(gammas)), dtype=bool)
    for i, beta in enumerate(betas):
        for j, gamma in enumerate(gammas):
            results = run_simulation(make_system(beta, gamma), update_func)
            out[i, j] = calc_total_infected(results) > threshold
    return out
---tests
betas = [0.1, 0.3, 0.5, 0.7]
gammas = [0.1, 0.25, 0.5]
grid = risk_cells(betas, gammas, 0.3)
assert grid.shape == (4, 3), "one row per beta, one column per gamma"
assert grid[3, 0] and not grid[0, 2], "fast spread and slow recovery is high risk; slow spread and fast recovery is not"
for i, b in enumerate(betas):
    for j, g in enumerate(gammas):
        if b / g < 1:
            assert not grid[i, j], f"when R0 = beta/gamma < 1 the illness fades out, so beta={b}, gamma={g} can't be high risk"
---hint
Two nested loops with `enumerate` so you have both the index and the value.
```
