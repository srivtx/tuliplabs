## One step is a matrix

A loop like `a, b = b, a + b` is O(n), and contests ask for the 10¹⁸-th term. The trick: each step is a **linear** map, so it's a multiplication by a fixed matrix:

```
[F(n+1)]   [1 1] [F(n)  ]
[F(n)  ] = [1 0] [F(n−1)]
```

So `n` steps are `Qⁿ` with `Q = [[1, 1], [1, 0]]`, and `Qⁿ = [[F(n+1), F(n)], [F(n), F(n−1)]]`. Powers square, exactly like numbers in chapter 39:

```viz
name: ds-matpow
title: F(60) mod 1000, two ways
goal: Run **loop 60 steps** to the end, then run **square the matrix** and compare.
height: 470
60 = 32 + 16 + 8 + 4, so Q⁶⁰ = Q³² · Q¹⁶ · Q⁸ · Q⁴.
```

The recipe for any recurrence that adds up fixed multiples of the last `k` terms:

1. **State vector**: the last `k` values, like `(T(n), T(n−1), T(n−2))` for Tribonacci.
2. **Transition matrix**: row `i` says how the new `i`-th value is built from the old ones.
3. **Power it**: `Tⁿ` by square-and-multiply, starting from the identity matrix. Each product of `k × k` matrices is `k³` multiplications, so it's **O(k³ log n)**.
4. Reduce mod `M` inside every product.

Two upgrades:

- **Graphs**: if `A` is the adjacency matrix, `(Aᴸ)[u][v]` counts the walks of exactly `L` edges from `u` to `v`.
- **Constants and running sums**: add a coordinate that's always 1 (for `+ c`), or one that accumulates (for "the total so far"). The matrix grows by one row and column.

```run
title: Matrix product, matrix power, and F(10¹⁸)
def mat_mult(a, b):
    n, k, p = len(a), len(b), len(b[0])
    return [[sum(a[i][t] * b[t][j] for t in range(k)) % M for j in range(p)] for i in range(n)]

def mat_pow(a, e):
    n = len(a)
    r = [[int(i == j) for j in range(n)] for i in range(n)]
    while e:
        if e & 1:
            r = mat_mult(r, a)
        a = mat_mult(a, a)
        e >>= 1
    return r

Q = [[1, 1], [1, 0]]
print(mat_pow(Q, 10))
fib, t = timed(lambda n: mat_pow(Q, n)[0][1], 10 ** 18)
print("F(10^18) mod M =", fib, "in", round(t * 1000, 2), "ms")
```

## The ladder

```exercise
title: fib_mod
kind: write
---prompt
*LeetCode 509, pushed to n = 10¹⁸.* Return `F(n) mod M` with `F(0) = 0, F(1) = 1`. Use matrix powers.
---starter
def fib_mod(n):
    phi = (1 + 5 ** 0.5) / 2
    return round(phi ** n / 5 ** 0.5) % M
---solution
def fib_mod(n):
    def mul(a, b):
        return [[(a[0][0] * b[0][0] + a[0][1] * b[1][0]) % M, (a[0][0] * b[0][1] + a[0][1] * b[1][1]) % M],
                [(a[1][0] * b[0][0] + a[1][1] * b[1][0]) % M, (a[1][0] * b[0][1] + a[1][1] * b[1][1]) % M]]
    r, q = [[1, 0], [0, 1]], [[1, 1], [1, 0]]
    while n:
        if n & 1:
            r = mul(r, q)
        q = mul(q, q)
        n >>= 1
    return r[0][1]
---tests

assert fib_mod(10) == 55
assert fib_mod(90) == 210345902
assert fib_mod(1000) == 517691607
assert fib_mod(10 ** 18) == 209783453
---hint
```

```exercise
    if n < 3:
```

```exercise

---prompt
`adj[u][v] = 1` if there's a one-way road from `u` to `v`. Return how many walks of **exactly** `L` roads go from `u` to `v`, modulo `M`, with `L` up to `10¹²`. It's `(adjᴸ)[u][v]`.

    n = len(adj)
    def mul(a, b):
        return [[sum(a[i][t] * b[t][j] for t in range(n)) % M for j in range(n)] for i in range(n)]
```

```exercise
title: herd_after
kind: write
---prompt
Given `start = [lambs, yearlings, adults]`, return the total herd size after `n` seasons, modulo `M`, using `(L, Y, A) → (2Y + 3A, L, Y + A)`. `n` up to `10¹⁸`.
---starter
def herd_after(n, start):
    L, Y, A = start
    for _ in range(min(n, 3)):
        L, Y, A = 2 * Y + 3 * A, L, Y + A
    return (L + Y + A) % M
---solution
def herd_after(n, start):
    T = [[0, 2, 3], [1, 0, 0], [0, 1, 1]]
    def mul(a, b):
        return [[sum(a[i][t] * b[t][j] for t in range(3)) % M for j in range(3)] for i in range(3)]

        T = mul(T, T)
```

## Rebuild it and explain it

```exercise
title: matpow_rebuild
kind: rebuild
---prompt
From memory: `nth_term(coeffs, first, n)` for the recurrence `a(n) = coeffs[0]·a(n−1) + coeffs[1]·a(n−2) + … + coeffs[k−1]·a(n−k)`, given the first `k` terms `first = [a(0), …, a(k−1)]`. Return `a(n) mod M` for `n` up to `10¹⁸`.
---starter
def nth_term(coeffs, first, n):
    pass
---solution
def nth_term(coeffs, first, n):
    k = len(coeffs)
    if n < k:
        return first[n] % M
    T = [[0] * k for _ in range(k)]
    T[0] = list(coeffs)
    for i in range(1, k):
        T[i][i - 1] = 1
    def mul(a, b):
        return [[sum(a[i][t] * b[t][j] for t in range(k)) % M for j in range(k)] for i in range(k)]
    r = [[int(i == j) for j in range(k)] for i in range(k)]
    e = n - (k - 1)
    while e:
        if e & 1:
            r = mul(r, T)
        T = mul(T, T)
        e >>= 1
    state = first[::-1]
    return sum(r[0][j] * state[j] for j in range(k)) % M
---tests
assert nth_term([1, 1], [0, 1], 10) == 55
assert nth_term([1, 1], [0, 1], 10 ** 18) == 209783453
assert nth_term([1, 1, 1], [0, 1, 1], 25) == 1389537
assert nth_term([2], [3], 5) == 96
assert nth_term([1, 1], [0, 1], 1) == 1
---hint
State `(a(n), a(n−1), …, a(n−k+1))`. Row 0 is the coefficients; the rows below shift everything down by one. Start from `first` reversed, and take `n − (k − 1)` steps.
```

```recall
Q: Explain how matrix exponentiation computes the n-th term of a linear recurrence, its cost, and how it counts walks in a graph and handles constants or running sums.
A: A recurrence that adds fixed multiples of the last k terms is one multiplication of a k × k matrix with the state vector of the last k values; for Fibonacci, Q = [[1, 1], [1, 0]] maps (F(n), F(n−1)) to (F(n+1), F(n)), and Qⁿ holds F(n) in its top-right corner. So n steps are the n-th power of one matrix, which square-and-multiply computes from the identity in log n products, reducing mod M inside each; with k³ work per product that is O(k³ log n), about a hundred products for n = 10¹⁸ instead of 10¹⁸ loop steps. The adjacency matrix A of a graph gives the number of walks of exactly L edges from u to v as (Aᴸ)[u][v]. A constant term is handled by adding a state coordinate that is always 1, and a running total by adding a coordinate that accumulates; each costs one extra row and column. Products of terms are not linear and do not fit.
```
