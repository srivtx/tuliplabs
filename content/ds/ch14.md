## When do two intervals overlap?

An interval `[s, e]` is a range: a meeting, a booking, a segment of a road. Almost every interval question starts with one test. Two intervals `a` and `b` overlap exactly when

`a.start < b.end and b.start < a.end`

(use `<=` if touching counts as overlapping). The opposite, "they don't overlap", is easier to see: one ends before the other starts.

```run
title: The overlap test, and the overlap itself
def overlap(a, b):
    return a[0] < b[1] and b[0] < a[1]

for a, b in [((1, 5), (4, 8)), ((1, 5), (5, 8)), ((2, 3), (0, 10)), ((6, 9), (1, 2))]:
    common = (max(a[0], b[0]), min(a[1], b[1]))
    print(a, b, overlap(a, b), "shared part:", common if overlap(a, b) else None)
```

```predict
a, b = (3, 9), (5, 12)
print(max(a[0], b[0]), min(a[1], b[1]))
```

```quiz
Intervals are half-open: `[s, e)` (a booking ending at 5 frees the slot at 5). Do `[1, 5)` and `[5, 8)` overlap?
- Yes, they share 5
* No: the first ends exactly where the second starts
- Only if they're in the same room
- It depends on the order
> With half-open intervals the test is `a.start < b.end and b.start < a.end`: `5 < 5` is false.
```

## Sorting first

Chapter 6 merged overlapping intervals after sorting by start. The same idea answers most list-of-intervals questions in one pass.

```exercise
title: insert_interval
kind: write
---prompt
*LeetCode 57.* `intervals` is sorted by start and has no overlaps. Insert `new` and merge where needed, in O(n): copy everything that ends before `new` starts, swallow everything that overlaps it (touching counts), then copy the rest.
---starter
def insert(intervals, new):
    return sorted(intervals + [new])
---solution
def insert(intervals, new):
    out, i, n = [], 0, len(intervals)
    s, e = new
    while i < n and intervals[i][1] < s:
        out.append(intervals[i]); i += 1
    while i < n and intervals[i][0] <= e:
        s, e = min(s, intervals[i][0]), max(e, intervals[i][1]); i += 1
    out.append([s, e])
    out.extend(intervals[i:])
    return out
---tests
assert insert([[1, 3], [6, 9]], [2, 5]) == [[1, 5], [6, 9]]
assert insert([[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]], [4, 8]) == [[1, 2], [3, 10], [12, 16]]
assert insert([], [5, 7]) == [[5, 7]]
assert insert([[1, 5]], [6, 8]) == [[1, 5], [6, 8]]
assert insert([[3, 5]], [1, 2]) == [[1, 2], [3, 5]]
---hint
Three loops over one index `i`: before, overlapping (grow `s, e`), after.
```

```exercise
title: interval_intersection
kind: write
---prompt
*LeetCode 986, asked at Meta.* Two lists of closed intervals, each sorted and non-overlapping. Return their intersection. Two pointers (chapter 7): the shared part of `A[i]` and `B[j]` is `[max of starts, min of ends]` if that's non-empty; then move past whichever interval **ends first**.
---starter
def intersect(A, B):
    out = []
    for a in A:
        for b in B:
            if a == b:
                out.append(a)
    return out
---solution
def intersect(A, B):
    out, i, j = [], 0, 0
    while i < len(A) and j < len(B):
        lo, hi = max(A[i][0], B[j][0]), min(A[i][1], B[j][1])
        if lo <= hi:
            out.append([lo, hi])
        if A[i][1] < B[j][1]:
            i += 1
        else:
            j += 1
    return out
---tests
A = [[0, 2], [5, 10], [13, 23], [24, 25]]
B = [[1, 5], [8, 12], [15, 24], [25, 26]]
assert intersect(A, B) == [[1, 2], [5, 5], [8, 10], [15, 23], [24, 24], [25, 25]]
assert intersect([[1, 3]], []) == []
assert intersect([[1, 7]], [[3, 10]]) == [[3, 7]]
---hint
The interval that ends first can't meet anything later in the other list, so it's the one you drop.
```

```exercise
title: erase_overlap
kind: write
---prompt
*LeetCode 435.* Return the fewest intervals to remove so the rest don't overlap (touching is fine). Greedy: sort by **end**, keep an interval whenever it starts at or after the last kept end. Ending early leaves the most room for the rest (chapter 16 proves why).
---starter
def erase_overlap(iv):
    iv = sorted(iv)
    removed, end = 0, float("-inf")
    for s, e in iv:
        if s >= end:
            end = e
        else:
            removed += 1
    return removed
---solution
def erase_overlap(iv):
    removed, end = 0, float("-inf")
    for s, e in sorted(iv, key=lambda x: x[1]):
        if s >= end:
            end = e
        else:
            removed += 1
    return removed
---tests
assert erase_overlap([[1, 2], [2, 3], [3, 4], [1, 3]]) == 1
assert erase_overlap([[1, 2], [1, 2], [1, 2]]) == 2
assert erase_overlap([[1, 2], [2, 3]]) == 0
assert erase_overlap([[1, 100], [2, 3], [4, 5], [6, 7]]) == 1
assert erase_overlap([]) == 0
---hint
The starter sorts by **start**, so a long early interval like `[1, 100]` gets kept and blocks everything. Sort by end instead.
```

```exercise
title: min_arrows
kind: write
---prompt
*LeetCode 452.* Balloons are horizontal ranges `[s, e]`; an arrow shot at `x` pops every balloon with `s <= x <= e`. Return the fewest arrows. Sort by end; shoot at the end of the first unpopped balloon, which pops everything starting at or before that point.
---starter

---solution

            x = e
```

## The sweep line

When the question is "how many at once?", stop thinking about intervals. Each one is two **events**: `+1` when it starts, `−1` when it ends. Sort the events and walk them with a running count.

```viz

goal: Run **check every hour** to the end, then run **sweep the events** and compare the steps.

The bars under the timeline show how many meetings are on during each hour.
```

At a tie, process **ends before starts** when intervals are half-open (a meeting ending at 10 frees its room for one starting at 10). Sorting `(time, delta)` pairs does that for free, because `-1 < +1`.

```exercise
title: car_pooling
kind: write
---prompt
*LeetCode 1094.* A car with `capacity` seats drives east. `trips[i] = (passengers, from, to)`: they get on at `from` and off at `to`. Can it do every trip? Sweep events: `+passengers` at `from`, `−passengers` at `to` (people get off before others get on).
---starter
def car_pooling(trips, capacity):
    return sum(p for p, _, _ in trips) <= capacity
---solution
def car_pooling(trips, capacity):
    events = []
    for p, a, b in trips:
        events.append((a, p))
        events.append((b, -p))
    cur = 0
    for _, d in sorted(events):
        cur += d
        if cur > capacity:
            return False
    return True
---tests
assert not car_pooling([(2, 1, 5), (3, 3, 7)], 4)
assert car_pooling([(2, 1, 5), (3, 3, 7)], 5)
assert car_pooling([(2, 1, 5), (3, 5, 7)], 3)
assert car_pooling([(3, 2, 7), (3, 7, 9), (8, 3, 9)], 11)
---hint
Same as counting rooms, but each event adds or removes a whole group. Sorting `(time, change)` puts the negative changes first at equal times.
```

```exercise
title: covered_points
kind: write
---prompt
*Codeforces 1000C "Covered Points Count".* Segments `[l, r]` cover integer points (both ends included). Return a list `cnt` where `cnt[k-1]` is how many integer points are covered by **exactly** `k` segments, for k = 1..n. Coordinates go up to 10¹⁸, so you can't loop over points: sweep events at `l` (+1) and `r + 1` (−1), and between consecutive event positions every point has the same count.
---starter
def covered(segs):
    n = len(segs)
    cnt = [0] * n
    hi = max((r for _, r in segs), default=0)
    for x in range(hi + 1):
        k = sum(1 for l, r in segs if l <= x <= r)
        if k:
            cnt[k - 1] += 1
    return cnt
---solution
def covered(segs):
    n = len(segs)
    events = []
    for l, r in segs:
        events.append((l, 1))
        events.append((r + 1, -1))
    events.sort()
    cnt = [0] * n
    cur, prev = 0, None
    for x, d in events:
        if prev is not None and cur > 0:
            cnt[cur - 1] += x - prev
        cur += d
        prev = x
    return cnt
---tests
assert covered([(0, 3), (1, 3), (3, 8)]) == [6, 2, 1]
assert covered([(1, 3), (2, 4), (5, 7)]) == [5, 2, 0]
assert covered([(5, 5)]) == [1]
_, secs = timed(covered, [(0, 200000), (100, 300)])
assert secs < 0.01, f"{secs:.2f}s: sweep the events, don't visit every point"
r, secs = timed(covered, [(0, 10**18), (5, 10**17)])
assert r == [10**18 + 1 - (10**17 - 4), 10**17 - 4] and secs < 0.01, "sweep the events, don't visit every point"
---hint
Before applying an event at `x`, the points `prev..x-1` (that's `x - prev` of them) all had count `cur`.
```

```exercise
title: free_time
kind: write
---prompt
*LeetCode 759, a hard one asked at Airbnb and Google.* Each employee has a sorted list of busy intervals. Return the finite gaps when **everyone** is free, sorted. Pool all intervals, sort by start, merge as you go, and every time the next start is after the merged end, that gap is free time.
---starter
def free_time(schedules):
    allv = sorted(iv for s in schedules for iv in s)
    return [[allv[i][1], allv[i + 1][0]] for i in range(len(allv) - 1) if allv[i][1] < allv[i + 1][0]]
---solution
def free_time(schedules):
    allv = sorted(iv for s in schedules for iv in s)
    out = []
    if not allv:
        return out
    end = allv[0][1]
    for s, e in allv[1:]:
        if s > end:
            out.append([end, s])
        end = max(end, e)
    return out
---tests
assert free_time([[[1, 2], [5, 6]], [[1, 3]], [[4, 10]]]) == [[3, 4]]
assert free_time([[[1, 3], [6, 7]], [[2, 4]], [[2, 5], [9, 12]]]) == [[5, 6], [7, 9]]
assert free_time([[[1, 10]], [[2, 3]], [[4, 5]]]) == []
---hint
The starter compares neighbours only, so a long interval like `[1, 10]` is forgotten. Track the furthest end seen so far.
```

```exercise
title: earliest_slot
kind: write
---prompt
`busy` is a list of every person's busy `(start, end)` blocks (any order, may overlap), in minutes. Working hours are `day = (open, close)`. Return the start of the earliest free gap of at least `length` minutes inside working hours, or `-1`.
---starter
def earliest_slot(busy, day, length):
    return day[0]
---solution
def earliest_slot(busy, day, length):
    t = day[0]
    for s, e in sorted(busy):
        if s - t >= length:
            return t if t + length <= day[1] else -1
        t = max(t, e)
    return t if day[1] - t >= length else -1
---tests
busy = [(540, 600), (570, 630), (700, 760), (900, 1020)]
assert earliest_slot(busy, (540, 1080), 60) == 630
assert earliest_slot(busy, (540, 1080), 150) == -1
assert earliest_slot(busy, (540, 1080), 140) == 760
assert earliest_slot([], (540, 1080), 30) == 540
assert earliest_slot([(540, 1080)], (540, 1080), 1) == -1
---hint
Walk the sorted blocks keeping `t`, the earliest moment everyone is free. A gap before a block is `s - t`; after the last block, check against closing time.
```

```exercise
title: busiest_moment
kind: write
---prompt
Return `(count, time)`: the most people busy at once and the **earliest** time that happens. Busy blocks are half-open. Sweep the events.
---starter
def busiest(busy):
    return (len(busy), busy[0][0] if busy else 0)
---solution
def busiest(busy):
    events = []
    for s, e in busy:
        events.append((s, 1))
        events.append((e, -1))
    events.sort()
    cur, best, when = 0, 0, 0
    for t, d in events:
        cur += d
        if cur > best:
            best, when = cur, t
    return (best, when)
---tests
assert busiest([(540, 600), (570, 630), (700, 760), (600, 720)]) == (2, 570)
assert busiest([(1, 5), (5, 9)]) == (1, 1)
assert busiest([(0, 10), (2, 8), (4, 6)]) == (3, 4)
assert busiest([]) == (0, 0)
---hint
Record the time only when the count goes strictly **above** the best, so the earliest moment wins.
```

```exercise

kind: rebuild
---prompt

def max_overlap(intervals):
    events = sorted([(s, 1) for s, _ in intervals] + [(e, -1) for _, e in intervals])

    for _, d in events:
        cur += d
```

```recall
Q: Explain the main interval techniques: the overlap test, merging, greedy by end, and the sweep line.
A: Two intervals overlap when each starts before the other ends: a.start < b.end and b.start < a.end (≤ if touching counts), and their shared part is [max of starts, min of ends]. Sorting by start lets you merge, insert or find gaps in one pass, tracking the furthest end so far; two sorted lists intersect with two pointers, dropping whichever interval ends first. To keep the most non-overlapping intervals (or use the fewest arrows), sort by end and greedily keep each interval that starts after the last kept end, because ending earliest leaves the most room. For "how many at once" questions, turn each interval into a +1 event at its start and a −1 event at its end, sort the 2n events (ends before starts at equal times for half-open intervals), and sweep with a running count; the maximum is the number of rooms, and the gaps between events let you count covered points even when coordinates reach 10¹⁸. Cost: O(n log n) for the sort, independent of how large the times are.
```
