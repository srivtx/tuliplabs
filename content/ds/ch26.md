## A tree of shared prefixes

A **trie** (said "try", from re*trie*val) stores strings letter by letter. Each node is a dictionary from a letter to a child node, plus a flag saying "a word ends here". Words that share a beginning share the path for it: "car", "card", "care" and "careful" all walk through c → a → r.

```viz
name: ds-trie
title: Autocomplete: scanning every word against walking a trie
goal: Run **scan every word** to the end, then run **walk the trie** and compare the steps.
height: 460
Click a trie node to see the prefix it spells.
```

- **Insert** or **search** a word of length L: O(L), no matter how many words are stored.
- **All words with a prefix**: walk the prefix (O(|prefix|)), then collect everything below.
- Memory is the cost: one small dictionary per node. Sharing prefixes helps.

```run
title: A trie made of nested dictionaries
END = "$"
trie = {}
for word in ["car", "card", "care", "careful", "cart", "cat", "dog"]:
    node = trie
    for ch in word:
        node = node.setdefault(ch, {})
    node[END] = True

def with_prefix(prefix):
    node = trie
    for ch in prefix:
        if ch not in node:
            return []
        node = node[ch]
    out = []
    def collect(n, path):
        if END in n:
            out.append(path)
        for ch in sorted(k for k in n if k != END):
            collect(n[ch], path + ch)
    collect(node, prefix)
    return out

print(with_prefix("car"))
print(with_prefix("ca"))
print(with_prefix("x"))
```

```exercise
title: trie_class
kind: write
---prompt
*LeetCode 208, asked at Google, Amazon and Microsoft.* Build a `Trie` with `insert(word)`, `search(word)` (is this exact word stored?) and `starts_with(prefix)` (is any stored word starting with it?).
---starter
class Trie:
    def __init__(self):
        self.words = []
    def insert(self, word):
        self.words.append(word)
    def search(self, word):
        return word in self.words
    def starts_with(self, prefix):
        return any(w.startswith(prefix) for w in self.words)
---solution
class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True
    def _walk(self, s):
        node = self.root
        for ch in s:
            if ch not in node:
                return None
            node = node[ch]
        return node
    def search(self, word):
        node = self._walk(word)
        return node is not None and "$" in node
    def starts_with(self, prefix):
        return self._walk(prefix) is not None
---tests
t = Trie()
t.insert("apple")
assert t.search("apple") and not t.search("app")
assert t.starts_with("app") and not t.starts_with("b")
t.insert("app")
assert t.search("app")
t2 = Trie()
for i in range(20000):
    t2.insert("word%05d" % i)
def many():
    return sum(t2.starts_with("word%05d" % i) for i in range(0, 20000, 5))
out, sec = timed(many)
assert out == 4000
assert sec < 0.4, f"too slow: {sec:.2f}s (scanning every word for every query?)"
---hint
A shared `_walk` that follows letters and returns the node (or None) makes `search` and `starts_with` one line each.
```

```exercise
title: search_suggestions
kind: write
---prompt
*LeetCode 1268, asked at Amazon.* After each letter of `typed`, suggest up to **3** product names starting with what's typed so far, in alphabetical order. Return the list of suggestion lists. Build a trie where each node keeps the (up to) 3 smallest words passing through it, by inserting the words in sorted order.
---starter
def suggest(products, typed):
    products = sorted(products)
    return [[p for p in products if p.startswith(typed)][:3] for _ in typed]
---solution
def suggest(products, typed):
    root = {}
    for p in sorted(products):
        node = root
        for ch in p:
            node = node.setdefault(ch, {"#": []})
            if len(node["#"]) < 3:
                node["#"].append(p)
    out, node = [], root
    for ch in typed:
        node = node.get(ch) if node is not None else None
        out.append(node["#"] if node is not None else [])
    return out
---tests
prods = ["mobile", "mouse", "moneypot", "monitor", "mousepad"]
assert suggest(prods, "mouse") == [["mobile", "moneypot", "monitor"], ["mobile", "moneypot", "monitor"], ["mouse", "mousepad"], ["mouse", "mousepad"], ["mouse", "mousepad"]]
assert suggest(["havana"], "tatiana") == [[]] * 7
assert suggest(["bags", "baggage", "banner", "box", "cloths"], "bags") == [["baggage", "bags", "banner"], ["baggage", "bags", "banner"], ["baggage", "bags"], ["bags"]]
---hint
Use the key `"#"` for the list, which can't clash with a letter. Once you fall off the trie, every later answer is `[]`.
```

```exercise
title: replace_words
kind: write
---prompt
*LeetCode 648, asked at Uber.* `roots` like `["cat", "bat", "rat"]`. In `sentence`, replace every word that starts with a root by its **shortest** root. Walk each word down the trie and stop at the first node where a root ends.
---starter
def replace(roots, sentence):
    out = []
    for w in sentence.split():
        for r in roots:
            if w.startswith(r):
                w = r
                break
        out.append(w)
    return " ".join(out)
---solution
def replace(roots, sentence):
    trie = {}
    for r in roots:
        node = trie
        for ch in r:
            node = node.setdefault(ch, {})
        node["$"] = r
    out = []
    for w in sentence.split():
        node, rep = trie, w
        for ch in w:
            if ch not in node:
                break
            node = node[ch]
            if "$" in node:
                rep = node["$"]
                break
        out.append(rep)
    return " ".join(out)
---tests
assert replace(["cat", "bat", "rat"], "the cattle was rattled by the battery") == "the cat was rat by the bat"
assert replace(["a", "b", "c"], "aadsfasf absbs bbab cadsfafs") == "a a b c"
assert replace(["catt", "cat", "bat"], "cattle") == "cat"
assert replace(["xyz"], "hello world") == "hello world"
---hint
The starter takes the first root in the list, not the shortest. In a trie, the first word-end you meet on the way down is the shortest.
```

```exercise
title: word_search_grid
kind: write
---prompt
*LeetCode 212, a hard one asked at Amazon, Google and Microsoft.* Return all `words` (sorted) that can be spelled in the letter `board` by moving between neighbouring cells (up, down, left, right), using each cell at most once per word. Put the words in a trie and run **one** DFS from each cell, following the trie as you go, so all the words are searched together.
---starter
def find_words(board, words):
    letters = {c for row in board for c in row}
    return sorted(w for w in words if set(w) <= letters)
---solution
def find_words(board, words):
    trie = {}
    for w in words:
        node = trie
        for ch in w:
            node = node.setdefault(ch, {})
        node["$"] = w
    R, C, found = len(board), len(board[0]), set()
    def dfs(r, c, node):
        ch = board[r][c]
        if ch not in node:
            return
        nxt = node[ch]
        if "$" in nxt:
            found.add(nxt["$"])
        board[r][c] = "#"
        for a, b in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= a < R and 0 <= b < C:
                dfs(a, b, nxt)
        board[r][c] = ch
    for r in range(R):
        for c in range(C):
            dfs(r, c, trie)
    return sorted(found)
---tests
board = [list("oaan"), list("etae"), list("ihkr"), list("iflv")]
assert find_words(board, ["oath", "pea", "eat", "rain"]) == ["eat", "oath"]
assert find_words([list("ab"), list("cd")], ["abcb"]) == []
assert find_words([list("ab"), list("cd")], ["abdc", "acdb", "ad"]) == ["abdc", "acdb"]
---hint
Mark a cell `"#"` while it's on the current path and restore it after: that's backtracking (chapter 27). If the next letter isn't a child of the current trie node, stop immediately.
```

```exercise
title: max_xor_pair
kind: write
---prompt
*LeetCode 421, and a Codeforces favourite.* Return the largest `a ^ b` over all pairs in `nums` (values below 2³¹). Comparing every pair is O(n²). Instead, insert each number's **bits** (from bit 30 down to 0) into a binary trie; for each number, walk down choosing the **opposite** bit whenever that child exists, since a 1 in a high bit beats anything in the lower ones.
---starter
def max_xor(nums):
    return max((a ^ b for a in nums for b in nums), default=0)
---solution
def max_xor(nums):
    root = {}
    for x in nums:
        node = root
        for i in range(30, -1, -1):
            node = node.setdefault((x >> i) & 1, {})
    best = 0
    for x in nums:
        node, cur = root, 0
        for i in range(30, -1, -1):
            b = (x >> i) & 1
            if 1 - b in node:
                cur |= 1 << i
                node = node[1 - b]
            else:
                node = node[b]
        best = max(best, cur)
    return best
---tests
assert max_xor([3, 10, 5, 25, 2, 8]) == 28
assert max_xor([14, 70, 53, 83, 49, 91, 36, 80, 92, 51, 66, 70]) == 127
assert max_xor([7]) == 0
random.seed(8)
nums = random.sample(range(1, 2 ** 30), 8000)
out, sec = timed(max_xor, nums)
assert sec < 0.8, f"too slow: {sec:.2f}s"
---hint
Greedy from the top bit works because 2^i is bigger than all the lower bits added together.
```

```quiz
What does a trie node store?
- One whole word
* Its children by letter, plus a flag for "a word ends here"
- A sorted list of words
- A hash of the prefix
> The path from the root spells the prefix; the node doesn't need to store it.
```

```quiz
Why is the end-of-word flag needed?
- To save memory
* Without it, a prefix like "app" would look like a stored word just because "apple" is
- To sort the children
- For deletion only
> Reaching a node proves a prefix exists, not a word.
```

```quiz
Which question is a trie best at, compared with a hash set of words?
- Is this exact word stored?
* Which stored words start with this prefix?
- How many words are stored?
- What's the longest word?
> A hash set must scan everything for a prefix; a trie walks straight to it.
```

```quiz
In the maximum XOR trie, why go from the highest bit down?
- It's faster to read
* A 1 in a higher bit is worth more than all lower bits together, so greedy from the top is optimal
- The low bits are always 0
- Tries must be built that way
> Bit i is worth 2^i, more than 2^(i−1) + … + 1.
```

```quiz
Searching many words in a letter grid: why one trie instead of searching each word separately?
- A trie uses less memory
* One DFS follows all words at once and stops as soon as the path isn't a prefix of any of them
- It sorts the answers
- Grids need tries
> Shared prefixes are explored once, and dead paths die early.
```

```exercise
title: top_by_usage
kind: write
---prompt
`commands` is a dict `name → uses`. Return a function `top(prefix)` that gives up to 5 names starting with `prefix`, most used first, ties alphabetical. Build a trie where every node stores its best 5 names (insert all, then sort and trim each node's list).
---starter
def build(commands):
    def top(prefix):
        return sorted(n for n in commands if n.startswith(prefix))[:5]
    return top
---solution
def build(commands):
    root = {"#": []}
    for name in commands:
        node = root
        for ch in name:
            node = node.setdefault(ch, {"#": []})
            node["#"].append(name)
    def trim(node):
        node["#"] = sorted(node["#"], key=lambda n: (-commands[n], n))[:5]
        for k, child in node.items():
            if k != "#":
                trim(child)
    trim(root)
    def top(prefix):
        node = root
        for ch in prefix:
            if ch not in node:
                return []
            node = node[ch]
        return node["#"]
    return top
---tests
cmds = {"save": 90, "save as": 20, "select all": 70, "settings": 15, "search": 88, "split": 5, "sort lines": 2, "copy": 99}
top = build(cmds)
assert top("s") == ["save", "search", "select all", "save as", "settings"]
assert top("sa") == ["save", "save as"]
assert top("se") == ["search", "select all", "settings"]
assert top("z") == []
---hint
Store names while inserting, then do one pass to sort by `(-uses, name)` and keep 5. The root never needs a list for a non-empty prefix.
```

```exercise
title: wildcard_search
kind: write
---prompt
*LeetCode 211, asked at Meta.* Return a function `match(pattern)` telling whether any stored word matches `pattern` exactly in length, where `"."` matches any one character. In the trie, a letter follows one branch; a dot tries **every** branch (DFS).
---starter
def build(words):
    def match(pattern):
        return pattern in words
    return match
---solution
def build(words):
    root = {}
    for w in words:
        node = root
        for ch in w:
            node = node.setdefault(ch, {})
        node["$"] = True
    def match(pattern):
        def go(node, i):
            if i == len(pattern):
                return "$" in node
            ch = pattern[i]
            if ch == ".":
                return any(go(child, i + 1) for k, child in node.items() if k != "$")
            return ch in node and go(node[ch], i + 1)
        return go(root, 0)
    return match
---tests
match = build(["bad", "dad", "mad", "copy"])
assert match("bad") and match(".ad") and match("b..") and match("c..y")
assert not match("pad") and not match("ba") and not match("....y")
assert not match("..")
---hint
The base case checks the end flag, so a pattern shorter than every word fails correctly.
```

## Rebuild it and explain it

```exercise
title: trie_rebuild
kind: rebuild
---prompt
From memory: `count_prefix(words, prefix)` that builds a trie where each node counts how many words pass through it, then returns how many words start with `prefix`.
---starter
def count_prefix(words, prefix):
    pass
---solution
def count_prefix(words, prefix):
    root = {"#": 0}
    for w in words:
        node = root
        for ch in w:
            node = node.setdefault(ch, {"#": 0})
            node["#"] += 1
    node = root
    for ch in prefix:
        if ch not in node:
            return 0
        node = node[ch]
    return node["#"] if prefix else len(words)
---tests
ws = ["apple", "app", "apt", "bat", "ape"]
assert count_prefix(ws, "ap") == 4
assert count_prefix(ws, "app") == 2
assert count_prefix(ws, "c") == 0
assert count_prefix(ws, "") == 5
---hint
Increment a counter on every node you pass while inserting. The answer is the counter at the prefix's node.
```

```recall
Q: Explain tries: their structure, operation costs, why they beat a hash set for prefixes, and the main problems they solve.
A: A trie stores strings letter by letter in a tree: each node maps letters to child nodes and has an end-of-word flag, so words that share a prefix share the path for it. Inserting or looking up a word of length L takes O(L) regardless of how many words are stored, and finding all words with a prefix walks the prefix and then collects the subtree, which a hash set can only do by scanning every word. The end flag distinguishes stored words from mere prefixes. Nodes can carry extra data such as counts of words passing through or the top suggestions below. Uses include autocomplete and search suggestions, replacing words by their shortest root, wildcard search by branching on every child, searching many words in a grid with a single trie-guided DFS, longest-prefix matching in routing, and a binary trie over bits from the highest down for the maximum XOR pair. The cost is memory, one small map per node.
```
