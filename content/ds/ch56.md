```prelude
sys.setrecursionlimit(10000)

def timed(fn, *args):
    t = time.perf_counter()
    out = fn(*args)
    return out, time.perf_counter() - t

def lcg(n, seed, mx):
    out, x = [], seed
    for _ in range(n):
        x = (x * 1103515245 + 12345) % 2 ** 31
        out.append(x % mx)
    return out

def walk_graph(n, m, seed, start=0, closed=True):
    """The edges of one random m-step walk from start, so an Euler path is guaranteed."""
    nodes = [start]
    for x in lcg(m, seed, 10 ** 9):
        y = x * n // 10 ** 9
        if y == nodes[-1]:
            y = (y + 1) % n
        nodes.append(y)
    if closed and nodes[-1] != start:
        nodes.append(start)
    return [(nodes[i], nodes[i + 1]) for i in range(len(nodes) - 1)]

def is_trail(edges, path, directed=False):
    """True when path walks along every edge exactly once."""
    if path is None or len(path) != len(edges) + 1:
        return False
    key = (lambda a, b: (a, b)) if directed else (lambda a, b: (min(a, b), max(a, b)))
    return Counter(key(a, b) for a, b in edges) == Counter(key(path[i], path[i + 1]) for i in range(len(path) - 1))
```

## Every edge, once

An **Euler path** uses every edge of a graph exactly once. If it ends where it started, it's an **Euler circuit**. (A path through every **node** once is a Hamiltonian path, which is NP-hard. Edges are the easy version.)

Whether one exists depends only on **degrees**. Each time the walk passes through a node it uses one edge in and one edge out, so a node in the middle of the walk needs an even degree. Only the two ends can be odd. For an undirected graph whose edges are all connected:

- **0 odd nodes**: an Euler circuit exists, starting anywhere.
- **2 odd nodes**: an Euler path exists, from one odd node to the other.
- **4 or more**: neither. (The count of odd nodes is always even.)

For a **directed** graph: every node needs in-degree = out-degree for a circuit. For a path, exactly one node has out − in = 1 (the start) and one has in − out = 1 (the end).

Knowing a path exists doesn't tell you how to find one. Walking to any unused edge can get stuck:

```viz

```

**Hierholzer's algorithm** fixes it with a stack. Push the start. Look at the node on top: if it has an unused edge, use it and push the other end. If it has none, **pop** it onto the answer. When the walk gets stuck, popping backs up to the last node that still has edges, and a detour starts there. A detour can only get stuck back at its own start (every other node it enters has an edge left to leave by), so it slots straight into the path.

Nodes are added to the answer when they're **popped**, so the answer comes out backwards: reverse it at the end. Every edge is pushed once and popped once, so the whole thing is O(V + E).

```run
title: Hierholzer's algorithm
def euler_path(n, edges):
    adj = [[] for _ in range(n)]
    for i, (a, b) in enumerate(edges):
        adj[a].append((b, i))
        adj[b].append((a, i))
    odd = [v for v in range(n) if len(adj[v]) % 2]
    if len(odd) not in (0, 2):
        return None
    start = odd[0] if odd else next((v for v in range(n) if adj[v]), 0)
    used = [False] * len(edges)
    stack, path = [start], []
    while stack:
        v = stack[-1]
        while adj[v] and used[adj[v][-1][1]]:
            adj[v].pop()                     # throw away edges used from the other end
        if adj[v]:
            u, i = adj[v].pop()
            used[i] = True
            stack.append(u)
        else:
            path.append(stack.pop())
    return path[::-1] if len(path) == len(edges) + 1 else None   # too short: not connected

print(euler_path(5, HOUSE))
E = walk_graph(300, 3000, 7)
p, secs = timed(euler_path, 300, E)
print(len(E), "edges:", is_trail(E, p), f"{secs:.3f}s")
```

```exercise
---starter
def crack(n, k):
    from itertools import product
    return "".join("".join(map(str, p)) for p in product(range(k), repeat=n))
---solution
def crack(n, k):
    start = "0" * (n - 1)
    nxt = {}
    stack, out = [(start, "")], []
    while stack:
        v, d = stack[-1]
        i = nxt.get(v, 0)
        if i < k:
            nxt[v] = i + 1
            stack.append(((v + str(i))[1:], str(i)))
        else:
            stack.pop()
            out.append(d)
    return start + "".join(out[::-1])
```

```exercise
def count_strokes(n, edges):
    adj = [[] for _ in range(n)]
    for a, b in edges:
```

```recall
Q: Explain Euler paths: when one exists in undirected and directed graphs, how Hierholzer's algorithm works and why nodes join the answer when popped, its cost, and two problems that are Euler paths in disguise.
A: An Euler path uses every edge exactly once, and a circuit also ends where it starts. Every node in the middle of the walk uses one edge in and one out, so its degree must be even. In a connected undirected graph: zero odd nodes means a circuit, two odd nodes means a path between them, more means neither. In a directed graph a circuit needs in = out everywhere, and a path needs one node with out − in = 1 (the start) and one with in − out = 1 (the end). Hierholzer keeps the walk on a stack. If the top node has an unused edge, use it and push the far end. If not, pop the node onto the answer. When the walk gets stuck, popping backs up to a node with edges left, and a detour starts there. A detour can only stall back at its own start, so it splices in. Nodes join the answer on pop, so the list is reversed at the end, and a too-short answer means the edges weren't connected. Each edge is pushed and popped once: O(V + E). Disguises: reordering plane tickets into one trip (airports are nodes, tickets are directed edges, take the alphabetically first ticket for the smallest trip), and the de Bruijn sequence for cracking a lock (each (n − 1)-digit string is a node and each code is an edge). When no single path exists, a piece with t odd nodes needs max(1, t/2) strokes.
```
