## Is it prime?

A **prime** has exactly two divisors: 1 and itself. So 1 is not prime, 2 is the only even prime, and every whole number above 1 splits into primes in exactly one way (`360 = 2·2·2·3·3·5`).

To test one number `n`, divide by 2, 3, 4, … but only up to **√n**: if `n = a·b`, one of `a` and `b` is at most √n. That's **trial division**, O(√n) per number. Fine for one number near 10¹², too slow for every number up to a million:

```viz

height: 520

```

The **Sieve of Eratosthenes** turns it round. Start with everything marked "maybe prime". Take the smallest unmarked number `p`: it's prime. Cross off `p², p² + p, p² + 2p, …`. Stop when `p² > n`. Whatever is left unmarked is prime.

- Start at `p²`: a smaller multiple `k·p` with `k < p` was already crossed off by `k`'s smallest prime.
- The work is `n/2 + n/3 + n/5 + …` = **O(n log log n)**, practically linear.
- In Python, cross off with one slice assignment, `s[p*p::p] = [False] * len(range(p*p, n + 1, p))`. It runs in C and is about 20 times faster than a loop.

Store the **smallest prime factor** of every number instead of True/False, and you can factorise any number up to `n` in O(log n): divide by `spf[x]` until you reach 1.

```run
title: Trial division, the sieve and the smallest-prime-factor table
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

def sieve(n):
    s = [True] * (n + 1)
    s[0] = s[1] = False
    for p in range(2, math.isqrt(n) + 1):
        if s[p]:
            s[p * p::p] = [False] * len(range(p * p, n + 1, p))
    return s

print([p for p in range(30) if is_prime(p)])
s, t = timed(sieve, 10 ** 6)
print(sum(s), "primes below a million, in", round(t, 3), "seconds")

def spf_table(n):
    spf = list(range(n + 1))
    for p in range(2, math.isqrt(n) + 1):
        if spf[p] == p:
            for m in range(p * p, n + 1, p):
                if spf[m] == m:
                    spf[m] = p
    return spf

spf = spf_table(1000)
x, parts = 360, []
while x > 1:
    parts.append(spf[x])
    x //= spf[x]
print(parts)
```

## Counting divisors

Write `n = p₁^e₁ · p₂^e₂ · …`. A divisor picks each exponent from `0` to `eᵢ`, so `n` has **(e₁ + 1)(e₂ + 1)…** divisors. `360 = 2³·3²·5` has `4·3·2 = 24`. The leftover after trial division up to √n, if it's above 1, is one last prime (exponent 1).

## Primes in disguise

```exercise

---prompt
Return how many divisors `n` has (`1 ≤ n ≤ 10¹²`), using the factorisation rule: the product of `(e + 1)` over the prime exponents.
---starter

def count_divisors(n):
    c, d = 1, 2
    while d * d <= n:
        e = 0
        while n % d == 0:
            n //= d
            e += 1
        c *= e + 1
        d += 1
    if n > 1:
        c *= 2
    return c
```

```exercise

kind: write
---prompt
*LeetCode 2523, asked at Amazon.* Return `[a, b]`, the two primes in `[left, right]` that are closest together (`a < b`, smallest `a` on a tie), or `[-1, -1]` if there are fewer than two primes. `right` can be a million.
---starter
def closest_primes(left, right):
    ps = [x for x in range(max(left, 2), right + 1) if all(x % d for d in range(2, 4) if d < x)]
    return ps[:2] if len(ps) >= 2 else [-1, -1]
---solution
def closest_primes(left, right):
    s = [True] * (right + 1)
    s[0] = False
    if right >= 1:
        s[1] = False
    for p in range(2, math.isqrt(right) + 1):
        if s[p]:
            s[p * p::p] = [False] * len(range(p * p, right + 1, p))
    ps = [x for x in range(left, right + 1) if s[x]]
    best = [-1, -1]
    for a, b in zip(ps, ps[1:]):
        if best[0] < 0 or b - a < best[1] - best[0]:
            best = [a, b]
    return best
---tests

assert closest_primes(1000000, 1000100) == [1000037, 1000039]
assert closest_primes(1, 10 ** 6) == [2, 3]
---hint
```

```exercise
---prompt
Return every prime in `[L, R]`, where `R` can be `10¹² + 10⁵` but `R − L ≤ 10⁵`. A sieve up to `R` won't fit in memory. Sieve the **base primes** up to `√R` instead, then cross off their multiples inside the window only, starting at `max(p², the first multiple of p ≥ L)`.

def primes_between(L, R):
    base = [p for p in range(2, 1000) if all(p % d for d in range(2, math.isqrt(p) + 1))]

---solution
def primes_between(L, R):
    r = math.isqrt(R)
    s = [True] * (r + 1)
    s[0] = False
    if r >= 1:
        s[1] = False
    for p in range(2, math.isqrt(r) + 1):
        if s[p]:
            s[p * p::p] = [False] * len(range(p * p, r + 1, p))
    mark = [True] * (R - L + 1)
    for p in range(2, r + 1):
        if s[p]:
            start = max(p * p, (L + p - 1) // p * p)
            if start <= R:
                mark[start - L::p] = [False] * len(range(start, R + 1, p))
    return [L + i for i, v in enumerate(mark) if v and L + i >= 2]
---tests

assert primes_between(10 ** 12, 10 ** 12 + 100) == [1000000000039, 1000000000061, 1000000000063, 1000000000091]
assert len(primes_between(10 ** 12, 10 ** 12 + 10 ** 5)) == 3614
```

```exercise
    if n < 2:

    if n < 4:
```

```recall
Q: Explain trial division and why it stops at √n, how the Sieve of Eratosthenes works and why it starts at p², and how a smallest-prime-factor table factorises numbers and counts divisors.
A: A prime has exactly two divisors, so 1 is not prime. Trial division tests one number by dividing by 2, 3, … up to √n, because if n = a·b one factor is at most √n; that is O(√n) per number, fine for one number near 10¹² but too slow for every number up to a million. The Sieve of Eratosthenes marks everything as maybe prime, then each unmarked p is prime and crosses off p², p² + p, …, stopping when p² passes n; starting at p² is safe because smaller multiples k·p were already crossed off by k's smallest prime, and the total work n/2 + n/3 + n/5 + … is O(n log log n). In Python a slice assignment does the crossing in C. Storing the smallest prime factor instead of True/False lets you factorise any x up to n in O(log x) by dividing by spf[x] repeatedly, provided the table keeps the first (smallest) prime that reaches each number. With n = p₁^e₁ · p₂^e₂ · …, the number of divisors is (e₁ + 1)(e₂ + 1)…. For huge ranges, a segmented sieve sieves base primes up to √R and crosses off their multiples in the window [L, R] only.
```
