## Squaring doubles the exponent

Problems love answers like `2^(10¹⁸) mod 1,000,000,007`. Multiplying one at a time takes 10¹⁸ steps. But **squaring doubles the exponent**: `3 → 3² → 3⁴ → 3⁸ → …`. Write the exponent in binary and multiply together the powers whose bit is 1:

```viz
name: ds-fastpow
title: 3¹⁰⁰ mod 997, two ways
goal: Run **multiply 100 times** to the end, then run **square and multiply** and compare.
height: 470
100 = 64 + 32 + 4, so 3¹⁰⁰ = 3⁶⁴ · 3³² · 3⁴.
```

**Binary exponentiation**, iteratively: keep `result = 1` and `base = a`. While `e > 0`: if `e` is odd, `result = result · base`; then `base = base²` and `e //= 2`. Reduce mod `m` after every multiplication. It's O(log e): about 60 squarings for 10¹⁸.

In Python, `pow(a, e, m)` does exactly this, in C. Never write `a ** e % m` for a big `e`: it builds the whole giant number first.

## Dividing modulo a prime

Chapter 37 said division doesn't survive `% M`. Instead, multiply by the **inverse**: the `b⁻¹` with `b · b⁻¹ ≡ 1 (mod M)`.

- **Fermat's little theorem**: if `M` is prime and `b` isn't a multiple of it, `b^(M−1) ≡ 1`, so `b⁻¹ = b^(M−2) mod M`. One fast power.
- So `a / b mod M = a · pow(b, M − 2, M) % M`. Python 3.8+ also has `pow(b, -1, M)`.
- If `M` **isn't prime**, use extended Euclid (chapter 37): `b·x + M·y = 1` makes `x` the inverse. It exists only when `gcd(b, M) = 1`.

That's how a probability `P/Q` is reported "modulo 998244353": as `P · Q⁻¹`.

```run
title: Fast power by hand, and dividing by inverses
def fast_pow(a, e, m):
    result, base = 1, a % m
    while e > 0:
        if e & 1:
            result = result * base % m
        base = base * base % m
        e >>= 1
    return result

print(fast_pow(3, 100, 997), pow(3, 100, 997))
print(fast_pow(2, 10 ** 18, M))

inv2 = pow(2, M - 2, M)
print(inv2, 2 * inv2 % M)
print("7 / 2 mod M =", 7 * inv2 % M)
print(pow(3, -1, 10), "because 3 × 7 = 21")
```

## The ladder

```exercise
title: mod_pow
kind: write
---prompt
Write `mod_pow(a, e, m)` with square-and-multiply (no `pow`). `e` can be `10¹⁸`.
---starter
def mod_pow(a, e, m):
    if e == 0:
        return 1 % m
    half = mod_pow(a, e // 2, m)
    return half * half % m
---solution
def mod_pow(a, e, m):
    result, base = 1 % m, a % m
    while e > 0:
        if e & 1:
            result = result * base % m
        base = base * base % m
        e >>= 1
    return result
---tests

assert mod_pow(123456789, 987654321987654321, 10 ** 9 + 7) == 689051811
assert mod_pow(7, 5, 1) == 0
---hint
When `e` is odd, `e // 2` drops one factor of `a`. `a^7 = (a^3)² · a`.
```

## Powers in disguise

```exercise
title: my_pow
kind: write
---prompt
*LeetCode 50, asked at Meta, Amazon and LinkedIn.* Return `x` to the power `n` for a float `x` and an integer `n` that can be negative or as big as `2³¹ − 1`. Don't use `**` or `pow`.
---starter
def my_pow(x, n):
    result, base, e = 1.0, x, abs(n)
    while e:
        if e & 1:
            result *= base
        base *= base
        e >>= 1
    return result
---solution
def my_pow(x, n):
    result, base, e = 1.0, x, abs(n)
    while e:
        if e & 1:
            result *= base
        base *= base
        e >>= 1
    return 1 / result if n < 0 else result
---tests
assert abs(my_pow(2.0, 10) - 1024.0) < 1e-9
assert abs(my_pow(2.1, 3) - 9.261) < 1e-9
assert abs(my_pow(2.0, -2) - 0.25) < 1e-12
assert my_pow(1.0, 2 ** 31 - 1) == 1.0
assert abs(my_pow(0.5, -3) - 8.0) < 1e-12
---hint
`x⁻ⁿ = 1 / xⁿ`.
```

```exercise
title: inverse_any_mod
kind: write
---prompt
Return the inverse of `b` modulo `m` (any `m ≥ 2`, not necessarily prime) as a number in `[0, m)`, or `None` if it doesn't exist. Use extended Euclid; don't use `pow(b, -1, m)`.
---starter
def mod_inverse(b, m):
    return pow(b, m - 2, m)
---solution
def mod_inverse(b, m):
    def ext(a, c):
        if c == 0:
            return a, 1, 0
        d, x, y = ext(c, a % c)
        return d, y, x - (a // c) * y
    g, x, _ = ext(b % m, m)
    if g != 1:
        return None
    return x % m
---tests
assert mod_inverse(3, 10) == 7
assert mod_inverse(4, 10) is None
assert mod_inverse(17, 3120) == 2753
assert mod_inverse(2, 10 ** 9 + 7) == 500000004
assert mod_inverse(10, 17) * 10 % 17 == 1
---hint
Fermat only works when `m` is prime: 10 isn't. Extended Euclid gives `b·x + m·y = gcd`, and when the gcd is 1, `x` is the inverse.
```

## Real-world project: a toy RSA

```project
title: Lock a message with two primes
client: A security workshop that wants attendees to see public-key encryption working with numbers they can check by hand
skills: fast modular power, modular inverses modulo a non-prime, Euler's φ
---brief
Build `rsa.py`. Pick two primes `p` and `q`, set `n = p·q` and `φ = (p − 1)(q − 1)`. The public key is `(n, e)` with `gcd(e, φ) = 1` (usually `e = 65537`); the private key is `d = e⁻¹ mod φ`, found with extended Euclid, since φ isn't prime. Encrypt a number `m < n` as `c = m^e mod n` and decrypt with `c^d mod n`. Both are fast powers. Show that it round-trips for small primes and for primes near 10⁹.
---why
RSA protected most of the web's key exchanges for decades and still signs software and certificates. Fast power and inverses also appear in Diffie-Hellman, hashing, and every contest answer "modulo a prime".
---milestones
- Make the key pair from p, q and e
- Encrypt and decrypt numbers
- Turn short text into a number and back
- Show that the wrong d gives garbage
---stretch
- Sign a message and verify the signature
- Speed up decryption with the Chinese remainder theorem
```

## Rebuild it and explain it

```exercise
title: divide_rebuild
kind: rebuild
---prompt
From memory, without `pow`: `divide(a, b)` returns `a / b` modulo the prime `M = 1,000,000,007`. Write your own square-and-multiply and use Fermat's little theorem.
---starter
def divide(a, b):
    pass
---solution
def divide(a, b):
    def fp(x, e):
        r, x = 1, x % M
        while e:
            if e & 1:
                r = r * x % M
            x = x * x % M
            e >>= 1
        return r
    return a % M * fp(b, M - 2) % M
---tests
assert divide(6, 3) == 2
assert divide(7, 2) == 500000007
assert divide(1, 2) * 2 % M == 1
assert divide(10 ** 18, 10 ** 9) == 10 ** 9 % M
assert divide(-1, 3) * 3 % M == M - 1
---hint
`b⁻¹ = b^(M−2) mod M`. Reduce `a` first so a negative `a` lands in range.
```

```recall
Q: Explain square-and-multiply and why it is O(log e), how to divide modulo a prime, and how to find an inverse when the modulus isn't prime.
A: Multiplying a by itself e times is O(e), hopeless for e = 10¹⁸. Squaring doubles the exponent, so a, a², a⁴, a⁸, … take one multiplication each, and writing e in binary says which of those powers to multiply into the result: when the lowest bit is 1 multiply, then square the base and halve e. That is O(log e), about 60 squarings for 10¹⁸, reducing mod m after every step; Python's pow(a, e, m) does it, while a ** e % m builds a giant number first. Division does not survive reduction, so instead multiply by the inverse b⁻¹ with b·b⁻¹ ≡ 1. If M is prime, Fermat's little theorem gives b^(M−1) ≡ 1, so b⁻¹ = b^(M−2) mod M; that is how a probability P/Q is reported as P·Q⁻¹. If the modulus isn't prime, extended Euclid solves b·x + m·y = 1, and x mod m is the inverse, which exists only when gcd(b, m) = 1. RSA uses both: d = e⁻¹ mod (p − 1)(q − 1), and messages are encrypted and decrypted with fast powers.
```
