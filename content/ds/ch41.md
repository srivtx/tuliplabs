## An integer is a row of switches

Every integer is stored in binary: `13 = 1101₂ = 8 + 4 + 1`. Bit `i` is worth `2ⁱ`. Treating a number as a row of yes/no switches gives you a set of up to 64 items in one machine word, with set operations that take a single instruction.

With `12 = 1100₂` and `10 = 1010₂`:

- **AND** `a & b`, in both: `1000₂ = 8`
- **OR** `a | b`, in either: `1110₂ = 14`
- **XOR** `a ^ b`, in exactly one: `0110₂ = 6`
- **shift left** `a << k`, × 2ᵏ: `12 << 1 = 24`
- **shift right** `a >> k`, // 2ᵏ: `12 >> 2 = 3`

The everyday moves:

- **Is bit i on?** `x >> i & 1`. **Turn it on**: `x | 1 << i`. **Off**: `x & ~(1 << i)`. **Flip**: `x ^ 1 << i`.
- **Clear the lowest 1**: `x & (x − 1)`. So `x` is a power of two exactly when `x > 0` and `x & (x − 1) == 0`.
- **Keep only the lowest 1**: `x & −x` (Fenwick trees use this, chapter 45).
- **Count the 1s** (popcount): `x.bit_count()` in Python 3.10+, or `bin(x).count("1")`.
- **All subsets of n items**: `for mask in range(1 << n)`, and item `i` is in when `mask >> i & 1`.

**XOR** is the star: `x ^ x = 0`, `x ^ 0 = x`, and order doesn't matter. Pairs cancel:

```viz
name: ds-xor
title: The number without a partner
goal: Run **tally every value** to the end, then run **XOR everything** and compare the memory.
height: 450
Every bit of the running total flips twice for a pair: back to where it started.
```

Watch the precedence: in Python, `==` binds **tighter** than `&`, so `x & 1 == 0` means `x & (1 == 0)`. Always bracket: `(x & 1) == 0`.

```run

x = 0b101100
print(x, bin(x), x.bit_count())
print("bit 2 on?", x >> 2 & 1, " bit 0 on?", x >> 0 & 1)

print("powers of two:", [n for n in range(1, 70) if n & (n - 1) == 0])

items = ["apple", "bread", "cheese"]
for mask in range(1 << len(items)):
    print(f"{mask:03b}", [items[i] for i in range(len(items)) if mask >> i & 1])

nums = [4, 1, 2, 1, 2]
acc = 0
for v in nums:
    acc ^= v
print("the loner:", acc)
```

## The ladder

```exercise
title: single_number
kind: write
---prompt
*LeetCode 136, asked at Amazon, Google and Apple.* Every number appears twice except one. Return it in O(n) time and O(1) extra memory.
---starter
def single_number(nums):
    return sorted(nums)[0]
---solution
def single_number(nums):
    acc = 0
    for x in nums:
        acc ^= x
    return acc
---tests
assert single_number([2, 2, 1]) == 1
assert single_number([4, 1, 2, 1, 2]) == 4
assert single_number([1]) == 1
assert single_number([-3, 7, 7]) == -3
assert single_number(list(range(1, 50001)) * 2 + [77777]) == 77777
---hint
`a ^ a = 0`. XOR everything together and the pairs disappear.
```

```exercise
title: power_of_two_bug
kind: bug
---prompt

def is_power_of_two(n):

---solution
def is_power_of_two(n):

assert is_power_of_two(1) and is_power_of_two(16) and is_power_of_two(2 ** 40)

Python reads `n & n - 1 == 0` as `n & ((n - 1) == 0)`. Bracket the AND, and rule out `n ≤ 0`.
```

## Bits in disguise

```exercise
title: all_subsets
kind: write
---prompt
*LeetCode 78, asked at Meta and Amazon.* Return every subset of `nums` (distinct values). Loop over masks `0 .. 2ⁿ − 1`, keeping the items in index order. The order of subsets is up to you.
---starter
def subsets(nums):
    return [[]] + [[x] for x in nums]
---solution
def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1] for mask in range(1 << n)]
---tests
assert sorted(subsets([1, 2, 3])) == [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
assert subsets([0]) == [[], [0]] or sorted(subsets([0])) == [[], [0]]
assert len(subsets(list(range(12)))) == 4096
---hint
Mask `101₂` means "take item 0 and item 2". Every mask from 0 to `2ⁿ − 1` is a different subset.
```

```exercise
title: missing_number
kind: write
---prompt
*LeetCode 268, asked at Amazon and Microsoft.* `nums` holds `n` distinct numbers from `0..n`, so exactly one is missing. Find it with XOR: XOR all the indices `0..n` and all the values, and every present number cancels.
---starter
def missing_number(nums):
    return len(nums)
---solution
def missing_number(nums):
    acc = len(nums)
    for i, x in enumerate(nums):
        acc ^= i ^ x
    return acc
---tests
assert missing_number([3, 0, 1]) == 2
assert missing_number([0, 1]) == 2
assert missing_number([9, 6, 4, 2, 3, 5, 7, 0, 1]) == 8
assert missing_number([1]) == 0
---hint
Start from `n` (it has no index of its own), then XOR in each index and each value.
```

```exercise
title: single_number_ii
kind: write
---prompt
*LeetCode 137, asked at Google.* Every number appears **three** times except one, which appears once. XOR doesn't cancel triples. Instead, for each of the 32 bits, count how many numbers have it on: modulo 3, what's left is the loner's bit. Numbers can be negative (32-bit two's complement).
---starter
def single_number_ii(nums):
    acc = 0
    for x in nums:
        acc ^= x
    return acc
---solution
def single_number_ii(nums):
    r = 0
    for b in range(32):
        if sum((x >> b) & 1 for x in nums) % 3:
            r |= 1 << b
    return r - (1 << 32) if r >= 1 << 31 else r
---tests
assert single_number_ii([2, 2, 3, 2]) == 3
assert single_number_ii([0, 1, 0, 1, 0, 1, 99]) == 99
assert single_number_ii([-2, -2, 1, 1, 4, 1, 4, 4, -4, -2]) == -4
---hint
Three copies of a number add 3 (or 0) to each bit count, which is 0 modulo 3. Bit 31 set means the answer is negative: subtract `2³²`.
```

```exercise
title: maximum_xor_pair
kind: write
---prompt
*LeetCode 421, asked at Google.* Return the largest `a ^ b` over pairs in `nums` (`0 ≤ x < 2³¹`, up to 20,000 numbers). Build the answer greedily from the top bit: keep the set of every number's top bits, and try to switch the next answer bit on. `cand = ans | 1 << b` is possible if some prefix `p` has `cand ^ p` also in the set.
---starter
def max_xor(nums):
    return max(nums) ^ min(nums)
---solution
def max_xor(nums):
    ans = mask = 0
    for b in range(30, -1, -1):
        mask |= 1 << b
        pre = {x & mask for x in nums}
        cand = ans | 1 << b
        if any(cand ^ p in pre for p in pre):
            ans = cand
    return ans
---tests
assert max_xor([3, 10, 5, 25, 2, 8]) == 28
assert max_xor([14, 70, 53, 83, 49, 91, 36, 80, 92, 51, 66, 70]) == 127
assert max_xor([0]) == 0
assert max_xor([(i * 2654435761) % 2 ** 31 for i in range(20000)]) == 2147442413
---hint
`a ^ b = cand` means `a = cand ^ b`. So checking "is there a pair with this prefix?" is a set lookup, the same trick as two-sum (chapter 3).
```

```exercise
title: apply_permission_changes
kind: write
---prompt
Start from `mask` and apply each change in order: `("grant", i)` turns bit `i` on, `("revoke", i)` turns it off, `("toggle", i)` flips it. Return the final mask.
---starter
def apply_changes(mask, changes):
    for op, i in changes:
        if op == "grant":
            mask |= 1 << i
        elif op == "revoke":
            mask ^= 1 << i
        else:
            mask ^= 1 << i
    return mask
---solution
def apply_changes(mask, changes):
    for op, i in changes:
        if op == "grant":
            mask |= 1 << i
        elif op == "revoke":
            mask &= ~(1 << i)
        else:
            mask ^= 1 << i
    return mask
---tests
assert apply_changes(0, [("grant", 0), ("grant", 2)]) == 5
assert apply_changes(5, [("revoke", 0)]) == 4
assert apply_changes(4, [("revoke", 0)]) == 4
assert apply_changes(0b1111, [("toggle", 1), ("revoke", 3), ("grant", 5)]) == 0b100101
---hint
Revoking a permission the user doesn't have should change nothing. XOR would grant it.
```

```exercise
title: users_with_all
kind: write
---prompt
Return the indices of users whose mask includes **every** bit of `required`.
---starter
def users_with_all(masks, required):
    return [i for i, m in enumerate(masks) if m & required]
---solution
def users_with_all(masks, required):
    return [i for i, m in enumerate(masks) if (m & required) == required]
---tests
assert users_with_all([0b111, 0b101, 0b011, 0b100], 0b101) == [0, 1]
assert users_with_all([1, 2, 4], 0) == [0, 1, 2]
assert users_with_all([8, 9, 10, 11], 0b11) == [3]
---hint
`m & required` being non-zero only means "at least one". All of them means the AND gives back `required` itself.
```

## Rebuild it and explain it

```exercise
title: subset_sum_rebuild
kind: rebuild
---prompt
From memory: count the subsets of `nums` (up to 16 numbers) whose sum is exactly `target`, by looping over every bitmask.
---starter
def count_subsets(nums, target):
    pass
---solution
def count_subsets(nums, target):
    n, count = len(nums), 0
    for mask in range(1 << n):
        s = 0
        for i in range(n):
            if mask >> i & 1:
                s += nums[i]
        if s == target:
            count += 1
    return count
---tests
assert count_subsets([1, 2, 3, 4, 5], 5) == 3
assert count_subsets([2] * 10, 4) == 45
assert count_subsets([], 0) == 1
assert count_subsets(list(range(1, 17)), 40) == 498
---hint
Mask `m` contains item `i` exactly when `m >> i & 1`. The empty mask is a subset with sum 0.
```

```recall
Q: Explain how an integer works as a set of bits, the main bit operations and tricks, looping over subsets with masks, and why XOR finds the unpaired element.
A: An integer is a row of bits, bit i worth 2ⁱ, so one integer can store up to 64 yes/no flags. AND keeps bits in both, OR bits in either, XOR bits in exactly one, and shifts multiply or divide by powers of two. Test bit i with x >> i & 1, set it with x | 1 << i, clear it with x & ~(1 << i), flip it with x ^ 1 << i. x & (x − 1) clears the lowest 1 bit, so x > 0 with x & (x − 1) == 0 means a power of two; x & −x keeps the lowest 1; popcount counts the 1s. In Python comparisons bind tighter than &, so always bracket. Looping mask from 0 to 2ⁿ − 1 visits every subset of n items, fine up to about n = 20. XOR satisfies x ^ x = 0 and x ^ 0 = x and ignores order, so XOR-ing a list cancels every pair and leaves the unpaired value in O(1) memory, where a tally needs a slot per value; for triples, count each bit modulo 3 instead.
```
