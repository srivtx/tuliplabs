## Graphs and adjacency lists

A **graph** is nodes joined by edges. Edges can be **undirected** (friendships, roads) or **directed** (follows, "must come before"). The standard way to store one is an **adjacency list**: for each node, the list of its neighbours. It takes O(V + E) memory.

```run
title: Build an adjacency list from an edge list
from collections import defaultdict
edges = [(0, 1), (1, 2), (3, 4)]
g = defaultdict(list)
for a, b in edges:
    g[a].append(b)
    g[b].append(a)
for v in range(5):
    print(v, "→", g[v])
```

**Depth-first search** goes as deep as it can along one route before backing up. It visits everything reachable from the start in O(V + E). Recursion is the shortest way to write it, but Python's recursion limit makes an explicit stack safer for big inputs.

## Counting the pieces

A **connected component** is a group of nodes that can all reach each other. To count them: loop over every node, and each time you find one that isn't visited, that's a new component. Search from it to mark the whole piece.

```exercise
title: num_islands
kind: write
---prompt
*LeetCode 200, the most-asked graph question at Amazon.* In a grid of `"1"` (land) and `"0"` (water), count the islands (land connected up, down, left, right). Every time you meet unvisited land, count one and flood-fill the whole island.
---starter
def num_islands(grid):
    return sum(row.count("1") for row in grid)
---solution
def num_islands(grid):
    R, C = len(grid), len(grid[0])
    seen, count = set(), 0
    for r in range(R):
        for c in range(C):
            if grid[r][c] == "1" and (r, c) not in seen:
                count += 1
                seen.add((r, c))
                stack = [(r, c)]
                while stack:
                    y, x = stack.pop()
                    for ny, nx in ((y + 1, x), (y - 1, x), (y, x + 1), (y, x - 1)):
                        if 0 <= ny < R and 0 <= nx < C and grid[ny][nx] == "1" and (ny, nx) not in seen:
                            seen.add((ny, nx))
                            stack.append((ny, nx))
    return count
---tests
assert num_islands(["11110", "11010", "11000", "00000"]) == 1
assert num_islands(["11000", "11000", "00100", "00011"]) == 3
assert num_islands(["0"]) == 0
assert num_islands(["101", "010", "101"]) == 5
---hint
Outer loops find a new island; an inner stack (or recursion) marks all of its land so it isn't counted again.
```

```exercise
title: count_components
kind: write
---prompt
*LeetCode 323.* `n` nodes labelled `0..n-1` and a list of undirected edges. Return the number of connected components. Build an adjacency list first; then it's islands on a graph.
---starter
def count_components(n, edges):
    return n - len(edges)
---solution
def count_components(n, edges):
    g = [[] for _ in range(n)]
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    seen, count = [False] * n, 0
    for s in range(n):
        if not seen[s]:
            count += 1
            seen[s] = True
            stack = [s]
            while stack:
                v = stack.pop()
                for w in g[v]:
                    if not seen[w]:
                        seen[w] = True
                        stack.append(w)
    return count
---tests

assert count_components(4, [(0, 1), (1, 2), (2, 0)]) == 2
assert count_components(3, []) == 3
---hint
`n - edges` is only right when there are no cycles: the triangle `0-1-2` has 3 edges but uses only 2 of them to connect.
```

## Cycles

**Undirected**: during DFS, a neighbour that's already visited and isn't the node you just came from (your parent) closes a loop.

**Directed**: that test gives false alarms, because two routes can reach the same node without any loop. Use three colours: white (unseen), grey (on the current path), black (finished). Only an edge into a **grey** node is a cycle.

```viz

```

```exercise
title: undirected_cycle
kind: write
---prompt
Does an undirected graph (`n` nodes, edge list, no repeated edges) contain a cycle? DFS from every unvisited node, carrying the parent; a visited neighbour other than the parent means a cycle.
---starter
def has_cycle(n, edges):
    return len(edges) > 0
---solution
def has_cycle(n, edges):
    g = [[] for _ in range(n)]
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    seen = [False] * n
    for s in range(n):
        if seen[s]:
            continue
        seen[s] = True
        stack = [(s, -1)]
        while stack:
            v, parent = stack.pop()
            for w in g[v]:
                if w == parent:
                    continue
                if seen[w]:
                    return True
                seen[w] = True
                stack.append((w, v))
    return False
---tests
assert has_cycle(3, [(0, 1), (1, 2), (2, 0)])
assert not has_cycle(4, [(0, 1), (1, 2), (2, 3)])
assert not has_cycle(5, [(0, 1), (0, 2), (3, 4)])
assert has_cycle(6, [(0, 1), (3, 4), (4, 5), (5, 3)])
assert not has_cycle(1, [])
---hint
A tree's edges look like a cycle from both ends unless you skip the edge back to your parent.
```

```exercise
def can_visit_all(rooms):
    seen, stack = {0}, [0]
```

## Two colours: bipartite graphs

A graph is **bipartite** if you can colour every node red or blue so that every edge joins different colours (two teams, no rivals on the same team). Colour the start red, its neighbours blue, theirs red… If an edge ever joins two nodes of the same colour, it's impossible: that happens exactly when there's an odd-length cycle.

```exercise
title: is_bipartite
kind: write
---prompt
*LeetCode 785, asked at Meta.* `g[i]` lists node i's neighbours (undirected; the graph may be disconnected). Return whether it's bipartite. BFS or DFS from every uncoloured node, giving each neighbour the opposite colour.
---starter
def is_bipartite(g):
    return all(len(nb) <= 2 for nb in g)
---solution
def is_bipartite(g):
    color = [-1] * len(g)
    for s in range(len(g)):
        if color[s] >= 0:
            continue
        color[s] = 0
        q = deque([s])
        while q:
            v = q.popleft()
            for w in g[v]:
                if color[w] < 0:
                    color[w] = 1 - color[v]
                    q.append(w)
                elif color[w] == color[v]:
                    return False
    return True
---tests
assert not is_bipartite([[1, 2, 3], [0, 2], [0, 1, 3], [0, 2]])
assert is_bipartite([[1, 3], [0, 2], [1, 3], [0, 2]])
assert not is_bipartite([[1, 2], [0, 2], [0, 1]])
assert is_bipartite([[], [2], [1]])
---hint
`color[w] = 1 - color[v]`. A neighbour already holding the **same** colour proves it's impossible.
```

```exercise
title: bipartite_edges
kind: write
---prompt
*Codeforces 862B "Mahmoud and Ehab and the bipartiteness".* A tree with `n` nodes is given as an edge list. Return how many more edges you can add (no repeats, no self-loops) while keeping the graph bipartite. Colour the tree: with `a` red and `b` blue nodes, a bipartite graph has at most `a · b` edges, and `n - 1` are already there.
---starter
def more_edges(n, edges):
    return n * (n - 1) // 2 - (n - 1)
---solution
def more_edges(n, edges):
    g = [[] for _ in range(n + 1)]
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    color = [-1] * (n + 1)
    color[1] = 0
    stack = [1]
    while stack:
        v = stack.pop()
        for w in g[v]:
            if color[w] < 0:
                color[w] = 1 - color[v]
                stack.append(w)
    a = color.count(0)
    return a * (n - a) - (n - 1)
---tests

assert more_edges(5, [(1, 2), (2, 3), (3, 4), (4, 5)]) == 2

assert more_edges(4, [(1, 2), (1, 3), (1, 4)]) == 0
---hint
Nodes are numbered from 1. Count the reds; the blues are `n - reds`.
```

```exercise

def bucket(canvas, r, c, new):
    out = [row[:] for row in canvas]
    old = out[r][c]
    if old == new:
        return out
```

```recall
Q: Explain depth-first search on graphs and how it counts components, fills regions and detects cycles in undirected and directed graphs.
A: Store a graph as an adjacency list (O(V + E)) and explore it with depth-first search, which follows one route as deep as possible before backing up, visiting everything reachable in O(V + E); in Python an explicit stack avoids the recursion limit. Looping over all nodes and starting a new search from each unvisited one counts connected components (islands, friend groups) and finds each region's size; flood fill on a grid treats cells as nodes, and starting from the border marks regions that escape (surrounded regions). In an undirected graph, a visited neighbour that isn't the parent means a cycle. In a directed graph that test gives false alarms, because two paths can reach the same node, so use three colours: white unseen, grey on the current path, black finished; only an edge to a grey node closes a cycle (course schedule). Two-colouring with BFS or DFS tests whether a graph is bipartite, which fails exactly when there is an odd cycle.
```
