```prelude
import time
import heapq
import random
from collections import defaultdict

def timed(fn, *args):
    t = time.perf_counter()
    out = fn(*args)
    return out, time.perf_counter() - t

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True
```

## The cheapest way to connect everything

You have places and possible links between them, each with a cost: cables, roads, pipes. You want every place connected (directly or through others) for the least total cost. Any extra link would close a loop, and you could drop the dearest link in that loop and stay connected. So the answer has no cycles: it's a **tree** that touches every node, with exactly **n − 1** edges. That's a **minimum spanning tree** (MST).

**Kruskal's algorithm**:

1. Sort the edges by cost.
2. Go through them in order. If the two ends are in different groups (union-find from chapter 22), take the edge and merge the groups; otherwise skip it.
3. Stop after n − 1 edges.

O(E log E), and the sort is most of it.

**Why is greedy safe here?** The **cut property**: split the nodes into any two sides; the cheapest edge crossing between them belongs to some MST. Every edge Kruskal takes is the cheapest one joining its group to the rest.

```run
title: Kruskal on the villages
edges = [(0, 1, 3), (0, 2, 4), (1, 2, 2), (1, 3, 5), (2, 3, 3), (3, 4, 6), (1, 4, 7), (3, 5, 2),
         (2, 5, 3), (4, 6, 3), (5, 6, 7), (4, 5, 6), (6, 7, 2), (4, 7, 3), (0, 3, 4), (5, 7, 8)]
d = DSU(8)
tree = []
for a, b, w in sorted(edges, key=lambda e: e[2]):
    if d.union(a, b):
        tree.append((a, b, w))

print("cables:", len(tree), " total:", sum(w for _, _, w in tree))
```

## The ladder

```exercise
title: kruskal
kind: write
---prompt
Return the total cost of a minimum spanning tree of `n` nodes `0..n-1` with undirected `edges` `(a, b, w)`, or -1 if the graph isn't connected. Use the `DSU` from the prelude.
---starter
def mst_cost(n, edges):
    return sum(w for _, _, w in sorted(edges, key=lambda e: e[2])[:n - 1])
---solution
def mst_cost(n, edges):
    d = DSU(n)
    total = used = 0
    for a, b, w in sorted(edges, key=lambda e: e[2]):
        if d.union(a, b):
            total += w
            used += 1
    return total if used == n - 1 else -1
---tests
assert mst_cost(4, [(0, 1, 1), (1, 2, 2), (0, 2, 2), (2, 3, 3)]) == 6
assert mst_cost(3, [(0, 1, 1), (0, 1, 2), (1, 0, 3)]) == -1
assert mst_cost(4, [(0, 1, 1), (1, 2, 1), (0, 2, 1), (2, 3, 5), (1, 3, 4)]) == 6
assert mst_cost(1, []) == 0
random.seed(5)
n = 3000
edges = [(i, i + 1, random.randint(1, 100)) for i in range(n - 1)] + [(random.randrange(n), random.randrange(n), random.randint(1, 100)) for _ in range(60000)]
out, t = timed(mst_cost, n, edges)
```

## Prim's algorithm

**Prim** grows one tree from a start node. A heap holds the edges leaving the tree; pop the cheapest, and if it reaches a node not yet in the tree, add that node and push its edges. It's Dijkstra's loop with "edge weight" instead of "distance so far". With a heap it's O(E log V); on a **dense** graph (every pair connected) a simple O(n²) array version is faster still.

```parsons
title: Prim with a heap
---lines
def prim(g, n):
    seen = [False] * n
    heap = [(0, 0)]
    total = 0
    while heap:
        w, v = heapq.heappop(heap)
        if seen[v]:
            continue
        seen[v] = True
        total += w
        for x, wx in g[v]:
            if not seen[x]:
                heapq.heappush(heap, (wx, x))
    return total
?? heapq.heappush(heap, (w + wx, x))
?? seen[x] = True
---tests
g = {0: [(1, 2), (2, 3)], 1: [(0, 2), (2, 1)], 2: [(0, 3), (1, 1)]}
assert prim(g, 3) == 3
```

```exercise
title: connect_points
kind: write
---prompt
*LeetCode 1584, asked at Amazon and Microsoft.* Points on a plane; connecting two costs their **Manhattan distance** `|x1 − x2| + |y1 − y2|`. Return the minimum cost to connect them all. Every pair is a possible edge (a dense graph), so use the O(n²) Prim: keep `best[v]` = cheapest link from the tree to v, and each round add the closest outside point.
---starter
def min_cost(points):
    pts = sorted(points)
    return sum(abs(a[0] - b[0]) + abs(a[1] - b[1]) for a, b in zip(pts, pts[1:]))
---solution
def min_cost(points):
    n = len(points)
    best = [float("inf")] * n
    best[0] = 0
    inside = [False] * n
    total = 0
    for _ in range(n):
        v = min((i for i in range(n) if not inside[i]), key=lambda i: best[i])
        inside[v] = True
        total += best[v]
        x, y = points[v]
        for i in range(n):
            if not inside[i]:
                d = abs(points[i][0] - x) + abs(points[i][1] - y)
                if d < best[i]:
                    best[i] = d
    return total
---tests
assert min_cost([[0, 0], [2, 2], [3, 10], [5, 2], [7, 0]]) == 20
assert min_cost([[3, 12], [-2, 5], [-4, 1]]) == 18
assert min_cost([[0, 0]]) == 0
assert min_cost([[0, 0], [1, 1], [1, 0], [-1, 1]]) == 4
---hint
No edge list at all: compute distances on the fly. n rounds, each scanning n points: O(n²).
```

## MST tricks

```exercise
title: water_supply
kind: write
---prompt
*LeetCode 1168, asked at Google and Meta (hard).* `n` houses `1..n`. Building a well in house i costs `wells[i-1]`; laying a pipe `(a, b, c)` costs c. Every house needs water from a well, directly or through pipes. Minimum total? Add a **virtual node 0** "the water source" with an edge `(0, i, wells[i-1])` for each house, then run Kruskal on everything.
---starter
def water(n, wells, pipes):
    return sum(wells)
---solution
def water(n, wells, pipes):
    edges = [(0, i + 1, c) for i, c in enumerate(wells)] + list(pipes)
    d = DSU(n + 1)
    return sum(c for a, b, c in sorted(edges, key=lambda e: e[2]) if d.union(a, b))
---tests
assert water(3, [1, 2, 2], [(1, 2, 1), (2, 3, 1)]) == 3
assert water(2, [1, 1], [(1, 2, 1), (1, 2, 2)]) == 2
assert water(3, [5, 5, 5], [(1, 2, 1), (2, 3, 1)]) == 7
assert water(1, [4], []) == 4
---hint
A well is just "an edge to the source". After that it's an ordinary MST over n + 1 nodes.
```

```exercise
title: bottleneck
kind: write
---prompt
*A Codeforces and interview classic.* Connect all `n` towns with roads chosen from `edges` `(a, b, height_limit_cost)`. You don't care about the total, only about making the **largest** single cost as small as possible. Return that value (or -1 if impossible). An MST also minimises the largest edge, so it's the last edge Kruskal takes.
---starter
def bottleneck(n, edges):
    return min(w for _, _, w in edges) if edges else -1
---solution
def bottleneck(n, edges):
    d = DSU(n)
    joined, last = 1, -1
    for a, b, w in sorted(edges, key=lambda e: e[2]):
        if d.union(a, b):
            joined += 1
            last = w
            if joined == n:
                return w
    return 0 if n == 1 else -1
---tests
assert bottleneck(4, [(0, 1, 5), (1, 2, 3), (2, 3, 8), (0, 3, 4), (1, 3, 9)]) == 5
assert bottleneck(3, [(0, 1, 1)]) == -1
assert bottleneck(2, [(0, 1, 7), (0, 1, 2)]) == 2
assert bottleneck(1, []) == 0
---hint
Kruskal adds edges in increasing cost, so the moment everything is connected, the edge you just took is the answer.
```

```exercise
title: new_cables
kind: write
---prompt
`n` buildings, `existing` links (free, already in place) and `options` `(a, b, cost)` for new cables. Return the minimum total cost of new cables so everything is connected, or -1. Union the existing links first, then Kruskal over the options.
---starter
def new_cables(n, existing, options):
    d = DSU(n)
    return sum(c for a, b, c in sorted(options, key=lambda e: e[2]) if d.union(a, b))
---solution
def new_cables(n, existing, options):
    d = DSU(n)
    groups = n
    for a, b in existing:
        if d.union(a, b):
            groups -= 1
    total = 0
    for a, b, c in sorted(options, key=lambda e: e[2]):
        if d.union(a, b):
            total += c
            groups -= 1
    return total if groups == 1 else -1
---tests
assert new_cables(4, [(0, 1), (2, 3)], [(0, 2, 5), (1, 3, 4), (0, 3, 9)]) == 4
assert new_cables(3, [], [(0, 1, 1), (1, 2, 1)]) == 2
assert new_cables(3, [(0, 1), (1, 2)], [(0, 2, 7)]) == 0
assert new_cables(3, [], [(0, 1, 1)]) == -1
---hint
Free links go in before any paid one. Count groups so you can tell whether everything ended up connected.
```

```exercise
title: zones
kind: write
---prompt
Split `n` buildings into `k` zones: run Kruskal on `edges` `(a, b, distance)` but **stop** once only `k` groups remain. Return the **spacing**: the smallest distance between two buildings in different zones (the next edge Kruskal would have joined). Assume the graph is connected and `k ≥ 2`.
---starter
def spacing(n, edges, k):
    return sorted(w for _, _, w in edges)[k - 1]
---solution
def spacing(n, edges, k):
    d = DSU(n)
    groups = n
    for a, b, w in sorted(edges, key=lambda e: e[2]):
        if d.find(a) != d.find(b):
            if groups == k:
                return w
            d.union(a, b)
            groups -= 1
---tests
edges = [(0, 1, 1), (1, 2, 2), (3, 4, 1), (2, 3, 10), (0, 4, 12), (1, 3, 11)]
assert spacing(5, edges, 2) == 10
assert spacing(5, edges, 3) == 2
assert spacing(3, [(0, 1, 4), (1, 2, 4), (0, 2, 4)], 2) == 4
---hint
Edges inside a group are skipped as usual. The first edge that would merge two groups once you're down to k is the gap between zones.
```

## Rebuild it and explain it

```exercise
title: mst_rebuild
kind: rebuild
---prompt
From memory: `kruskal(n, edges)` returning the list of chosen edges `(a, b, w)` in the order Kruskal takes them. Write your own tiny union-find inside (don't use the prelude's).
---starter
def kruskal(n, edges):
    pass
---solution
def kruskal(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    tree = []
    for a, b, w in sorted(edges, key=lambda e: e[2]):
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[ra] = rb
            tree.append((a, b, w))
    return tree
---tests
assert kruskal(3, [(0, 1, 5), (1, 2, 1), (0, 2, 2)]) == [(1, 2, 1), (0, 2, 2)]
assert kruskal(2, [(0, 1, 3), (0, 1, 1)]) == [(0, 1, 1)]
---hint
Sort by weight, find both roots, take the edge if they differ.
```

```recall
Q: Explain minimum spanning trees: what they are, Kruskal and Prim, why greedy is correct, their costs and the common tricks.
A: A spanning tree connects all n nodes of an undirected graph with n − 1 edges and no cycles; a minimum spanning tree has the smallest total weight, because any cycle would have a most expensive edge that could be dropped. Kruskal sorts edges by weight and takes each one whose ends are in different union-find groups, skipping edges that would close a loop, in O(E log E). Prim grows a tree from one node with a heap of edges leaving it, adding the cheapest edge to a new node, in O(E log V), or O(n²) with an array on dense graphs such as all pairs of points. Greedy works because of the cut property: the cheapest edge crossing any split of the nodes belongs to some MST. An MST also minimises the largest edge, giving bottleneck answers. Tricks include a virtual source node so node costs become edges (wells), pre-joining free existing links, and stopping Kruskal at k groups for single-linkage clustering with maximum spacing.
```
