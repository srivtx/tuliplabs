## Pairing two groups

A graph is **bipartite** when its nodes split into two sides and every edge crosses between them: workers and the jobs they can do, students and project slots, rows and columns of a grid. A **matching** picks edges with no shared endpoint (each worker gets at most one job, each job at most one worker). The goal is a **maximum** matching: as many pairs as possible.

The obvious way, giving each worker the first free job, gets stuck:

```viz
name: ds-match
title: Six workers, six jobs
goal: Run **first free job** to the end, then run **augmenting paths** and compare.
height: 460
Lines show who can do what. Green lines are the current matching.
```

The fix is an **augmenting path**: start at a free worker, go to a job they can do; if a worker holds it, go to that worker and on to **another** job they can do; keep alternating until you reach a **free** job. Flip every line on the path (matched becomes unmatched and the other way round) and the matching grows by one, with nobody losing a job.

**Berge's theorem** says a matching is maximum **exactly when** no augmenting path exists. So:

**Kuhn's algorithm.** For each worker, run a DFS `try_kuhn(v)`: for each job j of v not yet visited **in this search**, mark it; if j is free, or its holder can find another job by `try_kuhn`, give j to v. That's O(V·E) in the worst case and quick in practice. (Hopcroft-Karp finds many shortest paths per round for O(E·√V), and max flow with unit capacities does the same job, chapter 53.)

**König's theorem** gives a second tool: in a bipartite graph, the fewest nodes that touch every edge (a **vertex cover**) is exactly the size of a maximum matching. "Fewest rows and columns that cover every marked cell" is a matching question in disguise.

```run
title: Kuhn's algorithm
def max_matching(nl, nr, adj):
    owner = [-1] * nr                      # owner[job] = worker holding it

    def try_kuhn(v, seen):
        for j in adj[v]:
            if not seen[j]:
                seen[j] = True
                if owner[j] == -1 or try_kuhn(owner[j], seen):
                    owner[j] = v
                    return True
        return False

    return sum(try_kuhn(v, [False] * nr) for v in range(nl)), owner

print(max_matching(6, 6, ADJ))
print(max_matching(400, 400, bigraph(400, 400, 1200, 3))[0])
```

## Matching in the wild

```exercise
title: domino_tiling
kind: write
---prompt
*A classic contest problem.* A grid has open cells `.` and blocked cells `#`. How many dominoes (each covers two side-by-side open cells) fit without overlapping? Colour the cells like a chessboard: every domino covers one black and one white cell, so it's a maximum matching from black cells to neighbouring white cells. 30 × 30 grid.
---starter
def dominoes(grid):
    return sum(row.count(".") for row in grid) // 2
---solution
def dominoes(grid):
    R, C = len(grid), len(grid[0])
    idx = {}
    for r in range(R):
        for c in range(C):
            if grid[r][c] == ".":
                idx[(r, c)] = len(idx)
    n = len(idx)
    adj = [[] for _ in range(n)]
    for (r, c), i in idx.items():
        if (r + c) % 2 == 0:
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                if (r + dr, c + dc) in idx:
                    adj[i].append(idx[(r + dr, c + dc)])
    owner = [-1] * n
    def try_kuhn(v, seen):
        for j in adj[v]:
            if not seen[j]:
                seen[j] = True
                if owner[j] == -1 or try_kuhn(owner[j], seen):
                    owner[j] = v
                    return True
        return False
    return sum(1 for (r, c), i in idx.items() if (r + c) % 2 == 0 and try_kuhn(i, [False] * n))
---tests
assert dominoes(["..", ".."]) == 2
assert dominoes([".#.", "...", ".#."]) == 2, "7 open cells, but the corners only touch the middle column"
assert dominoes(["#"]) == 0
g = lcg(900, 5, 1000)
grid = ["".join("#" if g[r * 30 + c] < 250 else "." for c in range(30)) for r in range(30)]
assert dominoes(grid) == 312
---hint
The starter assumes every pair of open cells can be covered. Shape matters: the plus-shaped grid has 7 open cells but fits only 2 dominoes.
---hint
Build lines only from black cells (`(r + c) % 2 == 0`) to their open neighbours, then run Kuhn from each black cell.
```

```exercise
title: fewest_lines
kind: write
---prompt
*König's theorem, a Codeforces favourite.* Some cells of a big grid are marked. A "line" is a whole row or a whole column. What's the fewest lines that cover every marked cell? Each marked cell (r, c) is an edge between row r and column c. A set of lines covering every cell is a **vertex cover**, and by König's theorem the smallest one has the size of a maximum matching.
---starter
def min_lines(cells):
    return min(len({r for r, c in cells}), len({c for r, c in cells}))
---solution
def min_lines(cells):
    rows = sorted({r for r, c in cells})
    cols = sorted({c for r, c in cells})
    ri = {r: i for i, r in enumerate(rows)}
    ci = {c: i for i, c in enumerate(cols)}
    adj = [[] for _ in rows]
    for r, c in cells:
        adj[ri[r]].append(ci[c])
    owner = [-1] * len(cols)
    def try_kuhn(v, seen):
        for j in adj[v]:
            if not seen[j]:
                seen[j] = True
                if owner[j] == -1 or try_kuhn(owner[j], seen):
                    owner[j] = v
                    return True
        return False
    return sum(try_kuhn(v, [False] * len(cols)) for v in range(len(rows)))
---tests
assert min_lines([(0, 0), (0, 2), (1, 1), (2, 1)]) == 2, "row 0 and column 1"
assert min_lines([(0, 0), (1, 1), (2, 2)]) == 3
assert min_lines([(0, 0), (0, 1), (0, 2)]) == 1
g = lcg(1200, 6, 1000)
cells = list(dict.fromkeys((g[2 * i] * 300 // 1000, g[2 * i + 1] * 300 // 1000) for i in range(600)))
assert min_lines(cells) == 220
---hint
The starter picks all rows or all columns. Mixing them can do better, and the best mix is exactly as big as a maximum matching between rows and columns.
```

```quiz
When is a matching maximum?
- When every left node is matched
* When there's no augmenting path (Berge's theorem)
- When the greedy method stops
- When every edge is used
> A matching can be maximum with nodes left over, if the graph simply doesn't allow more.
```

```quiz
Why must `seen` be reset for each new worker in Kuhn's algorithm?
- To save memory
* A job explored in an earlier failed or finished search may be reachable in a different way now; stale marks hide it
- Python needs it
- It doesn't matter
> Inside one search the marks stop loops. Across searches they block valid paths.
```

```quiz
A bipartite graph has a maximum matching of size 7. What's the smallest number of nodes that touch every edge?
- 14
* 7 (König's theorem)
- It depends on the edges
- 3.5
> In bipartite graphs, minimum vertex cover = maximum matching. (In general graphs that's not true.)
```

```quiz
How can max flow solve bipartite matching?
* Source → every left node (capacity 1), left → right along each line (1), every right node → sink (1); the max flow is the matching size

- By reversing every edge
```

```exercise
def place_interns(prefs, seats):
    seat_ids, n = {}, 0
    for t, k in enumerate(seats):
        seat_ids[t] = list(range(n, n + k))
        n += k
    adj = [[s for t in p for s in seat_ids.get(t, [])] for p in prefs]

                seen[j] = True

                    return True
        return False
```

```recall
Q: Explain bipartite matching: what a matching and an augmenting path are, Berge's theorem, how Kuhn's algorithm works and why seen is reset for each start, its cost, and König's theorem with an example.
A: In a bipartite graph every edge crosses between two sides. A matching is a set of edges with no shared endpoint, and a maximum matching has as many edges as possible. Greedily taking the first free partner can get stuck. An augmenting path starts at a free left node and alternates unmatched and matched edges until it reaches a free right node. Flipping every edge on it adds one pair and unmatches nobody. Berge's theorem: a matching is maximum exactly when no augmenting path exists. Kuhn's algorithm runs a DFS try_kuhn(v) for each left node: for each partner j not seen in this search, mark it, and if j is free or its owner can be rehoused by a recursive try_kuhn, give j to v. The marks stop loops within one search. They must be fresh for each new start, because stale marks from earlier searches block valid paths. Cost O(V·E); Hopcroft-Karp is O(E·√V), and unit-capacity max flow also works. König's theorem: in a bipartite graph, the minimum vertex cover equals the maximum matching. So the fewest rows and columns covering every marked cell is a matching between rows and columns, and dominoes on a grid are a matching between black and white cells.
```
