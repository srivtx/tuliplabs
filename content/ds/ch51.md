## Who can reach whom, and back

In a one-way graph (links on the web, follows on a social network, calls between functions, one-way streets), u can reach v without v reaching u. A **strongly connected component** (SCC) is a largest group in which **every node can reach every other** and come back. Every node belongs to exactly one SCC, possibly on its own.

The obvious way: search from every node, then group u and v together when each reaches the other. That's n searches, O(n·(n + m)): 10¹⁰ for a graph of 10⁵ nodes.

**Kosaraju's algorithm** needs only two searches over the whole graph:

1. **Pass 1.** DFS over the graph, starting a new search from every unvisited node. Write each node down when it **finishes** (all its roads are done).
2. **Pass 2.** Reverse every edge. Go through the nodes from **last finished to first**; each one not yet labelled starts a search on the reversed graph, and everything that search reaches is one SCC.

Why pass 2 can't leak: the last node to finish sits in a "source" group, with no roads coming in from other unvisited groups. Reversed, the roads leaving its group now point **in**, so a backward search stays home. Its group is then removed, and the next latest finisher is a source of what's left.

A bonus: SCCs come out in **topological order**. Shrink each one to a single node (the **condensation**), and every edge between groups goes from a lower group number to a higher one. The condensation never has a cycle, because a cycle of groups would be one bigger group. So any DAG technique (chapter 21's topological order, chapter 28's DP) now works on graphs **with** cycles.

For 10⁵ nodes, Python's recursion limit makes recursive DFS crash, so both passes use an explicit stack.

```run
title: Kosaraju with two iterative passes
def scc(n, edges):
    out = [[] for _ in range(n)]
    inn = [[] for _ in range(n)]
    for a, b in edges:
        out[a].append(b)
        inn[b].append(a)
    seen, order = [False] * n, []
    for s in range(n):                      # pass 1: finishing order
        if seen[s]:
            continue
        seen[s] = True
        st = [(s, 0)]
        while st:
            x, i = st[-1]
            if i < len(out[x]):
                st[-1] = (x, i + 1)
                y = out[x][i]
                if not seen[y]:
                    seen[y] = True
                    st.append((y, 0))
            else:
                st.pop()
                order.append(x)
    comp, c = [-1] * n, 0
    for s in reversed(order):               # pass 2: reversed edges
        if comp[s] != -1:
            continue
        comp[s] = c
        st = [s]
        while st:
            x = st.pop()
            for y in inn[x]:
                if comp[y] == -1:
                    comp[y] = c
                    st.append(y)
        c += 1
    return comp

print(scc(6, [(0, 1), (1, 2), (2, 0), (2, 3), (3, 4), (4, 3), (5, 4)]))
comp = scc(100000, digraph(100000, 120000, 3))
sizes = Counter(comp)
print(len(sizes), "groups, the biggest has", max(sizes.values()))
```

```exercise
def checkposts(cost, edges):
    n = len(cost)
    out = [[] for _ in range(n)]
    inn = [[] for _ in range(n)]
    for a, b in edges:
        out[a].append(b)
        inn[b].append(a)
    seen, order = [False] * n, []
    for s in range(n):
        if seen[s]:
            continue
        seen[s] = True
        st = [(s, 0)]
        while st:
            x, i = st[-1]
            if i < len(out[x]):
                st[-1] = (x, i + 1)
                y = out[x][i]
                if not seen[y]:
                    seen[y] = True
                    st.append((y, 0))
            else:
                st.pop()
                order.append(x)
    comp, c = [-1] * n, 0
    for s in reversed(order):
        if comp[s] != -1:
            continue
        comp[s] = c
        st = [s]
        while st:
            x = st.pop()
            for y in inn[x]:
                if comp[y] == -1:
                    comp[y] = c
                    st.append(y)
        c += 1
    best, ways = [None] * c, [0] * c
    for v in range(n):
        k = comp[v]
        if best[k] is None or cost[v] < best[k]:
            best[k], ways[k] = cost[v], 1
        elif cost[v] == best[k]:
            ways[k] += 1
    w = 1
    for x in ways:
        w = w * x % (10 ** 9 + 7)
    return sum(best), w
```

```exercise

---prompt
*CSES 1686, "Coin Collector".* Each room has some coins and tunnels are one-way. Starting anywhere and ending anywhere, what's the most coins you can collect? ---solution
def coin_collector(coins, edges):
    n = len(coins)
    out = [[] for _ in range(n)]
    inn = [[] for _ in range(n)]
    for a, b in edges:
        out[a].append(b)
        inn[b].append(a)
    seen, order = [False] * n, []
    for s in range(n):
        if seen[s]:
            continue
        seen[s] = True
        st = [(s, 0)]
        while st:
            x, i = st[-1]
            if i < len(out[x]):
                st[-1] = (x, i + 1)
                y = out[x][i]
                if not seen[y]:
                    seen[y] = True
                    st.append((y, 0))
            else:
                st.pop()
                order.append(x)
    comp, k = [-1] * n, 0
    for s in reversed(order):
        if comp[s] != -1:
            continue
        comp[s] = k
        st = [s]
        while st:
            x = st.pop()
            for y in inn[x]:
                if comp[y] == -1:
                    comp[y] = k
                    st.append(y)
        k += 1
    val = [0] * k
    for v in range(n):
        val[comp[v]] += coins[v]
    adj = [[] for _ in range(k)]
    for a, b in edges:
        if comp[a] != comp[b]:
            adj[comp[a]].append(comp[b])
    best = val[:]
    for c in range(k - 1, -1, -1):
        for d in adj[c]:
            best[c] = max(best[c], val[c] + best[d])
    return max(best)
```

```recall
Q: Explain strongly connected components: what one is, how Kosaraju's two passes find them and why pass 2 can't leak between groups, what the condensation is and why it's a DAG, and two problems that use it.
A: A strongly connected component is a largest set of nodes in a directed graph where every node can reach every other, and every node is in exactly one. Testing each pair needs a search from every node, O(n(n + m)). Kosaraju does two DFS passes, O(n + m). Pass 1 runs DFS over the whole graph and records nodes in the order they finish. Pass 2 reverses every edge and processes nodes from the last finisher to the first, and each search from an unlabelled node labels exactly one SCC. The last finisher lies in a source group of the remaining graph, so after reversal every edge leaving that group points into it, or into a group already labelled, and the search stays inside. Both passes use an explicit stack to avoid recursion limits. The condensation shrinks each SCC to one node. It's a DAG, because a cycle of groups would merge them into one, and Kosaraju's labels come out in topological order. Uses: Checkposts (one cheapest post per SCC, multiplying the ways), Coin Collector (sum the coins in each SCC, then a longest-path DP on the DAG), and the fewest edges to make a graph strongly connected, max(sources, sinks), or 0 for a single group.
```
