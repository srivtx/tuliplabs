## Two strings, one table

Spell checkers, `git diff` and DNA alignment all compare two sequences. The trick is to compare **prefixes**: `dp[i][j]` answers the question for the first `i` letters of `a` and the first `j` letters of `b`. Each cell looks at the last letters, `a[i − 1]` and `b[j − 1]`, and reads three smaller cells.

```viz

title: Turning "sunday" into "saturday"
goal: Run **letter by letter** to the end, then run **edit distance table** and compare.
height: 480
Inserts, deletes and replacements each cost 1.
```

**Edit distance** (LeetCode 72):

- `a[i − 1] == b[j − 1]`: `dp[i][j] = dp[i − 1][j − 1]` (keep the letter, free)
- otherwise, 1 + the cheapest of: `dp[i − 1][j − 1]` (replace), `dp[i − 1][j]` (delete from `a`), `dp[i][j − 1]` (insert into `a`)
- base cases: `dp[i][0] = i`, `dp[0][j] = j`

**Longest common subsequence** (LeetCode 1143) is the same shape: if the last letters match, `dp[i − 1][j − 1] + 1`; otherwise `max(dp[i − 1][j], dp[i][j − 1])`.

```run
title: Both tables side by side
def tables(a, b):
    n, m = len(a), len(b)
    E = [[0] * (m + 1) for _ in range(n + 1)]
    L = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        for j in range(m + 1):
            if i == 0 or j == 0:
                E[i][j] = i + j
            elif a[i - 1] == b[j - 1]:
                E[i][j] = E[i - 1][j - 1]
                L[i][j] = L[i - 1][j - 1] + 1
            else:
                E[i][j] = 1 + min(E[i - 1][j - 1], E[i - 1][j], E[i][j - 1])
                L[i][j] = max(L[i - 1][j], L[i][j - 1])
    return E[n][m], L[n][m]

print(tables("sunday", "saturday"))
print(tables("horse", "ros"))
```

## One sequence: increasing subsequences

The **longest increasing subsequence** (LIS) has an O(n²) DP: `dp[i]` = longest increasing subsequence ending at `i` = 1 + the best `dp[j]` with `j < i` and `nums[j] < nums[i]`. There's a faster way. Keep `tails[k]` = the **smallest possible last number** of an increasing subsequence of length `k + 1`. `tails` is always sorted, so each new number finds its place by binary search:

- bigger than every tail: it extends the longest subsequence (append)
- otherwise: it replaces the first tail ≥ it (a smaller ending is easier to extend later)

The length of `tails` is the answer: O(n log n).

```exercise
title: lis_fast
kind: write
---prompt
*LeetCode 300, asked at Google, Microsoft and Amazon.* Return the length of the longest strictly increasing subsequence in O(n log n) with `tails` and `bisect_left`.
---starter
def lis(nums):
    return 1 + sum(1 for i in range(1, len(nums)) if nums[i] > nums[i - 1]) if nums else 0
---solution
def lis(nums):
    tails = []
    for x in nums:
        k = bisect.bisect_left(tails, x)
        if k == len(tails):
            tails.append(x)
        else:
            tails[k] = x
    return len(tails)
---tests
assert lis([10, 9, 2, 5, 3, 7, 101, 18]) == 4
assert lis([0, 1, 0, 3, 2, 3]) == 4
assert lis([7, 7, 7, 7]) == 1
assert lis([]) == 0
big = [(i * 7919) % 100003 for i in range(100000)]
out, t = timed(lis, big)
assert out == 306
assert t < 1.0, f"too slow: {t:.2f}s"
---hint
`bisect_left` (not right) keeps it strictly increasing: an equal number replaces, it doesn't extend.
```

```exercise
title: longest_palindromic_subsequence
kind: write
---prompt
*LeetCode 516, asked at Amazon and Uber.* Return the length of the longest subsequence of `s` that reads the same backwards. A palindrome in `s` is a common subsequence of `s` and `s` reversed.

def lps(s):
    best = 1
    for i in range(len(s)):

---solution

    t = s[::-1]
    n = len(s)
    dp = [[0] * (n + 1) for _ in range(n + 1)]

        for j in range(1, n + 1):

                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[n][n]
```

```exercise
title: interleaving_string
kind: write
---prompt
*LeetCode 97, asked at Google and Microsoft.* Is `c` made by interleaving `a` and `b` (keeping each one's letter order)? `dp[i][j]` = "the first `i` of `a` and the first `j` of `b` make the first `i + j` of `c`".

    return sorted(a + b) == sorted(c)
---solution
def is_interleave(a, b, c):
    if len(a) + len(b) != len(c):
        return False
    dp = [[False] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(len(a) + 1):
        for j in range(len(b) + 1):
            if i == j == 0:
                dp[i][j] = True
            else:
                from_a = i > 0 and dp[i - 1][j] and a[i - 1] == c[i + j - 1]
                from_b = j > 0 and dp[i][j - 1] and b[j - 1] == c[i + j - 1]
                dp[i][j] = from_a or from_b
    return dp[-1][-1]

assert is_interleave("ab", "cd", "acbd")
assert not is_interleave("ab", "cd", "abdc")
```

```exercise
title: wildcard_matching
kind: write
---prompt
*LeetCode 44, a hard one asked at Google, Meta and Microsoft.* `?` matches any one character and `*` matches any sequence (even empty). Does pattern `p` match all of `s`? For `*`: either it matches nothing (`dp[i][j − 1]`) or it eats one more character (`dp[i − 1][j]`).
---starter

    return len(s) == len(p) and all(x == y or y == "?" for x, y in zip(s, p))
---solution
def is_match(s, p):
    dp = [[False] * (len(p) + 1) for _ in range(len(s) + 1)]
    dp[0][0] = True
    for j in range(1, len(p) + 1):
        dp[0][j] = dp[0][j - 1] and p[j - 1] == "*"
    for i in range(1, len(s) + 1):
        for j in range(1, len(p) + 1):
            if p[j - 1] == "*":
                dp[i][j] = dp[i][j - 1] or dp[i - 1][j]

                dp[i][j] = dp[i - 1][j - 1] and p[j - 1] in ("?", s[i - 1])
```

```exercise
title: diff_lines
kind: write
---prompt
Return the diff as a list of strings. Fill the LCS table on **suffixes** (`dp[i][j]` = LCS of `a[i:]` and `b[j:]`, filled from the end) so you can walk **forwards**: if the lines match, keep (`"  "`); else if `dp[i + 1][j] >= dp[i][j + 1]`, remove `a[i]` (`"- "`); else add `b[j]` (`"+ "`). Leftovers are removals then additions.
---starter
def diff(a, b):
    return ["- " + x for x in a if x not in b] + ["+ " + x for x in b if x not in a]
---solution
def diff(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            dp[i][j] = dp[i + 1][j + 1] + 1 if a[i] == b[j] else max(dp[i + 1][j], dp[i][j + 1])
    out, i, j = [], 0, 0
    while i < n and j < m:
        if a[i] == b[j]:
            out.append("  " + a[i])
            i += 1
            j += 1
        elif dp[i + 1][j] >= dp[i][j + 1]:
            out.append("- " + a[i])
            i += 1
        else:
            out.append("+ " + b[j])
            j += 1
    return out + ["- " + x for x in a[i:]] + ["+ " + x for x in b[j:]]
---tests
assert diff(["a", "b", "c", "d"], ["a", "c", "d", "e"]) == ["  a", "- b", "  c", "  d", "+ e"]
assert diff(["x", "y"], ["y", "x"]) == ["- x", "  y", "+ x"]
assert diff([], ["new"]) == ["+ new"]
old = ["import os", "def f():", "    return 1", "print(f())"]
new = ["import os", "import sys", "def f():", "    return 2", "print(f())"]
assert diff(old, new) == ["  import os", "+ import sys", "  def f():", "-     return 1", "+     return 2", "  print(f())"]
---hint
The starter loses the order, and it can't show a line that moved. The LCS is the set of lines that stay put.
```

```exercise
title: suggest_words
kind: write
---prompt
Return the `k` words from `words` closest to `word` by edit distance, ties broken alphabetically. Write a two-row edit distance and sort by `(distance, word)`.
---starter
def suggest(word, words, k=3):
    return sorted(words, key=lambda w: abs(len(w) - len(word)))[:k]
---solution
def suggest(word, words, k=3):
    def dist(a, b):
        prev = list(range(len(b) + 1))
        for i in range(1, len(a) + 1):
            cur = [i] + [0] * len(b)
            for j in range(1, len(b) + 1):
                cur[j] = min(prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (a[i - 1] != b[j - 1]))
            prev = cur
        return prev[-1]
    return [w for _, w in sorted((dist(word, w), w) for w in words)[:k]]
---tests
```

```exercise

def min_delete_sum(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]

        for j in range(len(b) + 1):
```

```recall
Q: Explain DP on strings: the prefix-against-prefix state, the edit distance and LCS transitions, how to rebuild the alignment, and the fast longest increasing subsequence.
A: Comparing two sequences uses dp[i][j] for the first i items of one and the first j of the other, deciding by the last items and reading three smaller cells, so it costs O(n·m). Edit distance keeps a matching letter for free from the diagonal; otherwise it is one plus the cheapest of replace (diagonal), delete (above) and insert (left), with base cases i and j against the empty string. Longest common subsequence adds one on the diagonal for a match and otherwise takes the better of dropping either last letter; dropping both is a bug. Only two rows are needed for the number, but the full table lets you walk back from the corner (or forward on a suffix table) to rebuild the alignment, which is how a line diff prints kept, removed and added lines. The same state solves palindromic subsequences (LCS with the reverse), counting subsequences, interleaving and wildcard matching, where a star either matches nothing or eats one more character. The longest increasing subsequence can be found in O(n log n) by keeping tails, the smallest ending value for each length, which stays sorted so each number is placed with bisect_left.
```
