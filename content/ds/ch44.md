## Updating a whole range

Chapter 43's tree updates **one** position in O(log n). "Add 3 to every position from 2 to 13" would be 12 separate updates: O(n log n) per job, worse than a plain loop.

The fix is to be lazy. When a block lies **wholly inside** the update range, fix its total at once (`sum += v × size`) and leave a **note** on it: "every cell below me owes +v". Don't touch the children. Later, when a job needs to look **inside** that block, **push** the note down one level first.

```viz
name: ds-lazy
title: Range additions and range sums on 16 numbers
goal: Run **touch every cell** to the end, then run **lazy segment tree** and compare the work.
height: 470
Red notes are debts owed to the cells below. They're only paid when someone looks inside.
```

The recursive version is the clearest. Node `x` covers `[lo, hi]`, and its children are `2x` (left half) and `2x + 1` (right half). Use arrays of size `4n`:

- `apply(x, v)`: `s[x] += v × (hi − lo + 1)`, `lz[x] += v`. The block is now right, and the note remembers the debt.
- `push(x)`: if `lz[x]` is non-zero, `apply` it to both children and clear it.
- **update / query**: if the node is outside the range, stop. If it's wholly inside, `apply` (or return `s[x]`). Otherwise `push(x)`, recurse into both children, and (for an update) recompute `s[x]`.

Both are O(log n), because only the two edges of the range are ever partial at each level.

The tag changes with the job: **assign** needs "set to v" (a newer assign replaces an older one), **flip** needs "invert" (two flips cancel), and **add with max** just adds `v` to the max. If all the updates come **before** all the queries, you don't need a tree at all: a **difference array** (chapter 4) does it in O(n + q).

```run
title: A lazy segment tree for range add and range sum
class LazySum:
    def __init__(self, a):
        self.n = len(a)
        self.s = [0] * (4 * self.n)
        self.lz = [0] * (4 * self.n)
        self._build(1, 0, self.n - 1, a)

    def _build(self, x, lo, hi, a):
        if lo == hi:
            self.s[x] = a[lo]
            return
        m = (lo + hi) // 2
        self._build(2 * x, lo, m, a)
        self._build(2 * x + 1, m + 1, hi, a)
        self.s[x] = self.s[2 * x] + self.s[2 * x + 1]

    def _apply(self, x, lo, hi, v):
        self.s[x] += v * (hi - lo + 1)
        self.lz[x] += v

    def _push(self, x, lo, hi):
        if self.lz[x]:
            m = (lo + hi) // 2
            self._apply(2 * x, lo, m, self.lz[x])
            self._apply(2 * x + 1, m + 1, hi, self.lz[x])
            self.lz[x] = 0

    def add(self, l, r, v, x=1, lo=0, hi=None):
        if hi is None:
            hi = self.n - 1
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            self._apply(x, lo, hi, v)
            return
        self._push(x, lo, hi)
        m = (lo + hi) // 2
        self.add(l, r, v, 2 * x, lo, m)
        self.add(l, r, v, 2 * x + 1, m + 1, hi)
        self.s[x] = self.s[2 * x] + self.s[2 * x + 1]

    def query(self, l, r, x=1, lo=0, hi=None):
        if hi is None:
            hi = self.n - 1
        if r < lo or hi < l:
            return 0
        if l <= lo and hi <= r:
            return self.s[x]
        self._push(x, lo, hi)
        m = (lo + hi) // 2
        return self.query(l, r, 2 * x, lo, m) + self.query(l, r, 2 * x + 1, m + 1, hi)

t = LazySum([5, 3, 8, 6, 1, 4, 7, 2])
t.add(1, 5, 10)
print(t.query(0, 7), t.query(2, 3), t.query(5, 7))
t.add(0, 7, -1)
print(t.query(0, 0), t.query(0, 7))
```

```exercise
title: flight_bookings
kind: write
---prompt
*LeetCode 1109, asked at Amazon.* Flights are numbered `1..n`. Each booking `[first, last, seats]` reserves `seats` on every flight from `first` to `last`. Return the seat count for each flight. All the updates come before the answers, so you don't need a tree: use a **difference array**.

def flight_bookings(bookings, n):
    d = [0] * (n + 1)
    for first, last, seats in bookings:
        d[first - 1] += seats
        d[last] -= seats
    out, run = [], 0
    for i in range(n):
        run += d[i]
        out.append(run)
    return out
```

```exercise
title: my_calendar_iii
kind: write
---prompt
*LeetCode 732, a hard one asked at Google.* Events `[start, end)` arrive one by one (times up to `10⁹`). After each, return the largest number of events overlapping at any moment so far. Compress all the times to indices, then each event is "add 1 on `[idx(start), idx(end) − 1]`" and the answer is the tree's overall maximum. A neat trick for add + max: keep `mx[x] = max(children) + lz[x]` and never push at all.
---starter
def calendar(events):
    out, best = [], 0
    for i, (s, e) in enumerate(events):
        c = sum(1 for s2, e2 in events[:i + 1] if s2 <= s < e2)
        best = max(best, c)
        out.append(best)
    return out
---solution
def calendar(events):
    xs = sorted({t for ev in events for t in ev})
    idx = {t: i for i, t in enumerate(xs)}
    n = len(xs)
    mx, lz = [0] * (4 * n), [0] * (4 * n)
    def add(x, lo, hi, l, r):
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            mx[x] += 1
            lz[x] += 1
            return
        m = (lo + hi) // 2
        add(2 * x, lo, m, l, r)
        add(2 * x + 1, m + 1, hi, l, r)
        mx[x] = max(mx[2 * x], mx[2 * x + 1]) + lz[x]
    out = []
    for s, e in events:
        add(1, 0, n - 1, idx[s], idx[e] - 1)
        out.append(mx[1])
    return out
```

```exercise
---solution
def flip_and_count(bits, ops):
    n = len(bits)
    cnt, fl = [0] * (4 * n), [False] * (4 * n)
    def build(x, lo, hi):
        if lo == hi:
            cnt[x] = bits[lo]
            return
        m = (lo + hi) // 2
        build(2 * x, lo, m)
        build(2 * x + 1, m + 1, hi)
        cnt[x] = cnt[2 * x] + cnt[2 * x + 1]
    def apply(x, lo, hi):
        cnt[x] = (hi - lo + 1) - cnt[x]
        fl[x] = not fl[x]
    def push(x, lo, hi):
        if fl[x]:
            m = (lo + hi) // 2
            apply(2 * x, lo, m)
            apply(2 * x + 1, m + 1, hi)
            fl[x] = False
    def flip(x, lo, hi, l, r):
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            apply(x, lo, hi)
            return
        push(x, lo, hi)
        m = (lo + hi) // 2
        flip(2 * x, lo, m, l, r)
        flip(2 * x + 1, m + 1, hi, l, r)
        cnt[x] = cnt[2 * x] + cnt[2 * x + 1]
    def count(x, lo, hi, l, r):
        if r < lo or hi < l:
            return 0
        if l <= lo and hi <= r:
            return cnt[x]
        push(x, lo, hi)
        m = (lo + hi) // 2
        return count(2 * x, lo, m, l, r) + count(2 * x + 1, m + 1, hi, l, r)
    build(1, 0, n - 1)
    out = []
    for op, l, r in ops:
        if op == "flip":
            flip(1, 0, n - 1, l, r)
        else:
            out.append(count(1, 0, n - 1, l, r))
    return out
```

```exercise

kind: write
---prompt
Process `("set", l, r, v)` (every salary in `l..r` becomes `v`) and `("total", l, r)`. Return the totals. Use a lazy tag that is `None` when there's nothing to pass down.

def payroll(salaries, ops):
    sal, out = list(salaries), []
    for op in ops:
        if op[0] == "set":
            sal[op[1]] = op[3]
        else:
            out.append(sum(sal[op[1]:op[2] + 1]))

---solution
def payroll(salaries, ops):
    n = len(salaries)
    s, st = [0] * (4 * n), [None] * (4 * n)
    def build(x, lo, hi):
        if lo == hi:
            s[x] = salaries[lo]
            return
        m = (lo + hi) // 2
        build(2 * x, lo, m)
        build(2 * x + 1, m + 1, hi)
        s[x] = s[2 * x] + s[2 * x + 1]
    def apply(x, lo, hi, v):
        s[x] = v * (hi - lo + 1)
        st[x] = v
    def push(x, lo, hi):
        if st[x] is not None:
            m = (lo + hi) // 2
            apply(2 * x, lo, m, st[x])
            apply(2 * x + 1, m + 1, hi, st[x])
            st[x] = None
    def assign(x, lo, hi, l, r, v):
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            apply(x, lo, hi, v)
            return
        push(x, lo, hi)
        m = (lo + hi) // 2
        assign(2 * x, lo, m, l, r, v)
        assign(2 * x + 1, m + 1, hi, l, r, v)
        s[x] = s[2 * x] + s[2 * x + 1]
    def total(x, lo, hi, l, r):
        if r < lo or hi < l:
            return 0
        if l <= lo and hi <= r:
            return s[x]
        push(x, lo, hi)
        m = (lo + hi) // 2
        return total(2 * x, lo, m, l, r) + total(2 * x + 1, m + 1, hi, l, r)
    build(1, 0, n - 1)
    out = []
    for op in ops:
        if op[0] == "set":
            assign(1, 0, n - 1, op[1], op[2], op[3])
        else:
            out.append(total(1, 0, n - 1, op[1], op[2]))
    return out
```

```exercise
def final_salaries(salaries, raises):
    n = len(salaries)
    d = [0] * (n + 1)
    for l, r, v in raises:
        d[l] += v
        d[r + 1] -= v
    out, run = [], 0
    for i in range(n):
        run += d[i]
        out.append(salaries[i] + run)
    return out
```

```exercise
title: lazy_rebuild
kind: rebuild
---prompt
From memory: `LazyMax(n)` starting all zeros, with `add(l, r, v)` and `best(l, r)` returning the maximum in `l..r`. Use apply and push.
---starter
class LazyMax:
    pass
---solution
class LazyMax:
    def __init__(self, n):
        self.n = n
        self.mx = [0] * (4 * n)
        self.lz = [0] * (4 * n)

    def _apply(self, x, v):
        self.mx[x] += v
        self.lz[x] += v

    def _push(self, x):
        if self.lz[x]:
            self._apply(2 * x, self.lz[x])
            self._apply(2 * x + 1, self.lz[x])
            self.lz[x] = 0

    def add(self, l, r, v, x=1, lo=0, hi=None):
        if hi is None:
            hi = self.n - 1
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            self._apply(x, v)
            return
        self._push(x)
        m = (lo + hi) // 2
        self.add(l, r, v, 2 * x, lo, m)
        self.add(l, r, v, 2 * x + 1, m + 1, hi)
        self.mx[x] = max(self.mx[2 * x], self.mx[2 * x + 1])

    def best(self, l, r, x=1, lo=0, hi=None):
        if hi is None:
            hi = self.n - 1
        if r < lo or hi < l:
            return float("-inf")
        if l <= lo and hi <= r:
            return self.mx[x]
        self._push(x)
        m = (lo + hi) // 2
        return max(self.best(l, r, 2 * x, lo, m), self.best(l, r, 2 * x + 1, m + 1, hi))
---tests

t.add(0, 3, 5)
t.add(2, 6, 2)
assert t.best(0, 7) == 7 and t.best(4, 7) == 2 and t.best(0, 1) == 5

assert t.best(5, 7) == 10 and t.best(0, 6) == 7
---hint
For max, adding `v` to every cell adds `v` to the maximum: `mx[x] += v`, no size factor.
```

```recall
Q: Explain lazy propagation: why range updates need it, what apply and push do, why it stays O(log n), and how the tag changes for add, assign and flip, plus when a difference array is enough.
A: A plain segment tree updates one position at a time, so adding to a range costs O(n log n). With lazy propagation each node keeps its value and a tag. When an update fully covers a node's block, apply fixes the node at once (sum += v × size, or max += v) and records the tag, without visiting the children. Push hands a node's tag to both children and clears it, and it runs only when a later update or query needs to go inside that block. Only the blocks at the two edges of a range are partly covered at each level, so updates and queries both touch O(log n) nodes; recursive trees use arrays of size 4n. Range add accumulates tags, range assign replaces them (with None meaning empty, since 0 is a valid value), and range flip toggles a flag and turns a count of ones into size minus that count. If all updates come before all queries, a difference array with a running sum does the job in O(n + q).
```
