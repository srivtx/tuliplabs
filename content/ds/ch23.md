## When roads aren't equal

BFS (chapter 19) finds the path with the fewest **edges**. Once each edge has a **weight** (minutes, kilometres, money), the fewest edges can be far from the cheapest route.

```viz

```

**Dijkstra's algorithm** (for weights that are never negative):

1. `dist[start] = 0`, everything else infinity. Push `(0, start)` on a min-heap.
2. Pop the smallest `(d, v)`. If `d > dist[v]`, it's a stale entry: skip it (**lazy deletion**).
3. Otherwise `v` is **settled**: `d` is final. For each edge `v → w` with weight `t`, if `d + t < dist[w]`, improve `dist[w]` and push `(d + t, w)`.

Why is a popped distance final? Any other route to `v` must leave the settled region through some place whose distance is already at least `d`, and weights can't go negative, so it can't arrive with less than `d`. That argument is exactly why Dijkstra **breaks** with negative weights (chapter 24).

```run
title: Dijkstra with a heap, plus the route
import heapq
roads = {"A": [("B", 2), ("E", 9)], "B": [("A", 2), ("C", 1), ("G", 5)], "C": [("B", 1), ("D", 2)],
         "D": [("C", 2), ("F", 1), ("G", 2)], "E": [("A", 9), ("G", 3), ("H", 8)], "F": [("D", 1), ("H", 2)],
         "G": [("B", 5), ("E", 3), ("D", 2), ("H", 6)], "H": [("E", 8), ("F", 2), ("G", 6)]}
dist, parent = {"A": 0}, {}
heap = [(0, "A")]
while heap:
    d, v = heapq.heappop(heap)
    if d > dist[v]:
        continue
    for w, t in roads[v]:
        if d + t < dist.get(w, float("inf")):
            dist[w] = d + t
            parent[w] = v
            heapq.heappush(heap, (d + t, w))
route, v = [], "H"
while v != "A":
    route.append(v)
    v = parent[v]
print(dist)
print(" → ".join(["A"] + route[::-1]), dist["H"], "minutes")
```

## Changing what "cost" means

Dijkstra works for any path cost that never **decreases** as the path gets longer. Swap `+` for `max`, multiply probabilities (and pop the **largest**), or add extra state to each node.

```exercise
title: minimum_effort
kind: write
---prompt
*LeetCode 1631, asked at Google.* A grid of heights. A route's **effort** is the largest height difference between consecutive cells on it. Return the minimum effort from the top-left to the bottom-right (4-directional). Dijkstra where a route's cost is `max(effort so far, |step|)`.
---starter
def min_effort(h):
    r, c = len(h), len(h[0])
    path = [h[0][j] for j in range(c)] + [h[i][c - 1] for i in range(1, r)]
    return max([abs(a - b) for a, b in zip(path, path[1:])] or [0])
---solution
def min_effort(h):
    r, c = len(h), len(h[0])
    best = {(0, 0): 0}
    heap = [(0, 0, 0)]
    while heap:
        e, i, j = heapq.heappop(heap)
        if (i, j) == (r - 1, c - 1):
            return e
        if e > best[(i, j)]:
            continue
        for a, b in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
            if 0 <= a < r and 0 <= b < c:
                ne = max(e, abs(h[a][b] - h[i][j]))
                if ne < best.get((a, b), float("inf")):
                    best[(a, b)] = ne
                    heapq.heappush(heap, (ne, a, b))
---tests
assert min_effort([[1, 2, 2], [3, 8, 2], [5, 3, 5]]) == 2
assert min_effort([[1, 2, 3], [3, 8, 4], [5, 3, 5]]) == 1
assert min_effort([[1, 2, 1, 1, 1], [1, 2, 1, 2, 1], [1, 2, 1, 2, 1], [1, 2, 1, 2, 1], [1, 1, 1, 2, 1]]) == 0
assert min_effort([[7]]) == 0
---hint
Same loop, same heap. Only the "new cost" line changes: `max` instead of `+`.
```

```exercise
title: safest_path
kind: write
---prompt
*LeetCode 1514.* An undirected graph `0..n-1`; edge `i` joins `edges[i]` and succeeds with probability `p[i]`. Return the highest probability of getting from `start` to `end` (0 if impossible), rounded to 5 decimals. Probabilities only shrink as you multiply, so Dijkstra works: pop the **largest** (push negatives into the heap).
---starter
def safest(n, edges, p, start, end):
    best = 0
    for (a, b), q in zip(edges, p):
        if {a, b} == {start, end}:
            best = max(best, q)
    return round(best, 5)
---solution
def safest(n, edges, p, start, end):
    g = defaultdict(list)
    for (a, b), q in zip(edges, p):
        g[a].append((b, q))
        g[b].append((a, q))
    best = {start: 1.0}
    heap = [(-1.0, start)]
    while heap:
        negp, v = heapq.heappop(heap)
        if v == end:
            return round(-negp, 5)
        if -negp < best[v]:
            continue
        for w, q in g[v]:
            if -negp * q > best.get(w, 0):
                best[w] = -negp * q
                heapq.heappush(heap, (-best[w], w))
    return 0
---tests

assert safest(3, [(0, 1), (1, 2), (0, 2)], [0.5, 0.5, 0.3], 0, 2) == 0.3
assert safest(3, [(0, 1)], [0.5], 0, 2) == 0
---hint
Store the best probability per node; "better" now means bigger.
```

```exercise
title: zero_one_bfs
kind: write
---prompt
*LeetCode 1368, a hard one.* Each grid cell has an arrow: 1 right, 2 left, 3 down, 4 up. Following a cell's arrow is free; moving any other way costs 1 (you change the sign). Return the minimum cost from top-left to bottom-right. When every weight is 0 or 1, use **0-1 BFS**: a deque where free moves go on the **front** and cost-1 moves on the **back**. O(cells), no heap.
---starter
def min_cost(grid):
    r, c = len(grid), len(grid[0])
    return r + c - 2
---solution
def min_cost(grid):
    r, c = len(grid), len(grid[0])
    D = {1: (0, 1), 2: (0, -1), 3: (1, 0), 4: (-1, 0)}
    dist = {(0, 0): 0}
    dq = deque([(0, 0, 0)])
    while dq:
        d, i, j = dq.popleft()
        if d > dist[(i, j)]:
            continue
        for k, (di, dj) in D.items():
            a, b = i + di, j + dj
            if 0 <= a < r and 0 <= b < c:
                nd = d + (k != grid[i][j])
                if nd < dist.get((a, b), float("inf")):
                    dist[(a, b)] = nd
                    if nd == d:
                        dq.appendleft((nd, a, b))
                    else:
                        dq.append((nd, a, b))
    return dist[(r - 1, c - 1)]
---tests
assert min_cost([[1, 1, 1, 1], [2, 2, 2, 2], [1, 1, 1, 1], [2, 2, 2, 2]]) == 3
assert min_cost([[1, 1, 3], [3, 2, 2], [1, 1, 4]]) == 0
assert min_cost([[1, 2], [4, 3]]) == 1
assert min_cost([[4]]) == 0
---hint
The deque stays sorted by distance: everything at the front is `d`, everything at the back `d + 1`.
```

```exercise
def cheapest(n, flights):
    g = defaultdict(list)
    for u, v, p in flights:
        g[u].append((v, p))
    dist = {(0, 0): 0}
    heap = [(0, 0, 0)]
    while heap:
        d, v, used = heapq.heappop(heap)
        if d > dist[(v, used)]:
            continue
        if v == n - 1:
            return d
        for w, p in g[v]:
            moves = [(d + p, used)] + ([(d + p // 2, 1)] if not used else [])

                    heapq.heappush(heap, (nd, w, nu))
    return -1
```

```exercise
title: nearest_depot
kind: write
---prompt
Undirected `streets` `(a, b, minutes)`. Return a dict mapping every reachable intersection to `(minutes, depot)`: the fastest time from **any** depot and which depot gives it (ties: the smaller depot name). Multi-source Dijkstra: push `(0, depot, depot)` for each depot to begin with.
---starter
def nearest(streets, depots):
    out = {}
    for d in depots:
        out[d] = (0, d)
    return out
---solution
def nearest(streets, depots):
    g = defaultdict(list)
    for a, b, m in streets:
        g[a].append((b, m))
        g[b].append((a, m))
    best = {}
    heap = [(0, d, d) for d in depots]
    heapq.heapify(heap)
    while heap:
        t, src, v = heapq.heappop(heap)
        if v in best:
            continue
        best[v] = (t, src)
        for w, m in g[v]:
            if w not in best:
                heapq.heappush(heap, (t + m, src, w))
    return best
```

```exercise
def route(streets, src, dst, closed):
    g = defaultdict(list)
    for a, b, m in streets:
        if frozenset((a, b)) not in closed:
```

```recall
Q: Explain Dijkstra's algorithm: what it solves, how it works with a heap, why it is correct, its cost, its limits and its common variations.
A: Dijkstra finds shortest paths from a source in a graph whose edge weights are never negative, where BFS's fewest-edges answer is no longer the cheapest. It keeps a tentative distance for each node and a min-heap of (distance, node); it repeatedly pops the smallest, skips it if stale (larger than the recorded distance), otherwise treats it as settled and relaxes each outgoing edge, pushing any neighbour whose distance improves. A popped distance is final because any other route must leave the settled set through a node at least as far away and weights cannot be negative, which is also why negative edges break it. With a binary heap it costs O((V + E) log V). A parent map recovers the path. Variations keep the same loop: different path costs such as maximum step or multiplied probabilities, extra state such as (node, coupon used), many sources started at distance zero together, and 0-1 BFS with a deque when weights are only 0 or 1. It powers maps, delivery quotes and network routing.
```
