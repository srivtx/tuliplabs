## Arrays: the bricks of every model

Almost every model in *Think Complexity* is a numpy array that changes over time: a row of cells, a grid of sand, a city of households. Three moves cover most of what you need: make an array, look at part of it, and ask a yes/no question of every element at once.

```run
title: Make, slice, ask
city = np.array([1, 2, 0, 1, 1, 2, 0, 2])   # 0 empty, 1 red, 2 blue
print(city[2:5])          # a slice: elements 2, 3, 4
print(city == 1)          # a boolean mask: one True/False per house
print(np.sum(city == 1))  # True counts as 1, so this counts red houses
print(city[city != 0])    # use a mask to keep only occupied houses
```

```predict
a = np.array([3, 0, 2, 0, 5])
print(a > 1)
print(np.sum(a > 1), a[a > 1].sum())
```

```quiz
`city = np.array([1, 2, 0, 1])`. What does `np.mean(city == 1)` give?
- 1, because the first house is red
* 0.5, the fraction of houses that are red
- 2, the number of red houses
- An error: you can't average booleans
> `city == 1` is `[True, False, False, True]`. numpy treats True as 1 and False as 0, so the mean is 2/4 = 0.5. "Mean of a mask" = "fraction that satisfy the condition", a pattern you'll use in every chapter.
```

## Neighbours without index headaches

A Schelling household looks at the houses around it. With a loop you'd write `city[i-1]`, `city[i+1]` and then worry about the ends of the street. `np.roll` shifts the whole array at once and wraps around, so the street becomes a ring with no ends to special-case.

```run
title: Rolling the street
city = np.array([1, 2, 0, 1, 1])
print("city      ", city)
print("roll(+1)  ", np.roll(city, 1))    # each position now holds its LEFT neighbour
print("roll(-1)  ", np.roll(city, -1))   # ... its RIGHT neighbour
same_left = (np.roll(city, 1) == city) & (city != 0)
print("same as left?", same_left)
```

```predict
a = np.array([10, 20, 30, 40])
print(np.roll(a, 1))
print(np.roll(a, -2))
```

```exercise
title: Count same-colour neighbours
kind: write
---prompt
Write `same_neighbors(city, r=1)`. For every house, count how many of the houses within distance `r` on each side (so `2*r` houses) have the **same colour**. The street is a ring. Empty houses should get 0, and empty neighbours never count.

Use `np.roll` inside a loop over the offsets `-r … r` (skip 0).
---starter
def same_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    # your code here
    return count
---solution
def same_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d == 0:
            continue
        neighbor = np.roll(city, d)
        count += (neighbor == city) & (city != 0)
    return count
---tests
c = np.array([1, 1, 2, 0, 2, 2])
got = same_neighbors(c, 1)
assert got.tolist() == [1, 1, 0, 0, 1, 1], f"r=1: expected [1, 1, 0, 0, 1, 1], got {got.tolist()}"
got2 = same_neighbors(c, 2)
assert got2.tolist() == [1, 1, 1, 0, 2, 1], f"r=2: expected [1, 1, 1, 0, 2, 1], got {got2.tolist()}"
assert same_neighbors(np.array([0, 0, 0]), 1).tolist() == [0, 0, 0], "Empty houses have no neighbours of their own colour"
---hint
For each offset `d`, `np.roll(city, d)` lines every house up with one neighbour. Compare it with `city`.
---hint
Mask out empty houses with `& (city != 0)`: otherwise two empty houses next to each other would count as "same".
```

## Schelling's street

Here are the rules, exactly as in the 3D city but on one street:

1. Each house is empty (0), red (1) or blue (2). The street wraps around.
2. A household looks at the `2r` houses around it. It is **happy** if at least a fraction `p` of its *occupied* neighbours share its colour (or if it has no neighbours at all).
3. Each step, every unhappy household moves to a random empty house.

The full model, with a plot. Run it, then change `p` to 0.3 and to 0.7.

```run
title: Watch the street sort itself
import matplotlib.pyplot as plt

def same_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            count += (np.roll(city, d) == city) & (city != 0)
    return count

def occupied_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            count += np.roll(city, d) != 0
    return count

def unhappy(city, p=0.5, r=1):
    same, occ = same_neighbors(city, r), occupied_neighbors(city, r)
    with np.errstate(invalid="ignore", divide="ignore"):
        frac = np.where(occ > 0, same / occ, 1.0)
    return (city != 0) & (frac < p)

def step(city, rng, p=0.5, r=1):
    movers = np.flatnonzero(unhappy(city, p, r))
    rng.shuffle(movers)
    for i in movers:
        j = rng.choice(np.flatnonzero(city == 0))
        city[j], city[i] = city[i], 0

def segregation(city, r=2):
    occ = occupied_neighbors(city, r)
    mask = (city != 0) & (occ > 0)
    return np.mean(same_neighbors(city, r)[mask] / occ[mask])

rng = np.random.default_rng(1)
city = rng.choice([0, 1, 2], size=200, p=[0.1, 0.45, 0.45])
p = 0.5
history = [city.copy()]
for t in range(30):
    step(city, rng, p=p, r=2)
    history.append(city.copy())

print("segregation before:", round(segregation(history[0]), 2))
print("segregation after: ", round(segregation(city), 2))
plt.figure(figsize=(8, 3))
from matplotlib.colors import ListedColormap
street = ListedColormap(["#e8e8e8", "#e2532c", "#3a4fa3"])   # empty, red, blue
plt.imshow(history, aspect="auto", cmap=street, vmin=0, vmax=2, interpolation="none")
plt.xlabel("house"); plt.ylabel("step (time runs down)")
plt.title(f"A street where everyone wants at least {p:.0%} of neighbours alike")
```

## The bug hunt

```exercise
title: The happy-everyone bug
kind: bug
---prompt
This version of `unhappy` returns a mask, runs without errors, and is wrong: in a mixed street almost nobody is ever unhappy. Find the bug and fix it.
---setup
def same_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            count += (np.roll(city, d) == city) & (city != 0)
    return count
---starter
def unhappy(city, p=0.5, r=1):
    same = same_neighbors(city, r)
    frac = same / (2 * r)
    return (city != 0) & (frac > p)
---solution
def unhappy(city, p=0.5, r=1):
    same = same_neighbors(city, r)
    occ = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            occ += np.roll(city, d) != 0
    with np.errstate(invalid="ignore", divide="ignore"):
        frac = np.where(occ > 0, same / occ, 1.0)
    return (city != 0) & (frac < p)
---tests
c = np.array([1, 2, 1, 2, 1, 2])
assert unhappy(c, 0.5, 1).all(), "In a perfectly alternating street every household has 0 alike neighbours, so all are unhappy"
assert not unhappy(np.array([1, 1, 1, 1]), 0.5, 1).any(), "All-red street: nobody is unhappy"
assert unhappy(np.array([1, 0, 2, 2]), 0.5, 1).tolist() == [True, False, False, False], "Divide by occupied neighbours, not by 2r: house 2 has one occupied neighbour and it matches"
---hint
There are two bugs hiding in two lines. Look at the comparison operator first: unhappy means *below* the threshold.
---hint
The second bug: dividing by `2 * r` counts empty houses as "not alike". Schelling's rule uses the fraction of **occupied** neighbours.
```

## What makes this "complexity science"?

The book's first chapter describes a set of shifts away from classical, equation-based science. Your street model shows several of them at once: it's **discrete** (houses, not a smooth density), **stochastic** (random moves), made of **many interacting agents**, and studied by **computation** (you ran it) rather than by **analysis** (solving for an answer on paper).

```quiz
Which pair best describes the move from classical models to the Schelling model?
- Continuous to discrete only
* From one or two bodies described by equations, to many simple agents studied by simulation
- From stochastic to deterministic
- From composite to homogeneous
> Classical physics models a few bodies with equations you can solve. Schelling's model has hundreds of agents with a simple rule, and the interesting result, strong clustering from mild preferences, appears only when you run it. That is the core shift the book describes.
```

```quiz
Nobody in the model wants a segregated street (at p = 0.5 everyone is fine with half their neighbours being different). Yet the street segregates. What is the name for a pattern at the level of the whole system that no individual rule mentions?
- A bug in the simulation
- Determinism
* Emergence
- Equilibrium
> Emergence: the system-level property (large single-colour blocks) is not written into any agent's rule. You saw it appear in the plot.
```

```recall
Q: In your own words: why does a city segregate strongly even when each household is happy with half its neighbours being different?
A: - A household that moves leaves a gap and lands somewhere new, which changes the neighbourhood of **several** other households.
- Moves are local and keep cascading: each move can make a neighbour unhappy, who then moves too.
- The system only stops when (almost) nobody is unhappy, and the configurations where nobody is unhappy are mostly clustered ones. Mild individual preferences + feedback = strong collective pattern.
```

```recall
Q: Why use `np.roll` instead of a loop with `city[i-1]` and `city[i+1]`?
A: - It handles the whole array at once (fast, short code).
- It wraps around, so the ends of the street need no special case: the street is a ring.
- `np.roll(city, d)` lines every house up with its neighbour at offset `d`, so one comparison checks every house.
```
