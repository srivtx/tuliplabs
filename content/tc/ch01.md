```quiz
`city = np.array([1, 2, 0, 1])`. What does `np.mean(city == 1)` give?
- 1, because the first house is red
* 0.5, the fraction of houses that are red
- 2, the number of red houses
- An error: you can't average booleans
> `city == 1` is `[True, False, False, True]`. numpy treats True as 1 and False as 0, so the mean is 2/4 = 0.5. "Mean of a mask" = "fraction that satisfy the condition", a pattern you'll use in every chapter.
```

## Neighbours without index headaches

A Schelling household looks at the houses around it. With a loop you'd write `city[i-1]`, `city[i+1]` and then worry about the ends of the street. `np.roll` shifts the whole array at once and wraps around, so the street becomes a ring with no ends to special-case.

```run
title: Rolling the street
city = np.array([1, 2, 0, 1, 1])
print("city      ", city)
print("roll(+1)  ", np.roll(city, 1))    # each position now holds its LEFT neighbour
print("roll(-1)  ", np.roll(city, -1))   # ... its RIGHT neighbour
same_left = (np.roll(city, 1) == city) & (city != 0)
print("same as left?", same_left)
```

```predict
a = np.array([10, 20, 30, 40])
print(np.roll(a, 1))
print(np.roll(a, -2))
```

```exercise
def same_neighbors(city, r=1):
```

## Schelling's street

Here are the rules, exactly as in the 3D city but on one street:

1. Each house is empty (0), red (1) or blue (2). The street wraps around.
2. A household looks at the `2r` houses around it. It is **happy** if at least a fraction `p` of its *occupied* neighbours share its colour (or if it has no neighbours at all).
3. Each step, every unhappy household moves to a random empty house.

```run
def same_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            count += (np.roll(city, d) == city) & (city != 0)
    return count

def occupied_neighbors(city, r=1):
    count = np.zeros(len(city), dtype=int)
    for d in range(-r, r + 1):
        if d != 0:
            count += np.roll(city, d) != 0
    return count

def unhappy(city, p=0.5, r=1):
    same, occ = same_neighbors(city, r), occupied_neighbors(city, r)
    with np.errstate(invalid="ignore", divide="ignore"):
        frac = np.where(occ > 0, same / occ, 1.0)
```

## Real-world project: a neighbourhood-mix simulator

City planners really do ask "if we build this street of new homes, will it stay mixed?" Nobody can run the experiment on real families, but you can run it on your model in a second, a hundred times, with different settings. That is what a **what-if tool** is: the same model you just wrote, wrapped in a function that answers a planner's question with a number.

```project
title: Neighbourhood-mix simulator for a city planner
client: A city housing office planning a new 200-home street
skills: numpy, simulation loops, stopping conditions, parameter sweeps
---brief
The planners want a table: for each **tolerance** level p (how many alike neighbours a household wants), how segregated does the street end up, on average? Your job is to turn the street model into two functions: one that runs a street until it settles, and one that sweeps p and reports the average segregation.
---why
Policy teams, urban-planning consultancies and game studios all build tools like this: a model plus a **sweep** over the knobs people care about. The same pattern (run until stable, repeat with many random seeds, average) is how A/B-test simulators, epidemic dashboards and load-testing tools work.
---milestones
- Write `settle`, which runs `step` until nobody is unhappy (or a step limit) and reports how many steps it took
- Make sure `settle` stops early: a street that is already happy should take 0 steps
- Write `mix_report`, which averages the final segregation over several random streets for each p
- Print the table for p = 0.2 … 0.7 and spot the tolerance where segregation jumps
- Explain to the planner, in one sentence, why mild preferences still give strong clustering
---stretch
- Add a third colour of household and see whether the jump moves
- Report the spread (min and max), not just the average: planners care about the worst case
- Let a fraction of houses be "protected" (they never move) and test whether a few anchors keep the street mixed
```

## What makes this "complexity science"?

Complexity science starts from a set of shifts away from classical, equation-based science. Your street model shows several of them at once: it's **discrete** (houses, not a smooth density), **stochastic** (random moves), made of **many interacting agents**, and studied by **computation** (you ran it) rather than by **analysis** (solving for an answer on paper).

```quiz
Which pair best describes the move from classical models to the Schelling model?
- Continuous to discrete only
* From one or two bodies described by equations, to many simple agents studied by simulation
- From stochastic to deterministic
- From composite to homogeneous
> Classical physics models a few bodies with equations you can solve. Schelling's model has hundreds of agents with a simple rule, and the interesting result, strong clustering from mild preferences, appears only when you run it. That is the core shift complexity science describes.
```

```recall
Q: In your own words: why does a city segregate strongly even when each household is happy with half its neighbours being different?
A: - A household that moves leaves a gap and lands somewhere new, which changes the neighbourhood of **several** other households.
- Moves are local and keep cascading: each move can make a neighbour unhappy, who then moves too.
- The system only stops when (almost) nobody is unhappy, and the configurations where nobody is unhappy are mostly clustered ones. Mild individual preferences + feedback = strong collective pattern.
```

```recall
Q: Why use `np.roll` instead of a loop with `city[i-1]` and `city[i+1]`?
A: - It handles the whole array at once (fast, short code).
- It wraps around, so the ends of the street need no special case: the street is a ring.
- `np.roll(city, d)` lines every house up with its neighbour at offset `d`, so one comparison checks every house.
```
