```prelude
def laplacian(a):
    """Sum of the 4 neighbours minus 4x the cell itself (wrapping)."""
    return (np.roll(a, 1, 0) + np.roll(a, -1, 0) + np.roll(a, 1, 1) + np.roll(a, -1, 1) - 4 * a)
```

## Diffusion: averaging with your neighbours

Ink in water spreads because molecules jiggle randomly. On a grid, that becomes a simple rule: each step, every cell moves a little toward the **average of its neighbours**. The amount a cell differs from its neighbours is the **Laplacian**:

Δa = (up + down + left + right) − 4·a

and the update is a ← a + r·Δa for a small rate r. High spots fall, low spots rise, and everything smooths out.

## Reaction–diffusion: spots from nothing

In 1952 Alan Turing proposed that two chemicals that **react** and **diffuse at different speeds** can form stable patterns: spots and stripes, like a leopard's coat. We use the Gray–Scott model with chemicals A and B:

- A is fed in at rate f; B is removed at rate k;
- the reaction A + 2B → 3B turns A into B where B already is;
- A diffuses faster than B.

```run
title: Gray–Scott: three settings, three patterns
def gray_scott(f, k, n=100, steps=5000):
    A = np.ones((n, n))
    B = np.zeros((n, n))
    A[40:60, 40:60] = 0.5           # a square seed in the middle
    B[40:60, 40:60] = 0.25
    B += 0.02 * np.random.default_rng(0).random((n, n))
    ra, rb = 0.16, 0.08             # A diffuses twice as fast as B
    for _ in range(steps):
        reaction = A * B * B
        A += ra * laplacian(A) - reaction + f * (1 - A)
        B += rb * laplacian(B) + reaction - (f + k) * B
    return B

# Watch the spots form: one frame every 100 steps
n = 100
A, B = np.ones((n, n)), np.zeros((n, n))
A[40:60, 40:60], B[40:60, 40:60] = 0.5, 0.25
B += 0.02 * np.random.default_rng(0).random((n, n))
frames = []
for step in range(5000):
    r = A * B * B
    A += 0.16 * laplacian(A) - r + 0.035 * (1 - A)
    B += 0.08 * laplacian(B) + r - (0.035 + 0.065) * B
    if step % 100 == 0:
        frames.append(B.copy())
flipbook(frames, cmap="magma", titles=[f"step {100 * i}" for i in range(len(frames))], fps=10)

fig, axes = plt.subplots(1, 3, figsize=(10, 3.4))
for ax, (f, k) in zip(axes, [(0.035, 0.065), (0.040, 0.060), (0.025, 0.055)]):
    ax.imshow(gray_scott(f, k), cmap="magma", interpolation="bicubic")
    ax.set_title(f"f={f}, k={k}"); ax.set_xticks([]); ax.set_yticks([])
```

## Percolation: can the water get through?

Make an n×n grid of rock. Each cell is **porous** with probability q, otherwise solid. Pour water on the top row. Water spreads from wet cells to porous neighbours (up, down, left, right; no wrapping this time: the top and bottom are real edges). If water ever reaches the bottom row, the rock **percolates**.

## The critical point

```run
title: Probability of percolating vs porosity
def spread(wet, porous):
    nb = np.zeros_like(wet)
    nb[1:, :] |= wet[:-1, :]; nb[:-1, :] |= wet[1:, :]
    nb[:, 1:] |= wet[:, :-1]; nb[:, :-1] |= wet[:, 1:]
    return porous & (wet | nb)

def percolates(porous):
    wet = np.zeros_like(porous); wet[0] = porous[0]
    while True:
        new = spread(wet, porous)
        if (new == wet).all():
            return bool(wet[-1].any())
        wet = new

rng = np.random.default_rng(1)
n = 40
qs = np.linspace(0.45, 0.75, 13)
probs = [np.mean([percolates(rng.random((n, n)) < q) for _ in range(30)]) for q in qs]
for q, p in zip(qs, probs):
    print(f"q = {q:.3f}   P(percolates) = {p:.2f}")
plt.axvline(0.593, color="gray", ls="--", label="q_c ≈ 0.593")
plt.plot(qs, probs, "o-", label=f"simulation, n={n}")
plt.xlabel("porosity q"); plt.ylabel("P(percolates)"); plt.legend()
```

## Fractals at the critical point

At q = q_c, the wet cluster is a **fractal**: full of holes at every scale. One way to see it: how does the number of wet cells grow with grid size n? A solid square grows like n²; a line like n¹. The percolating cluster grows like n^D with D ≈ 1.85, a dimension between a line and a plane.

To estimate D, plot log(cells) against log(n): the slope is D.

```predict
sizes = np.array([10, 20, 40, 80])
counts = 3 * sizes ** 2
slope, intercept = np.polyfit(np.log(sizes), np.log(counts), 1)
print(round(slope, 3))
```

## Real-world project: how dense can a plantation be before fire runs through it?

Swap "porous rock" for "tree" and "wet" for "burning", and your percolation code is a **forest-fire model**. A fire starts along one edge and jumps from a burning tree to any neighbouring tree. Below the critical density, fires stay small; above it, one spark can cross the whole forest. Foresters plan plantations and firebreaks around exactly this tipping point.

```recall
Q: What does a fractal dimension of about 1.85 mean for the wet cluster, and how do you measure it?
A: - The number of wet cells grows like n^1.85 as the grid grows: faster than a line (n¹), slower than a filled square (n²). The cluster has holes at every scale.
- Measure it by counting cells for several sizes and fitting a straight line to log(count) vs log(n); the slope is the dimension.
```
