## The puzzle: six degrees

In 1967 Stanley Milgram asked people in Nebraska to forward a letter to a stranger in Boston, only through people they knew by first name. The letters that arrived took about **six** hand-offs. That's strange: your friends mostly know each other (a **clustered** network), and clustered networks usually have **long** paths, because you keep circling inside your own group.

Watts and Strogatz (1998) explained it with a tiny model: start with a perfectly regular, clustered network, then rewire a few edges at random. This chapter builds that model and measures it.

## Ring lattices: perfectly local

A **ring lattice** puts `n` nodes in a circle and joins each one to its `k` nearest neighbours (`k/2` on each side). It's the most clustered, most "local" network you can draw.

```run
title: The book's adjacent_edges and make_ring_lattice
def adjacent_edges(nodes, halfk):
    n = len(nodes)
    for i, u in enumerate(nodes):
        for j in range(i + 1, i + halfk + 1):
            v = nodes[j % n]
            yield u, v

def make_ring_lattice(n, k):
    G = nx.Graph()
    nodes = range(n)
    G.add_nodes_from(nodes)
    G.add_edges_from(adjacent_edges(nodes, k // 2))
    return G

lattice = make_ring_lattice(10, 4)
print(lattice.number_of_edges(), "edges")
nx.draw_circular(lattice, with_labels=True, node_color="#c9e9df", node_size=500)
```

## Rewiring: a few shortcuts

The Watts–Strogatz (WS) graph: go through every edge `(u, v)`; with probability `p`, keep `u` but move the other end to a random node that isn't `u` and isn't already a neighbour of `u`. At `p = 0` you have the lattice; at `p = 1` the graph is close to random.

```exercise
---solution
def rewire(G, p):
    nodes = set(G)
    for u, v in list(G.edges()):
        if flip(p):
            choices = nodes - {u} - set(G[u])
            new_v = np.random.choice(list(choices))
            G.remove_edge(u, v)
            G.add_edge(u, new_v)
---tests
np.random.seed(3)
G = nx.circulant_graph(30, [1, 2])

assert G.number_of_edges() == 60, f"Rewiring moves edges; it shouldn't delete them. Started with 60, now {G.number_of_edges()}"
assert nx.number_of_selfloops(G) == 0, "No node should link to itself"

---hint
What happens if `new_v` is already a neighbour of `u`? `add_edge` on an existing edge does nothing, but you already removed `(u, v)`.
```

## Clustering: do my friends know each other?

For one node `u` with `k` neighbours, there are `k(k-1)/2` possible links **among** those neighbours. The **local clustering** of `u` is the fraction of them that exist. The **clustering coefficient** of the graph is the average over all nodes.

```exercise

---starter

---solution
def node_clustering(G, u):
    neighbors = G[u]
    k = len(neighbors)
    if k < 2:
        return np.nan
    possible = k * (k - 1) / 2
    exist = 0
    for v, w in all_pairs(neighbors):
        if G.has_edge(v, w):
            exist += 1
    return exist / possible
---tests
assert node_clustering(nx.complete_graph(5), 0) == 1.0, "In a complete graph every pair of neighbours is linked"
assert node_clustering(nx.star_graph(4), 0) == 0.0, "The hub of a star: none of its neighbours know each other"
assert np.isnan(node_clustering(nx.path_graph(3), 0)), "An end of a path has one neighbour: return nan"
assert node_clustering(nx.circulant_graph(10, [1, 2]), 0) == 0.5, "Ring lattice with k=4: 3 of 6 possible links exist"
---hint
`possible = k * (k - 1) / 2`. Count the pairs `(v, w)` of neighbours with `G.has_edge(v, w)`, then divide.
```

## Path length: how many hand-offs?

The **characteristic path length** L is the average shortest-path length over all pairs of nodes. Now measure both C and L as `p` grows, each relative to the lattice's value. This is the book's Figure 3.2.

```run
title: The small-world experiment
def make_ws_graph(n, k, p):
    return nx.watts_strogatz_graph(n, k, p, seed=int(np.random.randint(1 << 30)))

def characteristic_path_length(G):
    lengths = dict(nx.shortest_path_length(G))
    return np.mean([d for u in lengths for v, d in lengths[u].items() if u != v])

def clustering_coefficient(G):
    return np.nanmean([nx.clustering(G, u) for u in G])

def run_one_graph(n, k, p):
    ws = make_ws_graph(n, k, p)
    return characteristic_path_length(ws), clustering_coefficient(ws)

n, k = 300, 10
ps = np.logspace(-4, 0, 9)
L0, C0 = run_one_graph(n, k, 0)
res = np.array([np.mean([run_one_graph(n, k, p) for _ in range(3)], axis=0) for p in ps])
L, C = res[:, 0] / L0, res[:, 1] / C0
for p, l, c in zip(ps, L, C):
    print(f"p={p:.4f}   L/L0={l:.2f}   C/C0={c:.2f}")
plt.plot(ps, C, "o-", label="C(p) / C(0)  clustering")
plt.plot(ps, L, "s-", label="L(p) / L(0)  path length")
plt.xscale("log"); plt.xlabel("rewiring probability p"); plt.legend()
plt.title("Small world: paths collapse long before clustering does")
```

```quiz
Look at the plot around p = 0.01. What does a "small world" network have?
- Low clustering and long paths
- Low clustering and short paths (a random graph)
* High clustering and short paths
- High clustering and long paths (a lattice)
> A handful of shortcuts slashes the average path length (each shortcut serves many pairs), while clustering barely moves because almost every local triangle survives. Both properties at once is what Watts and Strogatz meant by small world.
```

## Breadth-first search

`reachable_nodes` from chapter 2 used a **stack** (last in, first out), so it plunges deep before coming back: depth-first. Swap the stack for a **queue** (first in, first out) and the search spreads out in rings: first everything one step away, then two steps, and so on. That's **breadth-first search (BFS)**, and it's exactly what you need for shortest paths.

A Python list is slow at removing from the front, so we use `collections.deque`, which is fast at both ends.

```exercise
title: Shortest paths with BFS
kind: write
---prompt
The book calls this `shortest_path_dijkstra` (for unweighted graphs Dijkstra's algorithm is just BFS). Return a dict mapping every reachable node to its distance from `source`. A node's distance is set the first time BFS discovers it: its parent's distance plus one.
---starter
def shortest_path_dijkstra(G, source):
    dist = {source: 0}
    queue = deque([source])
    # your loop here
    return dist
---solution
def shortest_path_dijkstra(G, source):
    dist = {source: 0}
    queue = deque([source])
    while queue:
        node = queue.popleft()
        new_dist = dist[node] + 1
        neighbors = set(G[node]).difference(dist)
        for n in neighbors:
            dist[n] = new_dist
        queue.extend(neighbors)
    return dist
---tests
G = nx.path_graph(5)
assert shortest_path_dijkstra(G, 0) == {0: 0, 1: 1, 2: 2, 3: 3, 4: 4}, "Along a path the distance is the index"
G = nx.circulant_graph(12, [1, 2])
d = shortest_path_dijkstra(G, 0)
assert d == nx.single_source_shortest_path_length(G, 0), "Distances should match NetworkX on a ring lattice"
assert 99 not in shortest_path_dijkstra(nx.Graph([(0, 1), (99, 100)]), 0), "Unreachable nodes don't get a distance"
---hint
`set(G[node]).difference(dist)` gives the neighbours that don't have a distance yet (a dict's keys act like a set).
---hint
Each of those gets `dist[node] + 1`, then goes on the queue.
```

```recall
Q: Explain why a few random shortcuts make paths short but leave clustering high.
A: - Path length is a **global** property: one shortcut between distant parts of the ring gives a fast route to everyone near either end, so the average over all pairs drops a lot.
- Clustering is **local**: each shortcut destroys only the few triangles that used the edge it replaced. With p = 0.01, about 99% of edges, and almost all triangles, are untouched.
- So there's a wide range of p where the network is both clustered (like a lattice) and short (like a random graph): a small world.
```

```recall
Q: What's the one change that turns depth-first search into breadth-first search, and why does BFS give shortest paths?
A: - Replace the stack (pop from the end) with a queue (pop from the front, `deque.popleft`).
- BFS processes nodes in order of distance: all nodes at distance 1, then 2, and so on. So the first time a node is discovered, it's along a shortest path, and its distance is its parent's + 1.
```
