```prelude
import numpy as np
import matplotlib.pyplot as plt

def topple_step(a, K=3):
    """One round of toppling: every cell above K sends 1 grain to each of 4 neighbours.
    Grains pushed past the edge fall off the table."""
    toppling = a > K
    n = toppling.sum()
    t = toppling.astype(a.dtype)
    a -= 4 * t
    a[1:, :] += t[:-1, :]
    a[:-1, :] += t[1:, :]
    a[:, 1:] += t[:, :-1]
    a[:, :-1] += t[:, 1:]
    return n
```

## Critical without anyone tuning it

In chapters 2 and 7 you found **critical points**: a value of p or q where the system flips from one behaviour to another, with heavy tails and fractals right at the threshold. But someone had to set q to exactly 0.593. In nature, who does that?

In 1987 Bak, Tang and Wiesenfeld proposed an answer: some systems **drive themselves** to the critical point. Their model was a pile of sand. Keep dropping grains; the pile grows steeper until avalanches start; avalanches flatten it; it grows again. It ends up hovering at the edge, where the next grain might cause nothing, or might cause an avalanche of any size. That's **self-organized criticality** (SOC).

## The rule

Each cell holds a number of grains. Any cell with **more than K = 3** grains **topples**: it loses 4 and each of its 4 neighbours gains 1. Grains that would land off the edge are lost. Toppling can push neighbours over 3, so one topple can set off more: an **avalanche**.

```predict
a = np.array([[0, 0, 0],
              [0, 4, 1],
              [0, 0, 0]])
n = topple_step(a)
print(n)
print(a)
```

## Relax: run the avalanche to the end

```exercise

kind: write
---prompt
Write `relax(a, K=3)`: call `topple_step` until no cell topples. Return `(duration, size)` where **duration** is the number of steps in which something toppled, and **size** is the total number of topples. `topple_step` (in the prelude) modifies `a` in place and returns how many cells toppled.
---starter
def relax(a, K=3):
    duration = 0
    size = 0
    # your loop here
    return duration, size
---solution
def relax(a, K=3):
    duration = 0
    size = 0
    while True:
        n = topple_step(a, K)
        if n == 0:
            break
        duration += 1
        size += n
    return duration, size
---tests
```

```run
title: Collect 3,000 avalanches
def relax(a, K=3):
    duration = size = 0
    while (n := topple_step(a, K)):
        duration += 1
        size += n
    return duration, size

def drop(a, rng):
    i, j = rng.integers(a.shape[0]), rng.integers(a.shape[1])
    a[i, j] += 1
    return relax(a)

rng = np.random.default_rng(3)
n = 30
pile = np.full((n, n), 10)
relax(pile)                               # settle the big pile first
print("average height after settling:", round(pile.mean(), 2))
results = np.array([drop(pile, rng) for _ in range(3000)])
durations, sizes = results[:, 0], results[:, 1]
print("average height while driven:", round(pile.mean(), 2))
print("avalanches with no topple at all:", np.mean(sizes == 0).round(2))
print("biggest avalanche:", sizes.max(), "topples")

xs = np.arange(1, sizes.max() + 1)
ccdf = [np.mean(sizes > x) for x in xs]
plt.loglog(xs, ccdf)
plt.xlabel("avalanche size s"); plt.ylabel("fraction of avalanches bigger than s")
plt.title("Avalanche sizes: a straight-ish line on log-log axes")
```

```quiz
Most drops cause no avalanche at all, yet some cause hundreds of topples. On log-log axes, the CCDF of sizes falls roughly in a straight line over a wide range. What's the term for that?
- A normal distribution
- An exponential distribution
* A heavy-tailed (power-law-like) distribution
- A uniform distribution
> A straight line on log-log axes means the chance of a bigger avalanche falls off like a power of its size, not exponentially. There's no "typical" avalanche size; huge ones are rare but not vanishingly rare. That's the signature of criticality.
```

## Holism vs reductionism

The book uses SOC to talk about how we explain things. A **reductionist** explanation of an avalanche traces it to the grain that set it off and the cells it touched. But that misses the point: the same grain on the same cell might do nothing tomorrow. The **holistic** explanation is that the pile as a whole sits in a critical state, where small causes can have effects of any size.

The book argues SOC may explain heavy tails in earthquakes, forest fires, extinctions and even stock market crashes, while warning that a heavy-tailed distribution alone doesn't prove SOC.

```quiz
After a huge avalanche, someone asks "which grain caused it?" What does the SOC view say?
- The last grain, obviously
* The grain was only the trigger; the real cause is the pile's critical state, which made a large avalanche possible
- Avalanches have no causes
- The biggest cell caused it
> In a critical system the size of the response is set by the state of the whole pile, not by the trigger. Asking which grain caused it is like asking which match caused a forest fire after decades of dry undergrowth.
```

```recall
Q: What makes the sand pile "self-organized" critical, compared with percolation at q = 0.593?
A: - In percolation, the critical point is a parameter value someone has to choose.
- The sand pile reaches its critical state by itself: slow driving (one grain at a time) plus fast relaxation (avalanches) pushes it to the state where avalanches of all sizes occur.
- Evidence: the average height settles near 2.1 whatever the start, and avalanche sizes and durations follow heavy-tailed distributions.
```

```recall
Q: Describe the drop-and-relax experiment and what you measure.
A: - Start with a tall pile and relax it to stability.
- Repeatedly add one grain at a random cell and relax, counting the steps (duration) and total topples (size) of each avalanche.
- Plot the distributions of size and duration on log-log axes (PMF or CCDF). A roughly straight line across a wide range is the heavy tail.
```
