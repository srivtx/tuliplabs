## What makes a model agent-based

Four features set agent-based models (ABMs) apart from the cellular automata of earlier chapters:

- **Agents** that model people or organisms, each with its own state and simple behaviour.
- **Heterogeneity:** agents differ from each other (here: how far they see, how fast they burn sugar).
- **An environment** they live in and change.
- **Local interactions:** agents only see and affect what's near them.

The interesting results are again **emergent**: segregation nobody asked for, and inequality nobody designed.

## Schelling in 2-D

The classic version: an n×n grid; each cell is empty (0), red (1) or blue (2). An agent is unhappy if fewer than a fraction p of its 8 neighbours are the same colour as itself. Each step, every unhappy agent moves to a random empty cell.

```exercise
def frac_same(a):
    same = np.zeros(a.shape)
    occ = np.zeros(a.shape)
    for di in (-1, 0, 1):
```

```run
    same, occ = np.zeros(a.shape), np.zeros(a.shape)
    for di in (-1, 0, 1):
        for dj in (-1, 0, 1):
            if (di, dj) != (0, 0):
                nb = np.roll(np.roll(a, di, 0), dj, 1)

                same += (nb == a) & (a != 0)

def step(a, p, rng):
```

## Sugarscape: the world

Epstein and Axtell's Sugarscape (1996): a 50×50 grid where each cell has a **capacity** (0–4) for sugar, arranged as two mountains. Sugar regrows by 1 per step up to the cell's capacity. 400 agents, each with:

- **vision** (1–6): how many cells it can see in the 4 directions,
- **metabolism** (1–4): sugar burned per step,
- **sugar**: its stockpile. If it drops below 0, the agent dies.

## An agent's choice

Each step, an agent looks along the 4 directions (up, down, left, right) up to its `vision`, considers the cells that aren't occupied by another agent (and its own cell), and moves to the one with the **most sugar**. Ties go to the **closest** cell.

```exercise
def best_cell(sugar, loc, vision, occupied):
    n, m = sugar.shape
    r, c = loc
    candidates = [(0, loc)]
    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
```

## Run Sugarscape

```run
title: 400 agents, 100 steps
def make_capacity(n=50):
    rows, cols = np.indices((n, n))
    dist = np.minimum(np.hypot(rows - 15, cols - 15), np.hypot(rows - 35, cols - 35))
    return np.digitize(dist, [21, 16, 11, 6]).astype(float)

def best_cell(sugar, loc, vision, occupied):
    n, m = sugar.shape
    r, c = loc
    cands = [(0, loc)]
    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
        for d in range(1, vision + 1):
            cell = ((r + dr * d) % n, (c + dc * d) % m)
            if cell not in occupied:
                cands.append((d, cell))
    return max(cands, key=lambda x: (sugar[x[1]], -x[0]))[1]

rng = np.random.default_rng(4)
capacity = make_capacity()
sugar = capacity.copy()
spots = rng.choice(2500, 400, replace=False)
agents = [{"loc": (s // 50, s % 50), "vision": rng.integers(1, 7), "metabolism": rng.integers(1, 5),
           "sugar": rng.integers(5, 26)} for s in spots]
pop = [len(agents)]
frames = []
for t in range(100):
    if t % 2 == 0:
        view = sugar.copy()
        for a in agents:
            view[a["loc"]] = 6           # agents drawn as dark dots
        frames.append(view)
    rng.shuffle(agents)
    occupied = {a["loc"] for a in agents}
    alive = []
    for a in agents:
        occupied.discard(a["loc"])
        a["loc"] = best_cell(sugar, a["loc"], a["vision"], occupied)
        a["sugar"] += sugar[a["loc"]]; sugar[a["loc"]] = 0
        a["sugar"] -= a["metabolism"]
        if a["sugar"] >= 0:
            occupied.add(a["loc"]); alive.append(a)
    agents = alive
    np.minimum(sugar + 1, capacity, out=sugar)
    pop.append(len(agents))

flipbook(frames, cmap="YlOrBr", vmin=0, vmax=6, titles=[f"step {2 * i}" for i in range(len(frames))], fps=6)
print("survivors after 100 steps:", pop[-1], "of 400  (classic runs give about 250)")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.4))
ax1.plot(pop); ax1.set_xlabel("step"); ax1.set_ylabel("agents alive")
```

## Measuring inequality: the Gini coefficient

The **Gini coefficient** is 0 when everyone has the same and approaches 1 when one agent has everything. One formula: sort the wealth values x₁ ≤ … ≤ xₙ, then

G = (2 Σᵢ i·xᵢ) / (n Σᵢ xᵢ) − (n + 1)/n,  with i running from 1 to n.

```exercise

kind: write
---prompt

---starter

---solution
def gini(wealth):
    x = np.sort(np.asarray(wealth, dtype=float))
    n = len(x)
    i = np.arange(1, n + 1)
    return 2 * np.sum(i * x) / (n * np.sum(x)) - (n + 1) / n
---tests
assert abs(gini([5, 5, 5, 5])) < 1e-9, "Perfect equality: 0"
assert abs(gini([0, 0, 0, 10]) - 0.75) < 1e-9, f"One of four has everything: (n-1)/n = 0.75. Got {gini([0, 0, 0, 10])}"
assert abs(gini([3, 1, 2]) - gini([1, 2, 3])) < 1e-9, "Order of input mustn't matter"
assert 0.2 < gini(np.random.default_rng(0).exponential(1, 5000)) < 0.8, "An exponential distribution has Gini about 0.5"
```

## Real-world project: a housing-policy what-if tool

Agent-based models are used for real policy work: transport planners, housing agencies and central banks run them to ask "what happens if we change this rule?" before trying it on real people. Here you'll turn Schelling's city into a small what-if tool and test one policy idea: **anchored homes**, like long-term social-housing tenancies, whose residents stay put whatever their neighbours look like.

```project
title: Housing-policy what-if tool
client: A city council's housing team debating a long-term tenancy scheme
skills: agent-based simulation, boolean masks, parameter sweeps, reproducible seeds
---brief
The council wants to know: if some share of households are on long-term tenancies and never move, does the city stay more mixed? Build `run_city` to run Schelling's model and report segregation, then `step_with_anchors`, a version of `step` where anchored households never move. Sweep the anchored share from 0% to 60% and show the council the curve.
---why
This is how agent-based models earn their keep in practice: the UK's Bank of England uses them for the housing market, transport agencies use MATSim to test road pricing, and epidemiologists used them during COVID to compare lockdown rules. The software pattern is always the same: a model with **knobs**, a fixed **seed** so results can be reproduced and checked, and a **sweep** that turns runs into a chart someone can make a decision from.
---milestones
- Write `run_city(n, p, vacancy, steps, seed)` that returns the final segregation
- Check that p = 0 leaves the city about as mixed as it started
- Write `step_with_anchors`: unhappy households move only if they're not anchored
- Sweep the anchored share and plot segregation against it
- Write one paragraph for the council: what the model suggests, and what it leaves out
---stretch
- Make anchors move **with** their home: when an anchored household is happy, does it matter?
- Add a third group, or a rent level per cell that limits who can move where
- Report the Gini coefficient of "time spent unhappy" across households: who bears the cost?
```

```recall
Q: In Sugarscape no rule mentions wealth inequality. Explain how it emerges.
A: - Agents differ (heterogeneity): some see far and burn little sugar; others see little and burn a lot.
- Location matters: agents near a mountain peak harvest more, and good foragers find and hold the peaks.
- Advantages compound: sugar left over each step accumulates, while poorly-equipped agents hover near zero or die.
- So a skewed (long right tail) wealth distribution emerges from individual differences plus the landscape, with no rule about wealth.
```
