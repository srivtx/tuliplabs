## The dilemma

Two suspects are questioned separately. Each can **cooperate** (stay silent) or **defect** (betray the other). In points:

| | other cooperates | other defects |
|---|---|---|
| **you cooperate** | 3 (reward) | 0 (sucker) |
| **you defect** | 5 (temptation) | 1 (punishment) |

Whatever the other player does, you score more by defecting. So both defect and get 1 each, when they could have had 3 each. Rational individuals produce a bad collective outcome. Then how does cooperation, which is everywhere in nature and society, ever evolve?

```quiz
> Defection is a **dominant strategy** in a one-shot game: it's better whatever the other player does. That's what makes it a dilemma: two players following this logic both end up with 1 instead of 3.
```

## Repeat the game, and strategies appear

In the **iterated** game the same two players meet for several rounds (here, 6). Now your move can depend on what the other player did before, so you can reward cooperation and punish defection.

We encode a strategy as **7 genes**, one for each situation, keyed by the opponent's recent moves:

| key | situation |
|---|---|
| `""` | first round: nothing seen yet |
| `"C"`, `"D"` | second round: the opponent's first move |
| `"CC"`, `"CD"`, `"DC"`, `"DD"` | later rounds: the opponent's **last two** moves |

So a genome is a list of 7 moves, e.g. **tit for tat**: cooperate first, then copy the opponent's last move: `["C", "C", "D", "C", "D", "C", "D"]`.

```quiz
Tit for tat never scores more than its opponent in a single match (it lost 5–10 to all-D). Yet in Axelrod's 1980 tournaments it had the highest total score. How?
- It cheated
* It does well against cooperators (18 each) and loses only a little to defectors, so its average across all opponents is high
- It beats every strategy head to head
- The scoring was biased
> Head-to-head wins don't matter; total points across all games do. All-D beats everyone it meets, but scores poorly overall because nobody cooperates with it. Tit for tat earns full cooperation from nice strategies and limits its losses against nasty ones.
```

## Evolve a population

Now the experiment. Start with 100 agents that **always defect**. Each generation:

1. every agent plays iterated games against 2 others,
2. its fitness is its average score,
3. 10% die at random and are replaced by copies of agents chosen in proportion to fitness,
4. each copy mutates one random gene with probability 0.05.

We track **niceness**: the fraction of all genes in the population that are `"C"`.

```run
title: Cooperation from pure defectors
def respond(genome, opp_history):
    return genome[KEYS.index("".join(opp_history[-2:]))]

def play(g1, g2, rounds=6):
    h1, h2, s1, s2 = [], [], 0, 0
    for _ in range(rounds):
        m1, m2 = respond(g1, h2), respond(g2, h1)
        a, b = PAYOFF[(m1, m2)]
        s1, s2 = s1 + a, s2 + b
        h1.append(m1); h2.append(m2)
    return s1, s2

def evolve(gens=800, n=100, p_mutate=0.05, seed=1):
    rng = np.random.default_rng(seed)
    pop = [["D"] * 7 for _ in range(n)]
    niceness, mean_score = [], []
    for g in range(gens):
        total, games = np.zeros(n), np.zeros(n)
        order = rng.permutation(n)
        for k in range(n):
            for off in (1, 2):                      # play 2 neighbours on a shuffled ring
                i, j = order[k], order[(k + off) % n]
                a, b = play(pop[i], pop[j])
                total[i] += a; total[j] += b; games[i] += 1; games[j] += 1
        fit = total / games
        mean_score.append(fit.mean())
        niceness.append(np.mean([x.count("C") / 7 for x in pop]))
        dead = np.flatnonzero(rng.random(n) < 0.1)
        parents = rng.choice(n, size=len(dead), p=fit / fit.sum())
        for d, par in zip(dead, parents):
            child = list(pop[par])
            if rng.random() < p_mutate:
                i = rng.integers(7)
                child[i] = "C" if child[i] == "D" else "D"
            pop[d] = child
    return niceness, mean_score, pop

niceness, mean_score, pop = evolve()
print(f"niceness: start {niceness[0]:.2f}, end {niceness[-1]:.2f}")
print(f"mean points per game: start {mean_score[0]:.1f}, end {mean_score[-1]:.1f}  (all-D = 6, all-C = 18)")
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 3.4))
ax1.plot(niceness); ax1.set_xlabel("generation"); ax1.set_ylabel("niceness (share of C genes)")
ax2.plot(mean_score); ax2.set_xlabel("generation"); ax2.set_ylabel("mean points per game")
```

It takes a few seconds in the browser; try other `seed` values to see different histories. Cooperation tends to rise in waves and sometimes collapses.

> A note on the model: an early published version of this code had the dying rule backwards. Like the 3D lab, this lesson uses the corrected version, where fitter agents are more likely to survive (here, to reproduce), so your curves may not match some older published figures.

## Why cooperation can win

Axelrod's analysis of his tournaments found the successful strategies shared a few traits:

- **Nice:** never the first to defect.
- **Retaliating:** punish defection, so you can't be exploited forever.
- **Forgiving:** return to cooperation when the other does.
- **Clear:** easy for others to recognise and adapt to.

None of this needs altruism. In the repeated game, cooperating with reciprocators simply **pays**. Once a few reciprocators exist, they score well with each other, and selection does the rest.

```quiz
Why can a mutant cooperator in an all-defector population not take off alone, while a small cluster of reciprocators can?
- Mutants are always less fit
* A lone cooperator only meets defectors and gets exploited; reciprocators that meet each other earn 18 instead of 6 and outscore defectors
- Defectors refuse to play with cooperators
- Mutation rates are too low
> Cooperation pays only when cooperators meet each other. That's why it often appears in waves: a few reciprocators drift in, find each other, out-earn defectors, and spread.
```

## Real-world project: a tournament for negotiation bots

Axelrod ran his famous tournaments by inviting people to send in strategies and playing them all against each other. You can run the same thing. Think of each genome as a **negotiation bot**: cooperate means "make a fair offer", defect means "grab more". The twist that real negotiators know: messages get misread. A fair offer sometimes **looks** like a grab. That noise changes which bots win.

```project
title: Round-robin tournament for negotiation bots
client: A course on negotiation that wants students to submit bots and see them compete
skills: dictionaries, nested loops over pairs, randomness with seeds, ranking results
---brief
Build the tournament engine. `round_robin(bots)` plays every pair of bots once and returns each bot's total score. `play_noisy` is `play` with a twist: each move is flipped with probability `noise` before the other player sees it. Then compare the leaderboard with and without noise: does tit for tat still win when messages get garbled?
---why
Tournaments like this are how AI researchers compare game-playing agents (from Axelrod's 1980 contest to poker bots and multi-agent benchmarks), and the noisy version is why real protocols include forgiveness: TCP backs off and retries instead of giving up on a dropped packet, and diplomats use hotlines to explain a misread signal before it escalates. Round-robin scheduling itself is everywhere, from sports fixtures to load testing every pair of services.
---milestones
- Write `round_robin(bots, rounds)`: every pair plays once, totals go into a dict
- Print a leaderboard sorted by score
- Write `play_noisy`: flip each move with probability `noise`
- Show that tit for tat against itself breaks into long feuds when there is noise
- Add a forgiving bot that only punishes **two** defections in a row, and see if it beats tit for tat under noise
---stretch
- Let students submit bots as Python functions instead of 7-gene lists
- Run an evolutionary tournament: after each round, bots reproduce in proportion to their score
- Report, for each pair, who won the head-to-head and by how much
```

```exercise
---setup

def play(g1, g2, rounds=6):
```

```exercise
---solution
def play_noisy(g1, g2, rounds, noise, rng):
    flip = {"C": "D", "D": "C"}
    h1, h2, s1, s2 = [], [], 0, 0
    for _ in range(rounds):
        m1, m2 = respond(g1, h2), respond(g2, h1)
        if rng.random() < noise:
            m1 = flip[m1]
        if rng.random() < noise:
            m2 = flip[m2]
        a, b = PAYOFF[(m1, m2)]
        s1, s2 = s1 + a, s2 + b
        h1.append(m1); h2.append(m2)
    return s1, s2
---tests
```

```recall
Q: Explain how cooperation can evolve in a population that starts out all defectors, using the iterated prisoner's dilemma.
A: - In a single game defection dominates, but in repeated games strategies can condition on history.
- Mutation occasionally produces reciprocating strategies (nice but retaliating, like tit for tat).
- When reciprocators meet each other they cooperate and earn far more than defectors earn against each other (18 vs 6 over 6 rounds), while losing little against defectors.
- Fitness-proportional reproduction spreads them, so niceness and average score rise, often in waves, without anyone being altruistic.
```
